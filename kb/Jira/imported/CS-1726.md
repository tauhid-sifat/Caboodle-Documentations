## Description

Currently, filters across the Data Mapping modules are static and do not reflect the actual data present in the system. All filters across every module under Admin → Data Mapping need to be made dynamic, so filter options are populated from live data rather than a fixed/hardcoded list.

**Modules in Scope:**

Dashboard, Unmapped Data, Mapped Data, Entity Resolution, Credential Manager, Data Sync, Brand Data Cleanup

**Steps to Reproduce (current behavior):**

1. Navigate to Admin → Data Mapping.
2. Open any module and check the available filters.
3. Observe that filter options are static and do not reflect current/actual data values.

**Expected Result:**
All filters across every Data Mapping module should be dynamic — options should be populated based on the current data in the system and update automatically as data changes (new values added, old values removed, etc.).

**Actual Result:** Currently Filters are not dynamic, also some filter have text option. We need to convert it with List option.

**Acceptance Criteria:**

* All filters under every module of Admin → Data Mapping are converted to dynamic list-type filters.
* Filter options are sourced from live/current data, not static/hardcoded values.
* Filters update automatically as underlying data changes.
* No module under Data Mapping is left out of this update.
