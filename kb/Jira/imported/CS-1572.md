## Description

1. **CRM – Banner SKUs | Slotting filter is missing**

* **Issue:** No filter available for "Slotting" in the Banner SKUs section.
* **Expected:** A "Slotting" filter should be available to allow filtering Banner SKU records by this field.
* **Steps to Reproduce:** Navigate to Admin > Banner SKUs > check available filters > Slotting filter not present.

2. **CRM  – Banner SKUs | UPC filter is missing**

* **Issue:** No filter available for "UPC" in the Banner SKUs section.
* **Expected:** A "UPC" filter should be available to allow filtering/searching Banner SKU records by UPC.
* **Steps to Reproduce:** Navigate to Admin > Banner SKUs > check available filters > UPC filter not present.

3. **CRM – CRM Data Upload | Sample CSV file doesn't indicate mandatory fields**

* **Issue:** The sample CSV file provided for CRM Data Upload does not indicate which fields are mandatory vs. optional, making it unclear for admins/users preparing their upload file.
* **Expected:** Sample CSV (or accompanying documentation/tooltip) should clearly mark mandatory fields (e.g., via naming convention like `*FieldName`, a legend, or a separate note near the download link).
* **Steps to Reproduce:** Navigate to Admin > CRM Data Upload > download sample CSV > review file/headers > no mandatory field indication present.

4. **CRM – Price Lists | Category filter is missing**

* **Issue:** No filter available for "Category" in the Price Lists section.
* **Expected:** A "Category" filter should be available to allow filtering Price List records by category.
* **Steps to Reproduce:** Navigate to Admin > Price Lists > check available filters > Category filter not present.

5. **CRM – Product Specs | "Filtered Data" export option missing**

* **Issue:** There is no option to export only the currently filtered data in the Product Specs section — export likely only supports full/unfiltered data.
* **Expected:** An "Export Filtered Data" option should be available so users can export just the records matching their current filter selections.
* **Steps to Reproduce:** Navigate to Admin > Product Specs > apply a filter > attempt to export > only full dataset export available, no filtered export option.
