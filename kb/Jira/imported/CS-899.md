## Description

System allows duplicate pricing entries via form or CSV without validation.

* **Steps to Reproduce:**1. Go to the "Pricing" section.
  2. Add a price entry for a product with a specific valid-from date.
  3. Add the same product-price-date combo again manually or via CSV upload.
* **Actual Result:*** Duplicate price entries are created without any error or warning.
* **Expected Result:*** The system should check for duplicate price records and prevent adding duplicates, showing a message like “Duplicate pricing entry detected”.
