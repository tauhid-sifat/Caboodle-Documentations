## Description

Current export endpoints (`GET Brokers/export-events`, `GET Brokers/export-promotional-management-events`) output raw CSV only. Users then spend time formatting columns, adding headers, and styling before sharing with brands or retailers. The existing export also has known bugs (CS-1367: export data doesn't match filters — resolution blocks this story).

This story adds a "Formatted Report" export option that outputs a presentation-ready document with proper column widths, headers, date formatting, and branding.
