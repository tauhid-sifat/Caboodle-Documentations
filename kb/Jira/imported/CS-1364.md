## Description

In **Admin > CRM Data Upload > Stores**, when a user attempts to edit a store and clicks on the **“Update Store”** button, the system returns an error instead of successfully updating the store details.

**Steps to Reproduce:**

1. Navigate to Admin > CRM Data Upload > Stores
2. Select any store and click on Edit
3. Make changes to the store তথ্য
4. Click on **Update Store**

**Expected Result:**
Store details should be updated successfully without any errors.

**Actual Result:**
An error is displayed and the store is not updated.
