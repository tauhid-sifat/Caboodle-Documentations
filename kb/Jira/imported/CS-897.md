## Description

* System allows creation of duplicate category names.
* **Steps to Reproduce:**1. Create a category named "Ice Cream 16oz" (or any name).
  2. Try creating another category with the exact same name (either manually or through file upload).
* **Actual Result:*** The duplicate category is successfully created and appears in the list.
* **Expected Result:*** System should prevent duplication and display an error message such as "Category already exists".
