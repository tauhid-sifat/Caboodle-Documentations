## Description

In the "By Banner" section of the Trade Spend Roll Up Report, each banner can be expanded to show its individual events. After expanding a banner that contains the event 11/08-2 33333, attempting to collapse (minimize) any *other* banner does not collapse it as expected. Instead, an extra "11/08-2 33333" event row gets incorrectly added under that other banner — even though this event does not belong to it. This incorrect row keeps getting added every time the minimize button is clicked on a different banner. Refreshing the page restores the correct/expected state.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Roll Up Report (Brand: Zucchini Beanie Demo Brand).
2. Under "By Banner," expand a banner that contains the event **11/08-2 33333**.
3. Attempt to collapse (minimize, using the "−" icon) a different banner (e.g., "AJ's Fine Foods" or "Brooklyn Fare").
4. Observe the row list under that banner.

**Expected Result:**
Clicking the minimize ("−") icon on a banner should simply collapse that banner's expanded event list — no new rows should be added.

**Actual Result:**
Clicking minimize on a different banner incorrectly adds a duplicate/unrelated "11/08-2 33333" event row under it instead of collapsing. This repeats with every minimize click until the page is refreshed, after which the data displays correctly.
