## Description

The Sort By control in the Brand-Retailer section currently offers only one option ("Retail"). Since a sort selector with a single option serves no real purpose, it should be removed. Instead, the list should be sorted by **Banner Name** by default, with no user-facing sort control.

**Acceptance Criteria:**

* The Sort By dropdown/control is removed from the Brand-Retailer section.
* Data in this section is sorted by **Banner Name** by default (no user action required).
* No broken layout or leftover UI space where the Sort By control used to sit.
