## Description

In the "Notify Brands" modal (Broker → Category Review → Notify Brands), the **CC** field should be pre-populated by default with the email address of the currently logged-in user — regardless of role (Broker, Sub Broker, User, Brand Owner, etc.).

**Steps to Reproduce:**

1. Log in as any user type (Broker / Sub Broker / User / Brand Owner / etc.).
2. Navigate to Category Review.
3. Select an entry and click "Notify Brands."
4. Check the CC field.

**Expected Result:**
The CC field should default to the email address of whichever user is currently logged in and composing the notification (Broker, Sub Broker, User, Brand Owner, etc.) — not a single fixed/hardcoded address.
