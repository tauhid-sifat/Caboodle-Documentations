## Description

In **CRM → Distributors → Delivery Methods**, after linking banners to a delivery method, a **Region filter** is shown. However, this Region filter's option list includes extra/irrelevant values that don't correspond to the regions actually present among the linked banners for that specific delivery method.

**Impact**

* Users may select an irrelevant region and get an empty/unexpected result, assuming there's a data issue rather than a filter-scoping bug.
* Reduces trust in the accuracy of filters throughout the Delivery Methods flow.
* Adds unnecessary noise/clutter to the filter dropdown, making it harder to find relevant options.

**Steps to Reproduce**

1. Navigate to **CRM → Distributors → Delivery Methods**.
2. Select a delivery method and link one or more banners to it.
3. Open the **Region filter** shown after linking banners.
4. Review the list of region options.
5. Cross-check against the actual regions of the linked banners for this delivery method — observe extra region values present that don't correspond to any linked banner.

**Expected Behavior**

* The Region filter should only display region values that correspond to the banners actually linked under the current delivery method.

**Actual Behavior**

* The Region filter includes extra/irrelevant region options not present among the linked banners for that delivery method.
