## Description

When an Admin inactivates a sub-user, the resend mail functionality correctly **excludes** the inactive user and sends only to active participants — this part works as expected. However, the **participant count displayed in the Resend Mail modal is not updated** to reflect the reduced number of active recipients.

**Steps to Reproduce:**

1. As Admin, note a participant list with, e.g., 4 users (all active).
2. Inactivate one sub-user from that list.
3. Trigger "Resend Mail" for the same entry/participant list.
4. Observe the participant count shown in the Resend Mail modal.

**Actual Behavior:**

* Mail is correctly sent only to the 3 remaining active users (correct behavior).
* However, the modal still **displays the count as 4** — not reflecting the inactivated user's removal.

**Expected Behavior:**

* The participant count in the Resend Mail modal should dynamically reflect only **active** participants.
* In this example, after inactivating 1 of 4 users, the count should update and display **3**, matching the actual number of recipients the mail will be sent to.
