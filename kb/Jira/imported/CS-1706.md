## Description

The **Distributor APL** section currently does not support **Filtered Export**. This needs to be added so users can export only the data matching their currently applied filters/search, consistent with the export functionality being implemented across other modules in the app.

**Current Behavior:**

* Export in Distributor APL exports the **full dataset**, regardless of any filters applied on screen.

**Expected Behavior:**

* Add **Filtered Export** capability to Distributor APL, so that when filters (and/or search) are applied, the export produces only the **matching filtered records** — not the entire dataset.
* Should follow the same **3 export types** pattern already requested elsewhere (All Data / Current Page / Filtered Data), for consistency — *(confirm if all 3 are needed here, or just Filtered Export specifically for this ticket)*.
* Ensure the export correctly respects **both filter fields and search bar** input (ties into the earlier raised bug where Filtered Export didn't work with normal search in Brand Retail Item Status — same logic must be correctly applied here from the start).
