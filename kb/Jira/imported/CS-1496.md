## Description

Currently, when a user navigates from the Broker Dashboard into any module, there is no direct way to return to the Broker Dashboard from within that module. Users must go back through **Broker Workspace** to get back to the Dashboard, which is an extra, unnecessary step.

**Requirement:**
Add a **Back** button (or equivalent navigation element, e.g., breadcrumb/"Back to Dashboard" link) to every module accessible from the Broker Dashboard, allowing users to return directly to the Broker Dashboard without routing through Broker Workspace.
