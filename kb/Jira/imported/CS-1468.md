## Description

**Depends on:** [CS-1462](https://caboodleservices.atlassian.net/browse/CS-1462)

Switch Trade Spend over to Organization-based access, covering both live and sandbox areas. Priority fix: if the system can't determine the user's role, the restriction is currently **skipped entirely** rather than applied strictly. After this ticket, an unrecognised user sees nothing rather than everything.

**Acceptance Criteria:**

* Submission-status updates are limited to the brands the user has access to.
* A user whose role cannot be determined sees nothing, rather than everything.
* Promotional note figures and their exports are unchanged for an unaffected user.
* Revoked brand access takes effect immediately in Trade Spend screens.
