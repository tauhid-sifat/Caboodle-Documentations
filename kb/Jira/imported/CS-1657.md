## Description

Certain brands currently have reports marked with a "Coming Soon" message. Even when these reports are enabled via Module Configuration, they remain inaccessible to users due to the "Coming Soon" restriction. Since this feature/restriction is no longer needed, it should be removed.

**Current Behavior:**

* Admin can toggle a report On/Off in Module Configuration.
* However, if a report has the "Coming Soon" tag, it stays inaccessible regardless of the enabled/disabled toggle state.
* Users see a "Coming Soon" message instead of being able to access the report.

**Requested Behavior:**

* Remove the "Coming Soon" restriction/logic entirely.
* Once a report is enabled in Module Configuration, it should be **fully accessible** to users without any additional gating.
* Disabling the toggle should be the only mechanism controlling access going forward.

**Reason for Change:**
This restriction is no longer needed as the underlying reports are ready/available for use.

**Impact:**

* Removing this will allow admins to properly control report access via the existing enable/disable toggle without a redundant blocking layer.

**Action Needed:**

* Identify and remove all "Coming Soon" flags/messages and associated access-blocking logic tied to affected brands/reports.
* QA to verify enabled reports become accessible immediately after the change.
