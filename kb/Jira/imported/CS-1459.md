## Description

**Current Behavior**

* When an error occurs during file upload, the BE does not return a proper error message in the response.

**Required Behavior**

* BE should return a clear, specific error message whenever an upload error occurs (e.g., validation failure, malformed row, unsupported format, etc.).
* Error message should be structured so FE can display it directly or map it to a user-friendly message.
* Error response should include enough detail (e.g., row number, field, reason) to be useful in the error file/report.
