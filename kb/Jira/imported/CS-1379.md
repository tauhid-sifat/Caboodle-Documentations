## Description

If a user is already signed in to the system and then clicks on a new invitation/registration email link, the system redirects the user to the login page instead of taking them to the signup/registration flow associated with the invitation.

This breaks the expected invitation onboarding flow and creates confusion for users who are already authenticated.

### Steps to Reproduce

1. Log in to the system with any existing account
2. Receive a new invitation/registration email
3. Click the invitation registration link while still logged in

### Actual Behavior

The invitation link redirects the user to the login page.

### Expected Behavior

The invitation link should:

* Open the intended signup/registration page
* Validate the invitation token properly
* Allow the user to continue the invitation flow

Possible expected handling:

* If the logged-in user matches the invited email → continue registration flow
* If the logged-in user is different from the invited email → show a proper warning/message and request account switch/logout if necessary

Example message:

> “You are currently logged in with a different account. Please log out and continue with the invited email account.”
