## Description

When a promo name is updated in Trade Spend Sandbox (TSS) and then pushed to BAP, the updated name is not reflected in the BAP promo list.

**Steps to Reproduce:**

1. Go to TSS and create a promo.
2. Change the promo name in TSS.
3. Push the promo to BAP.
4. Go to BAP promo list.

**Expected Result:**
The updated promo name should appear in the BAP promo list.
