## Description

Implement an SNS webhook endpoint to receive email delivery events from the email provider (e.g., AWS SES via SNS). The primary goal is to track the status of outbound emails and detect failures for critical emails such as login authentication emails, password reset emails, and other system-generated notifications.

The webhook should securely receive and process SNS notifications, allowing the system to log and monitor email delivery outcomes for troubleshooting and operational visibility.

**Acceptance Criteria:**

* Create a webhook endpoint to receive SNS notifications.
* Validate and securely process incoming SNS messages.
* Handle SNS subscription confirmation requests.
* Process relevant email sending events, including but not limited to:* Delivery
  * Bounce
  * Complaint
  * Reject
  * Delivery delay (if applicable)
* Persist or log email event details for monitoring and debugging.
* Ensure failed email events can be correlated with the original email request (where possible).
* Add appropriate error handling and logging for invalid or failed webhook requests.
* Document the webhook endpoint, expected payloads, and configuration steps.

**Business Value:**

This implementation will provide visibility into email delivery failures, enabling the team to quickly identify issues affecting critical emails (such as login authentication emails) and improve the reliability and observability of the email delivery pipeline.
