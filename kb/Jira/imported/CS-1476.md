## Description

The promotion fee value displayed in the **Promotion Fees** listing does not match the actual **Lump Sum Amount** shown in the Promotion Fee Details.

**Steps to Reproduce:**

1. Navigate to **Trade Spend Sandbox**.
2. Go to the **Promotion Fees** section.
3. Create or view a promotion fee with **Fee Type = Lump Sum**.
4. Observe the fee value in the Promotion Fees listing.
5. Click the **View** icon to open Promotion Fee Details.
6. Compare the displayed values.

**Actual Result:**

* Promotion Fees listing shows **promo 3 = $0**.
* Promotion Fee Details shows **Lump Sum Amount = $20.00**.

**Expected Result:**
The value displayed in the Promotion Fees listing should match the actual **Lump Sum Amount** stored for the promotion fee. In this case, it should display **$20.00**.
