## Description

Banner naming/mapping is inconsistent between the Distributor Report and Monthly Report, causing case data to not roll up correctly in the Monthly Report.

**Steps to Reproduce:**

1. Go to Brand > Bubbies
2. Distributor Report > Banners: filter for "So Cal Albertsons Div," "So Cal DIV – Pavilions," "So Cal DIV – Vons"
3. Go to Monthly Report > search for the same three banners
4. Only one combined banner exists: "So Cal DIV - Albertsons/Vons/Pavilions" — even after refresh

**Expected Behavior:** Either both reports should use the same banner taxonomy, or the Monthly Report's combined banner should correctly aggregate cases from all three underlying Distributor Report banners.

**Actual Behavior:** Monthly Report is not pulling in any actual case data for these banners — data appears lost/orphaned between the two banner naming schemes.
