## Description

In User Management → Users section → Action button → “View Brand Info”, users are able to both view existing brand information and add new brands. Since the functionality includes more than just viewing, the current label is misleading and not appropriate.

**Steps to Reproduce:**

1. Go to User Management → Users
2. Click on the Action button for any user
3. Select “View Brand Info”
4. Observe that new brands can also be added from this section

**Actual Result:**
The option is labeled as “View Brand Info” although users can also add/manage brands.

**Expected Result:**
The menu/action name should be updated to a more appropriate label such as:

* “Manage Brands”
* “Brand Information”
* “View & Manage Brands”

**Impact:**
The current naming may confuse users about the actual functionality available in this section.
