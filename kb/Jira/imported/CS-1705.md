## Description

Multiple naming consistency updates are needed across the **Add Distributor APL modal**, **table column headers**, and **filters**, to align field names, sync titles between modal and table, remove a duplicate filter, apply the agreed filter naming convention, and reorder filters to match table column sequence.

---

1. **Add Distributor APL Modal — Field Title Updates**

* Rename **"Warehouse"** → **"Distribution Center Name"** (to sync with table column name).
* Rename **"Distributor Item Code"** → **"Distributor Code"** (to sync with table column name).

---

2. **Table Column Header Update**

* Rename table column **"Product Description"** → **"Product"** (to sync with the **Add Distributor APL modal** field name).

---

3. **Filters — Apply Naming Convention (Filter Name = Column Name)**

* Update all filter titles to be **exactly the same as their corresponding table column names** — no added "s" for plurals.
* Use **placeholder text** (e.g., "Select Field") to indicate multi-select capability, per the agreed convention — do **not** rely on the filter title itself to convey this.

---

4. **Remove Duplicate Filter — "Warehouse"**

* Remove the **"Warehouse"** filter entirely, since **"DCs"** (to be renamed "Distribution Center Name") already serves this purpose and having both is redundant.
* Update the **search filter's placeholder text** accordingly once "Warehouse" filter is removed, to correctly reflect the remaining/updated searchable fields.

---

5. **Reorder Filter List to Match Table Column Order**

* Rearrange the **filter list sequence** so it follows the **same order as the table's column sequence** (left to right), for a more intuitive and consistent user experience.
