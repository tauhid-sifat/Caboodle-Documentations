## Description

**Description:** In the Admin Panel > CRM Data Upload > Stores module, the current store list contains duplicates due to naming inconsistencies. Additionally, several stores are improperly mapped to multiple banners and/or retailers. We need to run a cleanup script to deduplicate the database and enforce a 1:1 mapping rule where applicable, without losing any historical data tied to these stores.

An export of the current module state is attached for reference.

**Acceptance Criteria:**

* **Identify Duplicates:** Create a script to flag duplicate store entries based matching addresses or geo long/lat.
* **Merge & Reassign:** Merge duplicates. All historical data, banners, and retailer mappings tied to the duplicate must be safely reassigned to the surviving record.
* **Resolve Multi-Mappings:** Determine how to resolve stores mapped to more than one banner/retailer & apply logic to resolve conflicts
* **Soft Deletion:** Determine if duplicate records should be soft-deleted (flagged as inactive) rather than permanently dropped from the database to ensure we can roll back if needed.
* **Data Integrity Check:** Ensure that resolving these mappings does not orphan any existing sales data or break existing reports in the UI.
