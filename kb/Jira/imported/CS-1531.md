## Description

In the **Pricing** section, during **Price Upload**, when some product prices in the batch fail to upload successfully, the system correctly shows an **error file download modal** (allowing users to download details of failed items). However, the **success modal** is also shown at the same time — even though the upload was only partially successful.

**Problem**

* Two conflicting modals (partial-failure error + full success) appear together for the same upload action, giving contradictory feedback to the user.
* Showing a success modal when some prices failed misrepresents the actual outcome of the upload — it implies everything succeeded when it didn't.
* This is the **same pattern** already reported in **Product Specs | Product Upload** (success modal shown alongside error file download modal) — strongly suggesting a shared/systemic issue in how partial-failure states are handled across upload modals platform-wide, not isolated to one module.

**Impact**

* Users may believe the entire price upload succeeded and not realize some prices failed, potentially missing the error file entirely.
* Risk of pricing data gaps going unnoticed — failed price updates may never get corrected/re-uploaded if the user assumes full success, which could have direct business/revenue impact (incorrect or missing pricing).
* Reduces trust in upload confirmation flows across the platform.

**Steps to Reproduce**

1. Navigate to **Pricing** section.
2. Upload a batch/file containing a mix of valid and invalid product prices (so that some succeed and some fail).
3. Observe the **error file download modal** appears (correct behavior for partial failure).
4. Observe the **success modal** also appears at the same time (incorrect).

**Expected Behavior**

* When some product prices fail to upload, only the **error file download modal** (or a combined partial-success/partial-failure modal) should be shown — clearly indicating that not all prices succeeded, with the option to download the error file.
* The success modal should only appear when **all** product prices in the batch upload successfully.
* Consider a distinct **"Partial Success"** modal/state (e.g., "X of Y prices uploaded successfully — download error file for details") for clearer communication, rather than reusing the pure success modal.

**Actual Behavior**

* Both the error file download modal and the success modal are shown together, regardless of partial failure.
