## Description

Update the Brand Report table schema:

* Remove the `Focus` column.
* Remove the `Action Needed` column.
* Add a new `Next Action Due Date` column.

### Acceptance Criteria

**Removals**

* `Focus` and `Action Needed` columns are removed from the Brand Report table UI.
* Any filters, sorts, exports, or saved views referencing these columns are updated or gracefully handled (no broken references/errors).
* Underlying data for these columns is either dropped or retained per data-retention decision (see Open Questions).

**Addition — **`Next Action Due Date`

* New column `Next Action Due Date` is added to the Brand Report table.
* Type: **date**.
* Default value: `null` for all existing and newly created rows.
* Column is inline-editable directly from the row (click-to-edit or edit-in-place date picker — no need to open a separate modal/detail view).
* Selecting/clearing a date updates the row immediately (optimistic update with rollback on API failure, or equivalent standard save pattern).
* Null/empty state is visually distinct (e.g., "—" or "Set date" placeholder) rather than blank ambiguity.
