## Description

### Bug 1: Category is Missing in Price ListSteps to Reproduce

1. Login to the Admin Portal.
2. Navigate to **CRM Data Upload → Price Lists**.
3. Observe the **Category** column.

---

### Actual Result

* The **Category** column displays `—` instead of the associated category name.

---

### Expected Result

* The Category column should display the correct category name for each product.

## Comments

### Kazi Towfiq Tasmin Ornov (2026-07-26T16:54:22.792+0600)

For the Case Cost filtering issue in the Pricing List, when the minimum case cost is set to **0** or is not provided, a large number of records have a case cost of **0**. As a result, it may appear that only records with a case cost of **0** are being returned. However, if you look closely, some page also contains records with other case cost values.

This was not a bug, but rather a misunderstanding caused by the high volume of records with a case cost of **0**.
