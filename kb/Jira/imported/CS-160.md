## Description

Sub Broker Setup process as it should be is attached, but the system is going from step 4 to step 7 (skips steps 5 & 6)

* User receives an invite to set up their account.
* User enters all info, then clicks Register then the system immediately re-directs them to the Login page, so they enter their login credentials. But we haven't even received the info in Super Admin to enable/activate the account. They try to log in, and receive error messages - the system keeps them on the page so they keep trying with repeated error messages. It's creating confusion and frustration.

After clicking "Register", it should **not **direct the User to login page. User should receive an email once we've activated them in Super Admin so they can Verify their email, and receive a "your account is now active". Only then should they be directed to the Login page to log in. 

Same should go for all users.
