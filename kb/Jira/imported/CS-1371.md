## Description

In the **Monthly Report** section, when the user clicks the **Refresh** button, only the table data gets updated. The UI chart and its associated values do not refresh and continue to display outdated data. This results in inconsistency between the table and the chart.

**Steps to Reproduce:**

1. Navigate to the Monthly Report section
2. Click on the **Refresh** button
3. Observe the table data and the chart

**Expected Result:**
Both the table data and the chart (including chart values) should be updated consistently after clicking refresh.

**Actual Result:**
Only the table data updates; the chart and its values remain unchanged.
