## Description

Currently, brand reports can only be removed one at a time. Users need the ability to select multiple brand reports and delete them in a single action.

### Acceptance Criteria

* Each row in the Brand Report list has a selection checkbox.
* A "select all" checkbox is available in the table header (selects/deselects all currently loaded/visible rows).
* When one or more rows are selected, a "Remove" (bulk delete) action becomes available (e.g., toolbar button or context action).
* Triggering removal shows a confirmation dialog stating how many reports will be removed (e.g., "Remove 5 brand reports?").
* On confirm, all selected brand reports are deleted.
* On cancel, no reports are removed and selection state is preserved.
* After successful deletion, removed rows are cleared from the table and selection state resets.
* If deletion partially fails (some IDs succeed, some fail), the user is shown which reports failed to delete and why; successfully removed rows are still removed from the view.
