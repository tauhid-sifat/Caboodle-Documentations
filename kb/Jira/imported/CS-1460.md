## Description

**Current Behavior**

* The error file generated during upload includes a date format validation message that appears to be incorrect or not matching actual validation logic.
* Additionally, the message does not indicate *which column* the invalid date format was found in — making it hard for users to locate and fix the issue in large files.

**Required Action**

* Review the source code responsible for date format validation.
* Confirm the expected/accepted date format(s).
* Update the error message text so it:1. Accurately reflects the validation rule being applied (e.g., specify the expected format like `MM/DD/YYYY` if that's what's enforced).
  2. Includes the **column name** where the invalid date format was detected.
