## Description

When a user renames a promotion in the Trade Spend Sandbox, the **Versions** panel continues to display the old/original name for the version card. The updated name is only reflected after the page is manually refreshed.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open an existing promo (e.g., "ADAMS HOMETOWN MARKET 2026 - KG PV").
3. Rename the promo (e.g., to "ADAMS HOMETOWN MARKET 2026 - KG PV draftv2") using the edit/pencil icon.
4. Open the "Versions" panel on the right.
5. Observe the version card's name.
6. Refresh the page and check the Versions panel again.

**Expected Result:**
Immediately after renaming the promo, the Versions panel should reflect the updated name on the corresponding version card without requiring a manual refresh.

**Actual Result:**
The Versions panel continues to show the old name (e.g., still shows "ADAMS HOMETOWN MARKET 2026 - KG PV" as the version's title) even after the promo has been renamed to "ADAMS HOMETOWN MARKET 2026 - KG PV draftv2." The updated name only appears after a manual page refresh.
