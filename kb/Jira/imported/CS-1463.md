## Description

**Depends on:** [CS-1462](https://caboodleservices.atlassian.net/browse/CS-1462)

The file library becomes shared across the whole Organization rather than tied to individuals. Today a second Broker joining the same brokerage gets an empty area of their own and can't see colleagues' files — once Admins can invite peers freely, that's an obvious gap.

Binding constraint: no existing file may move or become unreachable.

**Acceptance Criteria:**

* All members of an Organization see and work in the same file library.
* Every existing file is in the same place, same name, and still opens/downloads/moves/renames/deletes correctly.
* A newly invited Broker joins their Organization's existing library rather than getting an empty one.
* Admins have access to the Organization's file library.
* Files attached to a specific brand are unaffected.
