## Description

In the Brand report section, using the **Next Action Due Date** filter causes a client-side application crash when the user clicks into the date field a second time after already selecting a date.

**Steps to Reproduce:**

1. Go to the Brand report
2. Open the **Next Action Due Date** filter / **Email Activity **date range /  **Send Email History**
3. Select a date
4. Click into the date field again
5. The application crashes to a blank white page with: *"Application error: a client-side exception has occurred (see the browser console for more information)."*

**Expected Behavior:**

* Re-clicking the date field should let the user adjust the selected date (or simply reopen the picker) without crashing the page.

**Actual Behavior:**

* Full client-side crash, blank page; user has to reload/navigate away to recover.
