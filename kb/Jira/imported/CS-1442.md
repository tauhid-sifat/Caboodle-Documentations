## Description

Improve the CRM Data Upload area across upload, export, and filtering. Where feasible, Upload and Export should be handled in a consistent, reusable way so the same behavior applies across CRM data screens rather than being built per-screen. Filtering should be available on all applicable CRM data tables.

**Scope**

Upload

* Uploading CRM data works consistently across the applicable CRM screens.
* Clear feedback during upload: in-progress, success, and readable errors on failure.
* Invalid files (wrong format, empty, oversized) are rejected gracefully with an explanation.

Export

* User can export data from CRM screens where export applies.
* Export reflects the current view, including active filters.
* Exported file opens correctly; headers match the on-screen table.

Filter

* Filtering available on all applicable CRM data tables.
* Filters update results without a full page reload.
* Clearing filters restores the default state; active filters are visible.

**Acceptance Criteria**

* Upload and Export behave consistently across applicable CRM screens.
* Filtering present and functional on all applicable CRM tables.
* Export respects active filters.
* Clear success/error feedback on upload; clear filter state on tables.
* No regressions to existing functionality.
