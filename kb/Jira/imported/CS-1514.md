## Description

In the Monthly Report section, filters operate independently of one another. Selecting a value in one filter does not narrow down or update the available options in the other filters, forcing users to manually figure out valid filter combinations.

**Problem**

* Filters are not cascading — applying one filter has no effect on the option sets of the remaining filters.
* Users may select combinations that return no data, or see options that are irrelevant given their previous selections.
* This creates a disconnected, static filtering experience rather than a guided, context-aware one.

**Steps to Reproduce**

1. Navigate to Monthly Report section.
2. Apply a value to Filter A.
3. Open Filter B (or any other filter) — observe that its option list is unchanged and still shows all original values, regardless of Filter A's selection.

**Expected Behavior**

* Filters should be interdependent (cascading): selecting a value in one filter should dynamically update the available options in the other filters to reflect only valid, relevant combinations based on current selections.

**Actual Behavior**

* All filters display their full, static option lists regardless of what's selected in other filters.

**Acceptance Criteria**

* Selecting a value in any filter dynamically narrows the option sets of the remaining filters
* Option sets update correctly regardless of the order in which filters are applied
* No filter combination presents an option that would result in zero matching data (unless explicitly intended, e.g., "show all" states)
* QA verification across multiple filter combinations and orders confirms correct cascading behavior
* Performance impact of dynamic filter recalculation assessed, especially for large datasets
