## Description

Currently, there is no way for users to quickly reset or clear applied filters in filter sections across the **Admin Panel** and **Caboodle App**. Users need a **Reset/Clear Filter** button added consistently to every filter section to improve usability.

**Current Behavior:**

* Once filters are applied, users must manually undo each filter individually (or refresh the page) to return to the default/unfiltered view.
* No single-click option exists to clear all applied filters at once.

**Requested Behavior:**

* Add a **"Reset" / "Clear Filter"** button in every filter section across:* Admin Panel
  * Caboodle App
* Clicking this button should:* Clear all currently applied filter values in that section.
  * Reset the list/report/table to its default (unfiltered) state.
  * Reset associated search bar (if part of the same filter section), unless search is intended to be handled separately — *(please confirm scope)*.
