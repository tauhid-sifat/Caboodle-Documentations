## Description

On the Simple Promotion create flow (Retailers and Banners, Products, Events, Metrics), the **Clear Draft** button should discard everything entered so far and take the user back to the promotion list page. After that, when the user creates a new promotion, it should start empty. Currently the data from the cleared draft is not removed: the product selected earlier (and the values entered for it) are still there in the new promotion.

**Steps to Reproduce:**

1. Go to Promotional Planning and start a new promotion (e.g., "CS-1757", plan year 2026).
2. Select a retailer and banner, then go to the **Products** step.
3. Select a product (e.g., "Bubbies Mochi Ice Cream - Mint Chocolate Chip") and enter Average Unit Velocity (e.g., 1.08) and Stores (e.g., 104).
4. Click **Clear Draft**.
5. Create a new promotion again and go to the Products step.

**Expected Result:**

* Clear Draft takes the user to the promotion list page.
* The draft is fully removed, so the new promotion starts with no selected products and no entered values.

**Actual Result:**
The product selected in the old draft is still selected in the new promotion, with the Average Unit Velocity and Stores values still filled in. The draft data is not cleared.

**Acceptance Criteria:**

* Clicking Clear Draft removes all draft data (retailers, banners, selected products, Average Unit Velocity, Stores and any other values entered).
* Clicking Clear Draft takes the user to the promotion list page.
* A new promotion created after Clear Draft has no selected products and no values from the old draft.
