## Description

In *Unmapped Data > Unmapped Records*, when a user updates the mapping status, the change is reflected instantly on the first page without requiring a refresh. However, when navigating to the next page, the same record initially appears as *Unmapped*, and only after some delay does the status update correctly.

*Steps to Reproduce:*

# Navigate to Data Mapping > Unmapped Data > Unmapped Records
# Update the mapping status of any record
# Observe the updated status on the first page
# Navigate to the next page

*Expected Result:*
The updated mapping status should be consistent and immediately reflected across all pages without delay.

*Actual Result:*
On navigating to another page, the record temporarily shows the old status (Unmapped) and updates after a delay.
