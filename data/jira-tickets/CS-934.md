## Description

* filter does not retain selected values when reopened
* *Steps to Reproduce:*
*# Click the filter icon/button on any list.
*# Apply a filter (e.g., select a year, category, etc.).
*# Close the filter modal.
*# Reopen the filter modal.
* *Expected Result:*
The previously selected filters should remain visible and selected when reopening.
* *Actual Result:*
All selections are reset; filter modal shows empty/default state.
