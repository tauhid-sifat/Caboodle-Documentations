## Description

The Brand Report grid currently has no at-a-glance summary of how reports are distributed across each status column. This feature adds that summary, with the ability to hide cards for columns that aren't useful to a given broker/context. Visibility is controlled globally, not per-user or per-broker.

**Status Columns Covered (7 total):**

1. Submission Status
2. Brand Response
3. Waiting On
4. Focus
5. Action Needed
6. Next Action
7. Review Result

---

**What's Included**

1. **Status Settings (new)**

* A single **global** on/off switch per status column (not per-user, not per-broker), defaulting to **all 7 enabled**.
* `GET api/v1/brandreport/settings/status-settings` — returns the 7 current flags.* Viewable by: Admin, Broker, Broker Sub-user
* `PUT api/v1/brandreport/settings/status-settings` — replaces all 7 flags in a single call (no partial patch).* Access: **Admin only** — Broker/Sub-user receive `403`

2. **Status Analytics (new)**

* `POST api/v1/brandreport/analytics` — returns counts per status column.* Returns **one entry per enabled column only**.
  * Each entry lists **every active option** for that column with its count (including options with 0 matches, so chart legends stay stable).
  * Includes a separate `noOptionSelectedCount` for reports where that column is unset.
  * Returns `{ "columns": [] }` (not an error) when no column is enabled or the settings row is missing.
  * Same access-scoping and `View/BrandReport` permission as the existing list endpoint.

---

**Acceptance Criteria**

* Admin can view and toggle each of the 7 column cards on/off; toggles persist and reflect on next `GET`.
* Broker and Broker Sub-user can view current settings but **cannot** change them (`403` on `PUT`).
* Analytics response only includes cards for **enabled** columns.
* A column with 0 reports for a given option still shows that option with count **0**, not omitted.
* Reports pointing at an **inactive (soft-disabled)** status option are excluded from both the option counts and the "no option selected" count — not double-counted.
* Disabling all columns (or a missing settings row) returns an **empty **`columns`** array**, not an error.
