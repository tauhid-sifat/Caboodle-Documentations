## Description

When an admin invites a user by selecting the **Broker** user type, the invitation email is being generated/sent as **Sub-Broker** instead of Broker. Due to this mismatch, the invited broker user is unable to accept the invitation successfully using the received link.

**Steps to Reproduce:**

1. Login as Admin
2. Go to User Management → Invite User
3. Select user type as **Broker**
4. Send the invitation
5. Open the received invitation email
6. Observe the user type mentioned/generated in the invitation
7. Try accepting the invitation using the provided link

**Actual Result:**

* Invitation email is generated as **Sub-Broker** instead of Broker
* User fails to accept the invitation using the invitation link

**Expected Result:**

* Invitation email should be generated with the correct user type (**Broker**)
* Invited broker user should be able to accept the invitation successfully

**Impact:**
Broker users cannot complete the onboarding/invitation acceptance process due to incorrect role mapping in the invitation flow.
