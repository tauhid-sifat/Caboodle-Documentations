## Description

*Description:*
When there is only one product in the list and it already has an active EDLP, clicking on the *“Add New EDLP”* button opens a modal that stays in a loading state indefinitely.

*Steps to Reproduce:*

# Go to *Trade Spend Sandbox (TSS)*.
# Navigate to the product list where only one product exists.
# Ensure this product already has an existing EDLP event.
# Click on *“Add New EDLP”*.

*Expected Result:*
System should either:

* Show a proper validation message like “EDLP already exists for this product,” *or*
* Allow creation only if multiple products are available.

*Actual Result:*
A new modal appears and remains stuck on a continuous loading state.
