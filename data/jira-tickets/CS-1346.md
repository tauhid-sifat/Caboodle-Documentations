## Description

h3. *Description:*

During promo creation, clicking the *browser back button* redirects to the TSS listing page.
If the user starts creating a promo again with the *same name*, the system resumes from a previous step instead of starting fresh.

h3. *Steps to Reproduce:*

# Go to TSS → Add New Promo
# Enter promo name and proceed to next steps
# Click browser *Back button*
# User is redirected to TSS listing page
# Click *Add New Promo* again
# Enter the *same promo name*

h3. *Expected Result:*

* Browser back should navigate correctly within steps

h3. *Actual Result:*

* System resumes previous step using same promo name
