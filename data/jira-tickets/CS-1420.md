## Description

h3. *Problem Summary*

There are two distinct bugs occurring within the Promotion planning workflow:

# *Sorting Issue:* Event names are not being displayed in chronological order as expected.
# *Data Sync Issue:* Selecting an ad fee does not propagate the values to the "Store Ad Fee" or "Ad & TPR fees" columns under specific navigation paths, but _does_ sync successfully if the user selects the event name directly in the Event Name section.

h3. *Steps to Reproduce*

h4. *Scenario A: Bugged State*

# Log in or impersonate *Broker:* {{SarahNoble@noblesalesint.com}}.
# Navigate to *Brand:* {{Viori}} > *Promotion* > {{SPROUTS 2026 DRAFT KG}}.
# Observe the Event Names list (they are not sorted chronologically).
# Choose an ad fee in the designated field list.
# Check the *Product Summary* section > *Store Ad Fee* column.
#* _Actual Result:_ Value displays as {{0}}.
# Check the *View & Edit Promo Events Details* section > *Ad & TPR fees* column.
#* _Actual Result:_ The column is completely blank.

h4. *Scenario B: Working State (Workaround / Comparison)*

# Within the same promotion, navigate to the *Event Name Section* and explicitly select the same event name.
# Return to look at the *Product Summary* and *View & Edit Promo Events Details* sections.
#* _Actual Result:_ The chosen ad fee value now correctly populates in both sections.

h3. *Expected Behavior*

* *Event Names:* Should automatically sort in chronological order by default.
* *Ad Fees:* Selecting an ad fee from the dropdown/field list should immediately sync and reflect across all corresponding columns (*Store Ad Fee* and *Ad & TPR fees*) regardless of how the user navigates or selects the event.
