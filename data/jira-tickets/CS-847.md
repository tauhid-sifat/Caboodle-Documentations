## Description

* Entering data is tricky – when entering values the only way to make the data stick in the field is to click outside of the field.  This is very problematic.  We need to implement a method where the data sticks by hitting enter. 

* This is particularly problematic when the user enters the last item. If they don’t click outside of the field and don’t’ realize it, then they select NEXT to generate the promotion, the result is that, that last item didn’t get picked up in the promotion.
