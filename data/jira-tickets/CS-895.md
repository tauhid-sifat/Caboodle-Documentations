## Description

 Category not created when uploading file – shows success message but no category is added.

* *Steps to Reproduce:*
*# Go to the "Create Category" section.
*# Upload a valid Excel/CSV file containing category data.
*# Click "Submit".
* *Actual Result:*
** The UI shows "File is pending" initially.
** After submission, a message appears saying "File uploaded successfully".
** However, no category appears in the list.
* *Expected Result:*
** Upon successful file upload and submission, the categories listed in the file should be created and shown in the category list.
