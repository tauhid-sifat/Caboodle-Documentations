## Description

h3. *Description:*

System allows adding multiple Promotion Fees with the *same name*, which creates confusion and may lead to incorrect fee identification.

h3. *Steps to Reproduce:*

# Go to TSS → Open any promo
# Click *Add Promotion Fee*
# Enter a name (e.g., "aaa")
# Save
# Add another Promotion Fee with the *same name "aaa"*

h3. *Expected Result:*

* Promotion Fee name should be *unique*
* System should show validation message:
** _“Fee name already exists”_

h3. *Actual Result:*

* Duplicate names are allowed and displayed in the list
