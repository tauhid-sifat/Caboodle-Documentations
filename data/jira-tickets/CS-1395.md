## Description

Users can add/update a phone number in their profile, but the phone number field currently has no validation. As a result, invalid or incorrectly formatted phone numbers can be saved successfully.

*Steps to Reproduce:*

# Login to the application
# Go to Profile Settings/Edit Profile
# Enter an invalid phone number (e.g., alphabets, special characters, incorrect length, etc.)
# Save the profile

*Actual Result:*
Invalid phone numbers are accepted and saved successfully.

*Expected Result:*
The system should validate the phone number format and prevent invalid inputs from being saved. Proper validation/error messages should be shown to the user.

*Impact:*
Invalid contact information can be stored in the system, leading to data inconsistency and communication issues.
