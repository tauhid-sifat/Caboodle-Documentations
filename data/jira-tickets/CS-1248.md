## Description

Implement a feature that allows a user to add a Lump Sum Amount to a Trade Spend without associating it with a promotion. The lump sum amount would be incorporated into the calculations and added to the Ad/TPR fee to be included in those cost but could be entered without a promotion. you can add it a an item for the Even Summary but there would not be any Promo Revenue listed. Only the amount of the lump sum. 

!image-20260413-201344.png|width=504,alt="image-20260413-201344.png"!

Example User wants to add an *Ad Fee for $1000* but they don’t want it associated with a promo. The Click the Add Option,  Select a new option called Add Lump Sum (No Promo). 

They enter the Event Name “Mother’s Day Ad” and enter $1000 in a pop-out field. It would add to the total calculation for Trade Spend but not add addition lift to any cases calculation. 

Example: 

Listing called Mother’s Day Ad 

Promo Rev would be 0 

Trade Spend = 0

Store Ads/TPR Fee = $1000

Total Spend = $1000

Total Promo cases = 0

The $1000 ad fee would be included in the total spend calculation (treated like the other ad fees) it’s just not associated with any promotion.
