## Description

When applying a **Start Date – End Date** filter on the Brand Report (Review section), the report does not include data from the **selected end date**. Data for the last day of the selected range is silently excluded from the results.

**Steps to Reproduce:**

1. Go to Brand Report → Review.
2. Apply a date filter with a range, e.g., **1st to 5th** of the month.
3. Check the resulting data set.
4. Compare against actual data present for the 5th (end date).

**Actual Behavior:**

* Report shows data only from **1st to 4th**.
* Data belonging to the **5th (end date)** is missing from the results.

**Expected Behavior:**

* Report should include data for the **entire selected range, inclusive of both start and end dates**.
* For a 1st–5th filter, data from **1st, 2nd, 3rd, 4th, and 5th** should all be included.

**Additional Fixation: **
i) Please fix the UI for **Next Action Due Date. **The full date range is not visible cleary 
ii) Fix the **Arrow **Sign
