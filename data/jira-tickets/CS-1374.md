## Description

h3. *Steps to Reproduce:*

# Go to *TSS Promo (Step 4/5 or Event Details)*
# Click *Add SKU*
# Select:
#* Banner → AGSVT (example)
#* Product → any product
#* Event → e.g., *Q-123*
# Click *Submit*
# Observe top-right alert message

----

h3. *Actual Result:*

* Error toast appears:
❌ _“No events under this Promotion! Please add events and try again!”_
* Even though:
** Event dropdown has value selected
** Event exists in list (visible in background table)

----

h3. *Expected Result:*

* No error should be shown when a valid event is selected
* SKU should be successfully added to the selected event
