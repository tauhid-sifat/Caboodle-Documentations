## Description

In the "Category Review Notification from Your Broker" email, clicking the "View Brand Report" button redirects the user to the Category Review page instead of the Brand Report page. This mismatch between the button's label and its actual destination causes confusion for brand owners trying to view their report.

*Steps to Reproduce:*

# Trigger a Category Review notification by sending a review to a selected brand owner.
# Open the received "Category Review Notification from Your Broker" email.
# Click the "View Brand Report" button.
# Observe that the user is redirected to the Category Review page rather than the Brand Report page.

*Expected Behavior:*
Clicking "View Brand Report" should navigate the user directly to the relevant Brand Report page for the corresponding brand/category (e.g., Ahold Delhaize USA · Italian).

*Actual Behavior:*
The button redirects to the Category Review page instead.
