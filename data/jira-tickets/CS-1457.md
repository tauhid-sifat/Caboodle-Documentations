## Description

After a successful bulk upload, the newly added records do not appear in the Category Review section automatically. The user has to manually refresh the page before the uploaded data becomes visible, even though the upload response indicates success.

**Steps to Reproduce**

1. Upload a category review file (or add records via the upload flow).
2. Receive success confirmation.
3. Check the Category Review list/table without refreshing the page.
4. Manually refresh the page.

**Expected Behavior**

* Once an upload succeeds, the Category Review view should update automatically (e.g., via re-fetch, state update, or live refresh) to reflect the newly added records — no manual refresh required.

**Actual Behavior**

* The view remains stale after a successful upload.
* Records only appear after the user manually refreshes the page.
