## Description

Implement **multi-tenancy support** for the Brokers module to ensure data isolation and proper access control across different tenants. This will allow multiple organizations or clients to use the system simultaneously while keeping their broker data separate and secure.

### Scope of Work:

* Update database schema and queries to support tenant-specific broker data.
* Implement tenant identification and filtering throughout the Brokers module.
* Ensure role-based access and permissions respect tenant boundaries.
* Update existing APIs, services, and UI components to handle multi-tenant context.
* Test data isolation, access control, and edge cases to prevent cross-tenant access.

### Acceptance Criteria:

* Broker data is isolated per tenant.
* Only authorized users can access brokers within their tenant.
* Multi-tenancy logic is integrated across APIs and UI.
* Tests validate tenant separation and correct behavior.
