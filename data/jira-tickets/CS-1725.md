## Description

Currently the card lists 7 separate monthly buckets; this needs to be consolidated into 4 buckets with updated naming, as detailed below.

**Bucket Consolidation**

| Current | New |
| Past Due | **Current** |
| 1 Month | Next 30 Days |
| 2 Months + 3 Months | Combined → 60-90 Days |
| 4 Months + 5 Months + 6 Months | Combined → 4-6 Months |

**Confirmed Date Range Logic (relative to today):**

| Bucket | Date Range |
| Current | Today + Any Review Start Date on or before today (no lower limit) |
| Next 30 Days | Today+1 through today+30 |
| 60-90 Days | Today+31 through today+90 |
| 4-6 Months | Today+91 onward (no upper limit) |

**Acceptance Criteria (updated):**

* **Current:** Review Start Date is any date on or before today (no lower bound), including today itself.
* **Next 30 Days:** Review Start Date falls between today+1 and today+30 (inclusive).
* **60-90 Days:** Review Start Date falls between today+31 and today+90 (inclusive).
* **4-6 Months:** Review Start Date falls on or after today+91 (no upper bound).
* Bucket ranges are mutually exclusive — no date falls into more than one bucket.
* Clicking each bucket filters the table correctly based on these exact ranges.
* Clear button resets the filter and restores full unfiltered view.
