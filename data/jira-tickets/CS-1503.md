## Description

Search bar and filters in Retailer APL return extra/unrelated values in addition to the actual search term or filter criteria — results are not limited to what matches the search/filter input.

**Steps to Reproduce:**

1. Go to Retailer APL
2. Enter a search term in the search bar
3. Observe: results include values that don't match the search term
4. Apply a filter
5. Observe: filtered results include values that don't match the selected filter criteria

**Expected Behavior:** Search should return only results matching the entered term. Filters should return only results matching the selected criteria — no extra/unrelated values included.

**Actual Behavior:** Both search and filters return additional values beyond what matches the actual search/filter input.

**Impact:** Users can't trust search or filter results in Retailer APL — makes it difficult to locate the correct entries, especially as data volume grows.
