## Description

**Issue 1: Submit Button Not Disabled After File Import**

**Steps to Reproduce:**

1. Go to Admin → Store List → Import Store.
2. Upload/import a file.
3. Observe the **Submit** button state after the file has been successfully uploaded/processed.

**Actual Behavior:**

* Submit button remains **enabled** even after the file has already been imported.

**Expected Behavior:**

* Once a file has been successfully imported, the **Submit** button should be **disabled** to prevent duplicate/accidental re-submission of the same import.

---

**Issue 2: Cancel Button Not Working**

**Steps to Reproduce:**

1. Go to Admin → Store List → Import Store.
2. Open the Import Store modal (with or without a file uploaded).
3. Click **Cancel**.

**Actual Behavior:**

* Clicking Cancel does **not** perform the expected action — *(please confirm exact behavior: does nothing happen at all, does the modal fail to close, or does it throw an error?)*

**Expected Behavior:**

* Clicking Cancel should close the Import Store modal and discard any unsaved/uploaded file selection, returning the user to the previous state without submitting.
