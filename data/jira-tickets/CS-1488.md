## Description

The manual entry or existing entry edit form does not accept **0** as a value for **Wholesale Case Cost** and **Wholesale Unit Cost** — this applies both when adding a new entry and when editing an existing one. However, the CSV upload flow **does** accept 0 for these same fields, creating inconsistent validation depending on entry method.

**Steps to Reproduce:**

1. Go to Distributor APL
2. Try entering **0** in Wholesale Case Cost or Wholesale Unit Cost on the manual form (both Add and Edit) — rejected
3. Upload a CSV with **0** in those same fields — accepted

**Expected Behavior:** Validation rule for 0 in Wholesale Case Cost / Wholesale Unit Cost should be consistent across both entry methods — either both accept it, or both reject it, per correct business logic.

**Actual Behavior:** Manual entry blocks 0; CSV upload allows it — inconsistent data validation.
