## Description

h3. Steps to Reproduce:

# Navigate to TSS Promotion
# Open *Add Promotion Fee (lump sum)*
# Select a specific banner from the *Banners* dropdown
# Open the *Products* dropdown
# Observe the listed products

----

h3. Actual Result:

* Products associated with other banners are visible in the dropdown
* User can potentially select mismatched products

----

h3. Expected Result:

* Products dropdown should display only products associated with the selected banner
* Cross-banner product visibility should not occur
