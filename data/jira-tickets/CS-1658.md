## Description

For the **Jade Street** broker, in the **Brand Retail Item Status** section, two issues are occurring:

1. Filters and the search bar are not functioning correctly.
2. Pagination is displaying **more than 10 rows per page**, even though page size is set to 10 and the **backend is correctly sending only 10 records per page**.

**Issue 1: Filters & Search Not Working**

**Steps to Reproduce:**

1. Go to Jade Street broker → Brand Retail Item Status.
2. Apply a filters.
3. Try searching using the search bar.

**Actual Behavior:**

* Filters do not narrow down results as expected.
* Search bar does not return correct/matching results.

**Expected Behavior:**

* Filters should correctly narrow the list based on selected criteria.
* Search bar should return results matching the search term.

**Issue 2: Pagination Showing More Than 10 Rows Despite Page Size = 10**

**Steps to Reproduce:**

1. Go to Jade Street broker → Brand Retail Item Status.
2. Observe the row count per page.
3. Confirm via network/API logs that BE is sending exactly 10 records per page.

**Actual Behavior:**

* UI displays **more than 10 rows** on a page, even though:* Page size is configured as 10.
  * Backend response confirms only 10 records are sent per page.

**Expected Behavior:**

* UI should display exactly 10 rows per page, matching both the configured page size and the backend response.
