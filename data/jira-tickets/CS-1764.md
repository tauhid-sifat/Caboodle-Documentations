## Description

## Summary

On the Trade Spend Sandbox promo creation **Products** step, the **Add Product Pricing** modal (opened for a product showing "No Pricing Found") pre-fills **Distributors** and **Products** only the first time it opens. If the user closes the modal and opens it again, those two fields are **empty**. They are read-only (static) fields, so the user can't select a value and can't add the price. Only a manual page refresh fixes it.

## Environment

Staging, Promotional Planning → Trade Spend Sandbox → Add New Promo

## Steps to reproduce

1. Navigate to Promotional Planning → Trade Spend Sandbox → **Add New Promo**.
2. Select a Retailer and Banner.
3. On the **Products** step, find a product showing **"No Pricing Found"**.
4. Click to set the price for that product.
5. The **Add Product Pricing** modal opens with Distributors (e.g. KeHE DELIVERED) and Products (e.g. BE Bubbies Mochi Ice Cream - Churro) already selected.
6. Close the modal (X) without creating a price.
7. Open the modal again for the same product, or for another unpriced product.

## Actual result

* **Distributors** and/or **Products** are empty on the second open.
* The fields are static, so the user can't select a value.
* The price can't be added. Create either can't be used or fails validation.
* A manual page refresh is the only workaround.

## Expected result

* Every time the modal opens, Distributors and Products are pre-filled for the product it was opened from.
* Opening it for a different product pre-fills that product's values, not the previous one's.
* Closing or cancelling resets the entered values (Per Unit Price, Valid From) without clearing the pre-filled context.
* The price can be created without refreshing the page.

## Suspected cause

The modal's state is cleared on close but not re-initialised on re-open. Pre-fill probably happens only on first mount.

## Also check

* Open, close and re-open several times, and across different products.
* Re-open after a successful Create.
* The same modal from the Simple Promotion "Set price" link. **CS-1745** (Add Price returns 400 "Please select at least one product") may share the same root cause, if ProductIDs are empty after a re-open.
