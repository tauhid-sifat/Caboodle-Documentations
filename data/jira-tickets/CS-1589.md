## Description

# Admin | Admin Controls | Control Dropdown Options for Broker Category Review Brand Report

AAC2 | New Requirement | User Story | Priority: TBD | Status: New

## User Story

As an Admin user,

I want to control the dropdown options available in the Broker Category Review Brand Report,

So that users select from a managed, consistent set of options (not hard-coded or stale values).

## Description

Provide an Admin Control to manage the dropdown option lists used by the Broker Category Review Brand Report. Admins should be able to add/remove/reorder the choices presented in those dropdowns, so the report's filters/selectors stay accurate.

## Acceptance Criteria

### Scenario 1: Admin Edits Dropdown Options

* Given** an Admin with permission

* When** they open the Admin Control for the Brand Report dropdowns

* Then** they can add, remove, or reorder the available options

* And** the updated options appear in the Broker Category Review Brand Report

### Scenario 2: Options Scoped Correctly

* Given** options are changed

* When** a Broker user opens the Brand Report

* Then** only the managed options are presented (no orphaned/stale entries)
