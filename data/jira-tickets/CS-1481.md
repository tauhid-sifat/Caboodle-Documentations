## Description

In the Market Overview section, using the *Presentation Date Range* filter causes a client-side application crash when the user clicks into the date field a second time after already selecting a date. Also Needs to update the filters based on the column name.

*Steps to Reproduce:*

# Go to Market Overview ({{/market-overview}})
# Open the Presentation Date Range filter
# Select a date
# Click into the date field again
# The application crashes to a blank white page with: _"Application error: a client-side exception has occurred (see the browser console for more information)."_

*Expected Behavior:* 

* Re-clicking the date field should let the user adjust the selected date (or simply reopen the picker) without crashing the page.
* Changed all the filters and added  new filters, which will be a reflection of table columns 

*Actual Behavior:* 

* Full client-side crash, blank page; user has to reload/navigate away to recover.
* Current filters are not valid
