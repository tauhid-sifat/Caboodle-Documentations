## Description

*Steps to Reproduce:*

# Open the Add Banner modal.
# Search for a term.
# Close the modal.
# Reopen the modal.
*Expected Behavior:*
The search field should reset (be empty) when the modal is reopened.
*Actual Behavior:*
Previous search value is still present in the input field.
