## Description

**Steps to Reproduce:**

1. Open the Add Banner modal.
2. Search for a term.
3. Close the modal.
4. Reopen the modal.
**Expected Behavior:**
The search field should reset (be empty) when the modal is reopened.
**Actual Behavior:**
Previous search value is still present in the input field.
