## Description

h3. Bug 1: Category is Missing in Price ListSteps to Reproduce

# Login to the Admin Portal.
# Navigate to *CRM Data Upload → Price Lists*.
# Observe the *Category* column.

----

h3. Actual Result

* The *Category* column displays {{—}} instead of the associated category name.

----

h3. Expected Result

* The Category column should display the correct category name for each product.

h2. Bug 2: Case Cost Filter Returns Incorrect Results

*Title:*
*Price List - Case Cost range filter does not filter records accurately*



h3. Steps to Reproduce

# Login to the Admin Portal.
# Navigate to *CRM Data Upload → Price Lists*.
# Open the *Filter* panel.
# Enter:
#* *Min Case Cost:* {{2}}
#* *Max Case Cost:* {{3}}
# Apply the filter.

----

h3. Actual Result

* Records with case costs outside the range (e.g., values not between *2* and *3*) are returned.
* The filter does not correctly enforce the specified range.

----

h3. Expected Result

* Only records with *Case Cost ≥ 2 and ≤ 3* should be displayed.
* All records outside the specified range should be excluded.
