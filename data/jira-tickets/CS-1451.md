## Description

### Steps to Reproduce

1. Login to the Admin Portal.
2. Navigate to **CRM Data Upload → Stores**.
3. Open the **Import Stores** modal.
4. Select a file (or leave it empty).
5. Click the **Cancel** button.

---

### Actual Result

* Clicking **Cancel** has no effect.
* The Import Stores modal remains open.

---

### Expected Result

* Clicking **Cancel** should immediately close the Import Stores modal without performing any action.
