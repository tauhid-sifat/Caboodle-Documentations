## Description

h3. Steps to Reproduce

# Login to the Admin Portal.
# Navigate to *CRM Data Upload → Stores*.
# Open the *Import Stores* modal.
# Select a file (or leave it empty).
# Click the *Cancel* button.

----

h3. Actual Result

* Clicking *Cancel* has no effect.
* The Import Stores modal remains open.

----

h3. Expected Result

* Clicking *Cancel* should immediately close the Import Stores modal without performing any action.
