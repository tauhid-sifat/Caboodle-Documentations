## Description

h3. *Description:*

In the Promotion Fee modal, when a specific *banner is selected*, the *event dropdown shows events from other banners as well*, causing mismatch.

h3. *Steps to Reproduce:*

# Go to TSS → Open any promo
# Click *Add Promotion Fee (prime)*
# Select a specific *Banner (e.g., AGSVT)*
# Open *Events dropdown*

h3. *Expected Result:*

* Only events belonging to the *selected banner* should be shown

h3. *Actual Result:*

* Events from *other banners are also visible* (e.g., Denver DIV - Safeway)
