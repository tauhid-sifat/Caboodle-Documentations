## Description

**Issues Identified:**

1. **EDLP Promo – Missing Price*** For one SKU in an EDLP promotion, the price is not displayed on the TSS details page.
2. **Normal Promo – Everyday Allowance Showing 0*** For one SKU in a normal promotion, Everyday Allowance is showing as 0, even though a value was provided during promo creation.
3. **Incorrect Total Spend Calculation*** The Total Spend value is incorrect and does not match the sum of individual spend components.
4. **Alert Message UI Issue (EDLP Promo)*** While adding an EDLP promo, the alert/validation message appears behind the modal, making it difficult to notice.
5. **TPR Fee Breakdown Rule Issue*** Applying TPR fee breakdown rules across all banners is not accurate.
* Rounding logic is causing calculation mismatches and inconsistencies.

**Expected Result:**

* Price and Everyday Allowance should display correctly for all SKUs.
* Total Spend should calculate accurately based on all components.
* Alert messages should appear above the modal and be clearly visible.
* TPR fee breakdown rules should apply consistently and follow correct rounding logic across all banners.

**Actual Result:**

* Missing or incorrect values are displayed for certain SKUs.
* Total Spend is miscalculated.
* Alert messages are hidden behind the modal.
* TPR fee calculations vary due to rounding issues.
