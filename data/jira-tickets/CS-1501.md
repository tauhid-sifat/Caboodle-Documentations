## Description

Filters in Promotional Management do not narrow down based on other filters already applied — same cascading filter issue previously identified in *Ticket 17* (platform-wide) and *Ticket 20* (Promotional Management → Notes).

*Steps to Reproduce:*

# Go to Promotional Management
# Select a value in one filter
# Check the options in another filter
# Observe: options remain static and don't narrow down based on the first filter's selection

*Expected Behavior:* Selecting a value in one filter should dynamically narrow the available options in other filters to only valid combinations, consistent with the cascading filter behavior requested in Ticket 17.

*Actual Behavior:* Filters operate independently — no cascading/dependency behavior.
