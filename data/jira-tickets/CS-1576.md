## Description

On the Add Product screen, the "Category Name" field shows a loading indicator on initial page load (before any Brand is selected). It correctly clears once a Brand Name is selected. However, if the user then removes/deselects the Brand Name, the loading indicator reappears incorrectly.

**Steps to Reproduce:**

1. Go to CRM – Product Specs > Add Product.
2. Observe "Category Name" field shows a loading indicator on initial load (no Brand selected).
3. Select a Brand Name — loading indicator disappears, category options populate.
4. Remove/deselect the Brand Name.
5. Observe "Category Name" field shows the loading indicator again.

**Expected Behavior:**

* When no Brand Name is selected, the Category Name field should show a **dropdown icon** and remain **disabled** — no loading indicator should appear.
* The loading indicator should only appear while actively fetching categories after a Brand is selected.

**Actual Behavior:**
Loading indicator incorrectly displays both on initial load and after Brand Name is removed.
