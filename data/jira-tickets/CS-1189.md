## Description

Refactor the existing **Promotion Module** to be more **generic and reusable** across different use cases. The goal is to eliminate hard-coded logic and module-specific dependencies, enabling support for multiple product types, business rules, and promotion structures with minimal customization.

### Scope of Work:

* Abstract promotion logic to handle various product categories and promotion types.
* Introduce configuration-driven or template-based structures for defining promotions.
* Ensure the module supports extensibility for future requirements.
* Refactor existing code to reduce duplication and dependency on specific modules.
* Ensure backward compatibility for existing promotions.
