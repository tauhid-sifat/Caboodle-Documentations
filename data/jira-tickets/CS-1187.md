## Description

If Multiple events are selected in Step 4 Metrics, that fee is split among all items in all events rather than for each item within an event. For example if there are 4 items in 4 events, and the user enters $1,000 in Ad Fees, the expected result is $4,000 for all 4 events ($250 each item (4) x4 events). 

Currently, each item is assigned $62.50, resulting in a total Ad fee of $1,000 for all 4 events. It should divide the Ad fee by Item for each event individually.
