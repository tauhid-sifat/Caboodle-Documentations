## Description

Currently, when a user tries to accept an invitation that is no longer valid, no proper error message is shown. We need to detect the invalid state and show the user a clear, specific message for each case:

- **Cancelled** — This invitation has been cancelled.

- **Expired** — This invitation link has expired. Please request a new invitation.

- **Already registered** — This invitation has already been accepted. Try logging in instead.
