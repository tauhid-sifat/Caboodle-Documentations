## Description

Currently, the system allows a user to create a **Promo Event** with a start and end date that span **across different years** (e.g., Dec 2026 – Jan 2027). Per business rule, a promo event's date range must stay **within the same year** — it can span different **months**, but **not different years**.

**Steps to Reproduce:**

1. Go to Promo Event creation (Promotional Planning → TSS).
2. Set a start date and end date where the range crosses into a different year (e.g., Start: 15-Dec-2026, End: 15-Jan-2027).
3. Attempt to save/submit the promo event.

**Actual Behavior:**

* System allows the promo event to be created/saved with a date range spanning two different years.

**Expected Behavior:**

* System should **validate** that the promo event's start date and end date fall within the **same calendar year**.
* Different **months within the same year** should be allowed (e.g., Start: 15-Nov-2026, End: 15-Jan-... — wait, only valid if End is still 2026, e.g., Nov–Dec 2026).
* If the selected range crosses into a different year, the system should **block submission** and show a **validation error message**.
