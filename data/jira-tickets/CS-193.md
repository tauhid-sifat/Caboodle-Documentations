## Description

An admin panel will be provided for Administrator users, offering the following functionalities:

* Creation of new brand accounts
* Creation of unlimited user accounts under a brand account
* Creation of new broker accounts
* Creation of unlimited user accounts under a broker account
* Editing, deactivating, reactivating, or deleting any database record, including brand accounts, broker accounts, user accounts, and other module-related data records.
* Generation of listing reports for any module within the system. In other words, from the Admin Panel, an admin will be able to see the lists of everything, for all modules, for all brands and brokers.
