## Description

When the KeHE POD report is pulled into the system, it should pull in only Current Yrar QTY. Currently, it’s pulling in Prior Year QTY. When Prior Year QTY is pulled in, it create errors in the reporting. 

Here is an example:

Broker Noble Sales>Brand Ener-Life> Report > KeHE > Product > ELECTROLYTE BX LMN LIME

* Report KEHE: Reporting 0 sales & 0 cases but it’s showing store counts which is confusing to the user 
* When I exported the data from the KEHE Report, I discovered that it’s pulling in Prior Year QTY Data, which is not required on the template, which Current Year QTY is required. 

NOTE: This is also doing the same thing in the Distributor Report. > It could be a Data Mapping Issue in which we should not be pulling in data with 0 Current Year QTY.
