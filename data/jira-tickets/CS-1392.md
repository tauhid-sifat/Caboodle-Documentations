## Description

s an Admin, I want to invite users, resend invitations, accept user requests, and manage enrolled users so that I can efficiently control user onboarding and access management.

h1. Features

* Invite new users via email
* Resend pending invitations
* Accept invitation and complete account setup
* Activate/Deactivate/Suspend/Delete users
* Manage user roles and permissions
* Search and filter users
* Handle expired invitations

h1. Definition of Done

* Feature implemented
* APIs tested
* Email flow verified
* QA completed
* No critical bugs remaining
