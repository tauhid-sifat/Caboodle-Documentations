## Description

in the filter section, selecting the Grocery category returns no results, even though there are SKUs like “onion” under that category. Selecting that SKU individually also shows no data.



*Steps to Reproduce:*

# Go to the Trade Spend Sandbox page.
# Open the filter panel.
# Select the category _Grocery_ and apply the filter.
# Observe that no results appear.
# Alternatively, select the SKU _Onion_ (which belongs to Grocery) and apply the filter.
# Observe that no data is returned.
