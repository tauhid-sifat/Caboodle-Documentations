## Description

*Description:*
On smaller screens/laptop resolutions, the "Total Cases" column in Trade Spend Sandbox and Approved Promotions displays/renders incorrectly (reported by user working remotely on a smaller screen). Many broker sub-users work on laptops and will likely hit this.

*Steps to Reproduce:*

# Open Trade Spend Sandbox (or Approved Promotions) on a smaller/laptop screen resolution
# Observe the "Total Cases" column

*Expected Behavior:* Column should be responsive — truncate gracefully, allow horizontal scroll, or resize proportionally so data isn't cut off/unreadable on smaller viewports.

*Actual Behavior:* Column breaks/misdisplays at smaller screen widths.
