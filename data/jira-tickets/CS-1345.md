## Description

h3. *Description:*

While creating a promo in TSS, the *Store Count field accepts negative values*, which should not be allowed as store count cannot be negative.

h3. *Steps to Reproduce:*

# Go to TSS → Add New Promo
# Navigate to Step 2 (Product configuration)
# Enter a negative value in *Store Count* field (e.g., -5)

h3. *Expected Result:*

* System should *restrict negative input*
* Validation message should be shown
* Field should accept only positive integers (≥ 0 or ≥ 1 based on business rule)

h3. *Actual Result:*

* Negative values are accepted without validation
