## Description

Distribution Center is a required field when creating a Market Activity, but the Distribution Center list is empty. Users can't manually enter a value either, so it's impossible to create any Activity.
Also, the store list associated with Market Activities is empty

*Steps to Reproduce:*

# Go to Broker Market Activities
# Attempt to create a new Activity
# Attempt to select a store — list is empty
# Try to select a Distribution Center — list is empty
# Try typing a value manually — not permitted


*Expected Behavior:* 

* Store list should populate with the relevant stores tied to the broker/banner/distribution center.
* Distribution Center dropdown should be populated (or the field should allow manual entry if no list exists), so users can complete and save an Activity.

*Actual Behavior:*

* No stores are listed.
* Activity creation is completely blocked.

*Impact:* Brokers cannot log any Market Activities — full workflow blocker now that brokers are live in the system.
