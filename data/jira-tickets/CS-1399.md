## Description

In User Management → Invited Users section, the filter dropdown/list contains *Name* and *Status* columns, although these columns are not available in the Invited Users table.

At the same time, relevant columns such as *User Type* and *Invited By* are missing from the filter options.

*Steps to Reproduce:*

# Go to User Management → Invited Users
# Open the filter column list/dropdown
# Observe the available filter columns

*Actual Result:*

* “Name” and “Status” appear in the filter list despite not existing in the table
* “User Type” and “Invited By” are missing from the filter options

*Expected Result:*

* Remove “Name” and “Status” from the filter list
* Add “User Type” and “Invited By” as filter options

*Impact:*
The filter configuration is inconsistent with the actual table columns, which may confuse users and reduce usability.
