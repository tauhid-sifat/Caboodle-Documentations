## Description

In the User Management > Invited Users list, the *User Type* field is displaying as *“Unknown”* for invited users instead of showing the actual assigned role/user type.

*Steps to Reproduce:*

# Go to User Management
# Invite a new user with any user type/role
# Open the Invited Users list
# Observe the User Type column

*Actual Result:*
User Type is displayed as *“Unknown”*.

*Expected Result:*
The correct assigned user type/role should be displayed for each invited user.

*Impact:*
Admins cannot identify the invited user roles properly from the invited users list.
