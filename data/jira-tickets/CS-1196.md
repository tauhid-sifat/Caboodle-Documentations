## Description

Can we create a coupon Option? User would enter the Banner, dates, Items, estimated redemption rate and value of coupon and the Lump Sum Fee for adding the Coupon. 

The Estimated value of the coupon would be based on how many Units are projected to sell during the dates selected for the coupon then apply the redemption rate. For example: User Enters 

# Nugget Market 
# $1 off coupon Value 
# 20% Redemption 
# $500 Coupon Fee
# 5 items are selected 

If 80 cases (8 units per case = 640 units) are projected to sell between Jan 1 & Jan 15, and a redemption rate is entered at 20%. It would calculate 128 units * $1 = $128 redemption fee. Plus a a $500 fee across all the items in selected ($100 each)
