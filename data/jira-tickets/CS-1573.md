## Description

**Requirements:**

| Section | Current | Required Change |
| CRM – Banners | "Retailer Name" write (free-text) filter | Hide write filter; keep "Retailer list" filter; rename to **"Retailer Name"** |
| CRM – Banner SKUs | "SKU Name" write (free-text) filter | Hide write filter; keep "Product list" filter; rename to **"SKU Name"** |
| CRM – Categories | "Brand Name" write (free-text) filter | Hide write filter; keep "Brand list" filter; rename to **"Brand Name"** |
| CRM – Price Lists | "Distributor" column/filter | Rename to **"Distributor MOD"** (both column and filter) |
| CRM – Regions | "Address" column | Rename to **"State"**; add as a filter |
| CRM – Stores | Column/filter names | Update to **"Retailer Name"** and **"Banner Name"** (column + filter) |
| CRM – Data Upload | All filters/columns | Ensure filter names and column names match exactly; ensure consistent capitalization across all filters and columns |
| CRM – Product Specs | | **Product Details** and **Dimensions & Weight** header present in the corner of the Add Product modal | Keep the headers in the middle point of the modal |

```
General Rule (applies across all CRM sections): Column names must match their corresponding filter names exactly (naming + capitalization).
```


**Acceptance Criteria:**

* All listed write/free-text filters replaced with list-based filters, correctly renamed.
* Column and filter names match exactly in each section.
* Capitalization is consistent across all filters and columns in CRM Data Upload (and ideally CRM-wide).
* Address → State rename applied to both column and filter in Regions.
* Distributor → Distributor MOD rename applied to both column and filter in Price Lists.
