## Description

## Background

Client feedback (Constance, Sep 29): users want to turn an existing Simple Promo into a Trade Spend promotion without re-entering everything through the Trade Spend Stepper from scratch. The idea is to reuse the details already in the Simple Promo and only enter the extra Trade Spend inputs (store count, velocity, event lift).

## Goal

Provide a **Convert to Trade Spend** action on a Simple Promo that carries over existing data and asks only for the additional Trade Spend inputs.

## Requirements

1. Add a **Convert to Trade Spend** action on an existing Simple Promo entry.
2. On conversion, open the Trade Spend flow (Stepper) **pre-filled** with the Simple Promo's data:* Brand, retailer/banner, event type
* Start and end dates
* Items (SKUs/UPCs)
* Promo price / discount and any other matching fields
3. The user enters the **additional Trade Spend inputs**, such as:* Store count
* Velocity
* Event lift
* Any other required Trade Spend fields
4. The user can **review and edit** the pre-filled values before saving.
5. Trade Spend calculations (e.g. projected volume, spend, ROI) run on the combined data, the same way as for a Trade Spend created directly.
6. **What happens to the original Simple Promo:** define whether it is replaced by the Trade Spend promotion or kept and linked to it. Either way, the promotion must **not appear twice** in the Promotional Calendar, reports, or exports.
7. Keep a reference showing the Trade Spend was converted from a Simple Promo (audit: converted by, converted date).
8. If the user cancels mid-conversion, the original Simple Promo stays unchanged.

## Acceptance Criteria

* A user can convert an existing Simple Promo into a Trade Spend promotion.
* Simple Promo fields are pre-filled in the Trade Spend flow.
* The user only has to enter the additional Trade Spend inputs (store count, velocity, event lift, etc.).
* Trade Spend calculations work the same as for a directly created Trade Spend.
* The promotion is not duplicated in the calendar, reports, or exports after conversion.
* Cancelling the conversion leaves the Simple Promo unchanged.
* The conversion is recorded with user and timestamp.
