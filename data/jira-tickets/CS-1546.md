## Description

When sending a Category Review notification to brand owners, the recipient list currently displays sub-users in addition to owners. Only the owner list should be shown/selectable as recipients; sub-users should not appear in this list.

**Steps to Reproduce:**

1. Go to Category Review section.
2. Select a category and proceed to send the review.
3. Open the recipient selection list.
4. Observe that sub-users are listed alongside brand owners.

**Expected Behavior:**
The recipient list should display only brand owners. Sub-users should be excluded from this list entirely.

**Actual Behavior:**
Sub-users are showing up in the recipient list along with owners, allowing them to be incorrectly selected/notified.
