## Description

In the Broker Dashboard's **Retailer APL** section, there is currently no way for users to export the APL list. Add an export feature that allows users to download the currently displayed APL list as a CSV file.

**Problem**

* Users viewing the Retailer APL list have no way to extract the data for offline use, sharing, or further analysis in tools like Excel.
* Other report sections (e.g., Brand Retail Reports) already support CSV export, so this is a gap in feature parity within the platform.

**Proposed Solution**

* Add an **Export** button/icon in the Retailer APL section (Broker Dashboard).
* Clicking Export generates and downloads a CSV file containing the APL list data currently visible to the user.
* Exported CSV should reflect any active filters applied by the user at the time of export (i.e., export the filtered/current view, not the full unfiltered dataset — to be confirmed with product).
* Follow the naming convention agreed in the earlier naming-consistency ticket, so the exported file name aligns with the unified feature name (avoiding a repeat of the "APL Report" vs. "Retail APL" mismatch).
* Also added option to export current page or all data

**Acceptance Criteria**

* Export button/icon added to the Retailer APL section in Broker Dashboard
* Clicking Export downloads a CSV file containing the APL list data
* Exported CSV columns match what's displayed in the table (column names, order, and formatting)
* Exported data respects currently applied filters (confirm expected behavior with product/UX)
* Exported file name follows the standardized naming convention (per naming-consistency ticket)
* Large datasets export successfully without timeout or performance issues
* QA verification: exported CSV opens correctly in Excel/Google Sheets with no formatting/encoding issues (e.g., special characters, commas within fields)
