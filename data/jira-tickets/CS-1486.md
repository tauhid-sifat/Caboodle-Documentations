## Description

When a user has already added a comment to a row and clicks Edit again to add more to it, the previously added comment does not persist/show in the edit field — it appears empty instead of pre-filled with the existing comment. And after adding the new comment it replace the previous comment.

*Steps to Reproduce:*

# Go to Market Overview
# Add a comment to any row and save
# Click Edit on that same comment again to add more text
# *Observe the edit field — previous comment text is missing*
# *Add a new comment - save the comment*
# *Click on the view button after saving*

*Expected Behavior:* 

* Clicking Edit on an existing comment should load the previously saved text into the edit field, so the user can add to it rather than starting over.
* New Comment will be add with the previous comment.

*Actual Behavior:* 

* Edit field comes up empty/doesn't retain prior comment.
* Previous commet is replaced with the new comment
