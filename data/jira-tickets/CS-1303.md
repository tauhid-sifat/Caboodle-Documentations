## Description

User feedback tells us that in order to enter the information in the fields in the pop-out box they need to see behind the box or have the ability to move it and minimize the box so they don’t lose the information they enter and have to start all over.  

Expected result is the ability for the user to move and minimize/re-size  this box so they can manipulate and view the screen behind it and the data they entered in the fields remain there until user selected “Submit” 

Think of a Zoom Call where the user can move/resize the video box so they can see their screen behind it.
