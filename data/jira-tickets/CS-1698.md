## Description

Following the terminology update from "Submission Due Date" → **"Review Start Date"** and "Review Date" → **"Review End Date"** (as applied to Add Log, KPI Card, and Filters), the same update must be applied to the **File Upload section** — including validation logic, error messages, and the sample file template. Additionally, add a **mandatory field indicator (icon)** for all mandatory columns, along with corresponding backend/source validation.

**Requirements:**

1. **Update Validation with Latest Titles**

* Update all validation logic/error messages in the File Upload flow that currently reference "Submission Due Date" / "Review Date" to use the new titles: **"Review Start Date"** and **"Review End Date"**.
* Ensure error messages shown to users during upload (e.g., wrong header, missing value, invalid date) reflect the updated column titles.

2. **Update Sample File Template**

* Update the **downloadable sample file** column headers to match the new titles:* "Submission Due Date" → **"Review Start Date"**
  * "Review Date" → **"Review End Date"**

3. **Add Mandatory Field Indicator (Icon)**

* Add a **mandatory field icon** (e.g., red asterisk `*`) next to column headers that are mandatory — both:* In the **sample file template** (if applicable/visually indicable), and
  * In any **on-screen column reference/legend** shown to users during upload (if such UI exists).
* Ensure this is applied consistently to **all mandatory columns**, not just Review Start/End Date.

4. **Add Mandatory Field Validation in Source Code**

* Ensure **backend/source code validation** correctly enforces mandatory columns during file upload — rejecting rows/files where mandatory fields are missing, with a clear validation error message referencing the correct (updated) column name.
* Confirm this validation is **in sync with** the mandatory field icons shown in UI — i.e., every column marked mandatory in UI must have actual mandatory validation in code, and vice versa (no mismatch).
