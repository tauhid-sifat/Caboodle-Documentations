## Description

In **Admin Panel > User Management > Users**, when the browser window is resized to **80% or more**, the **First Name** column values overlap with the **Role** column values. This affects readability and breaks the UI layout.

**Steps to Reproduce:**

1. Navigate to Admin Panel > User Management > Users
2. Resize the browser window to ~80% or adjust zoom accordingly
3. Observe the First Name and Role columns

**Expected Result:**
Column values should remain properly aligned without overlapping, maintaining a responsive layout.

**Actual Result:**
First Name column values overlap with Role column values, causing UI distortion.
