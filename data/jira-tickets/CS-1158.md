## Description

*Description:*
The sequence of promo event details displayed in Trade Spend Sandbox (TSS) is not consistent with the order shown in BAP.

*Steps to Reproduce:*

# Create or view a promo event in *TSS*.
# Push the promo to *BAP*.
# Compare the event details order between TSS and BAP.

*Expected Result:*
Promo event details should appear in the same sequence in both TSS and BAP for consistency.
