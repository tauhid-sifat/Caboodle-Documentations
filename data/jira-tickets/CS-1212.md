## Description

There are 3 Boxes when adding an EDLP to an Existing Promo. 

# 1st Box, User enters the Event Name and selects the Products. 
# 2nd Box User sees the items selected in the previous box. User Selects Multiple Edit to Select Fields. 
# 3rd Box User chooses the Events, Banners, etc. When the Products Field is selected there is only 1 product is displayed.
