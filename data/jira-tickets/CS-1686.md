## Description

When a Store Name is updated in the **Store List**, the change is expected to **reflect in the "Mapped Data" section under "Customer Name."** Currently, this update does **not propagate**, resulting in outdated/stale store name data being shown in Mapped Data.

**Steps to Reproduce:**

1. Go to Admin → Store List.
2. Update the **Store Name** for an existing store.
3. Save the change.
4. Go to **Mapped Data** section → check the **"Customer Name"** field for the same store.

**Actual Behavior:**

* Store Name is successfully updated in **Store List**.
* **Mapped Data → Customer Name** still shows the **old/previous store name** — not updated.

**Expected Behavior:**

* Once a Store Name is updated in Store List, the corresponding **"Customer Name"** value in **Mapped Data** should automatically reflect the updated name.
