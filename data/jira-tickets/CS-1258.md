## Description

!image-20260121-030210.png|width=671,alt="image-20260121-030210.png"!

*Steps to Reproduce:*

# Go to TSS.
# Open any existing promo in View & Edit mode.
# Click on the date edit field repeatedly or quickly multiple times.

*Actual Result:*

* Application throws an error and becomes unstable.

*Expected Result:*

* Date edit should remain stable regardless of multiple clicks and should not trigger any application error.
