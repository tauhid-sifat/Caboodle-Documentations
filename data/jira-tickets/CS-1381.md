## Description

### Steps to Reproduce:

1. Navigate to TSS Promo
2. Open **Add SKU** modal
3. Enter valid data in required fields
4. In the **Stores** field, enter a negative value (e.g., `-7`)
5. Click **Submit**

---

### Actual Result:

* System accepts negative store values
* No validation message is shown

---

### Expected Result:

* Stores field should not accept negative numbers
