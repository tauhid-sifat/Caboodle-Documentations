## Description

h3. Steps to Reproduce:

# Navigate to TSS Promo
# Open *Add SKU* modal
# Enter valid data in required fields
# In the *Stores* field, enter a negative value (e.g., {{-7}})
# Click *Submit*

----

h3. Actual Result:

* System accepts negative store values
* No validation message is shown

----

h3. Expected Result:

* Stores field should not accept negative numbers
