## Description

A user was invited to the platform and later the invitation was cancelled by the admin.

Currently, if the invited user accesses the old registration link and attempts to sign up, the system shows the following generic error message:

{quote}*Error*
Something went wrong.{quote}

This creates confusion for the user because the message does not explain the actual reason.

*Expected Behavior:*
When a user tries to register using a cancelled/invalid invitation link, the system should display a proper informative message such as:

{quote}“This invitation link has been cancelled or is no longer valid.”{quote}

or

{quote}“Your invitation is no longer active. Please contact the administrator for a new invitation.”{quote}
