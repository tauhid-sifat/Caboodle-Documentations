## Description

In **CRM → Pipeline**, the **Plan search bar** is not functioning — users are unable to search for plans as expected.

**Impact**

* Reduces efficiency for users managing pipelines with a large number of plans.
* Core search functionality being broken undermines usability of the Pipeline section as a whole.

**Steps to Reproduce**

1. Navigate to **CRM → Pipeline**.
2. Locate the **Plan search bar**.
3. Enter a valid, known plan name (or partial name) in the search bar.
4. Observe that the list does not filter/update to show matching results (or no response occurs at all).

**Expected Behavior**

* Entering a plan name (or partial name) in the search bar should filter the Pipeline list to show only matching plans in real-time (or on enter/submit, depending on intended design).

**Actual Behavior**

* Search bar does not filter/return results as expected — plan list remains unchanged or unresponsive.
