## Description

The CSV file generated by *"Export All Promo Events"* does not match the data shown in the app table. Some values present in the table are missing from the CSV, and the CSV also contains extra values that don't actually exist in the table/list.

*Steps to Reproduce:*

# Go to Promotional Management
# Note the Promo Events shown in the table
# Click *"Export All Promo Events"*
# Open the downloaded CSV and compare against the table
# Observe: some table values are missing from the CSV, and some CSV values don't appear in the table at all

*Expected Behavior:* The exported CSV should be a complete and accurate reflection of the table data — no missing values, no extra/incorrect values.

*Actual Behavior:* CSV data doesn't match the table — both missing and extraneous values present.
