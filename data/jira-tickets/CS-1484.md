## Description

The "Case Stack" and "Training" filter options currently display as **True/False**. Per feedback, these should be updated to display as **Yes/No** to match the table results and be more user-friendly/consistent.

**Steps to Reproduce:**

1. Go to the relevant table/report
2. Open the Case Stack and/or Training filter
3. Note current values shown as True/False

**Expected Behavior:** Filter options and corresponding table values should display as **Yes/No** instead of True/False.

**Actual Behavior:** Currently shows True/False.
