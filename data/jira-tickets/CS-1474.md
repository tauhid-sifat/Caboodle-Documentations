## Description

Implement the requested improvements to the **Category Review Calendar** functionality.

#### Requirements

1. **Calendar – Add Review Month & Reset**

* On the Category Review Calendar, only the following actions should be available:* **Add Review Month**
  * **Reset**
* Remove or disable any other unnecessary calendar actions if currently available.

2. **Remove Reviews from Calendar**

* Allow users to remove Category Reviews from the Calendar.
* Removing a review from the Calendar should **only remove its calendar assignment**.
* The corresponding Category Review must **remain available in the Category Review List/Grid**.
* The removal should not delete or modify the underlying Category Review record.

#### Expected Behavior

* User can add Category Reviews to the Calendar using **Add Review Month**.
* User can reset the Calendar using **Reset**.
* User can select existing Calendar items and remove them from the Calendar.
* Once removed:* The item should no longer appear on the Calendar.
  * The item should still appear in the Category Review List/Grid.
  * No Category Review master data should be deleted.
* The remove operation should only affect the relationship/assignment between the Category Review and Calendar.

#### Backend Considerations

* Update the Calendar removal API/logic to delete only the corresponding Calendar assignment records.
* Do **not** delete the underlying Category Review records.
* Ensure the behavior works correctly for both **Brand** and **Broker** users according to their existing access rules.
* If multiple reviews are selected, the removal should support bulk removal.

#### Acceptance Criteria

* Calendar displays only **Add Review Month** and **Reset** actions.
* Users can select Category Reviews from the Calendar.
* Users can remove selected reviews from the Calendar.
* Removing a review removes only its Calendar assignment.
* Removed reviews remain available in the Category Review List/Grid.
* No Category Review master data is deleted during Calendar removal.
* Bulk removal works correctly.
* Existing Brand/Broker access rules remain intact.
* Calendar refreshes correctly after a review is removed.
* Add Review Month functionality continues to work as expected.
* Reset functionality continues to work as expected.
