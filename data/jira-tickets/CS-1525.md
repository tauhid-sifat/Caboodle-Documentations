## Description

In SPINS → *Stores Insight Report*, the filter dropdowns contain extra/unnecessary values that don't appear to be relevant or valid — consistent with a pattern seen in other report sections (e.g., Retail Report, Monthly Report).

*Problem*

* Filter options include values not applicable to the current dataset/context, cluttering the dropdown and confusing users about which options are actually meaningful.

*Impact*

* Users may select irrelevant filter values that return no data or unexpected results.
* Reduces trust in the filter panel's accuracy.

*Steps to Reproduce*

# Navigate to SPINS → *Stores Insight Report*.
# Open any filter dropdown.
# Review the option list — note values not reflected in/relevant to the report's actual data.

*Expected Behavior*

* Filter dropdowns should only display options that are valid/relevant to the current report data.

*Actual Behavior*

* Extra/unnecessary values are present in the filter options.
