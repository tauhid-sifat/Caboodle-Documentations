## Description

In the Brand Report section, when a user applies filters to the table, the "Due Dates" KPI card does not currently update to reflect the filtered data — it continues to show counts based on the full, unfiltered dataset. The KPI card should dynamically recalculate and display counts based on the currently filtered table rows.

**Steps to Reproduce:**

1. Go to Brand Report section.
2. Note the current "Due Dates" KPI card values (based on full/unfiltered data).
3. Apply a filter to the table (e.g., filter by Brand, Broker, Status, etc.).
4. Observe the "Due Dates" KPI card — values remain unchanged and do not reflect the filtered table data.

**Expected Behavior:**
When any filter is applied to the Brand Report table, the "Due Dates" KPI card should recalculate and display counts based only on the currently filtered/visible rows — staying in sync with the table at all times.

**Actual Behavior:**
KPI card values remain static and reflect the full dataset regardless of table filters applied.
