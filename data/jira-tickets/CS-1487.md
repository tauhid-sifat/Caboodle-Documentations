## Description

Multiple inconsistencies between the manual log entry form and the file upload flow for Distributor APL:

1. **Field count mismatch:** Manual entry form has 6 fields to fill in, but the sample upload file only has 5 fields.
2. **Field mismatch:** Some fields in the manual entry form don't match the fields present in the upload file/sample.

**Steps to Reproduce:**

1. Go to Distributor APL
2. Try adding a log manually — note 6 required fields
3. Download/check the sample upload file — note only 5 fields present, and some don't correspond to the manual form's fields

**Expected Behavior:** Manual entry form and upload template should have matching fields — same count, same names, same mapping — so users can move between the two entry methods without confusion or errors.

**Actual Behavior:** Field count and field names don't align between the manual form and the upload template.
