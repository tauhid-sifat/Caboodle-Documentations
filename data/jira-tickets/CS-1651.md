## Description

The warning "No owner, sub-users or contacts on: [Brand Name]" does not clear or update correctly. Once triggered for a brand (e.g., AQUA-Test), it continues to display even after the underlying condition changes or the modal is reopened.

**Steps to Reproduce:**

1. Open the relevant modal/entry for a brand with no owner, sub-users, or contacts assigned (e.g., "AQUA-Test").
2. Note the warning: "No owner, sub-users or contacts on: AQUA-Test"
3. Try any of the following:* Change the brand name
* Remove the brand entirely
* Close the modal and reopen it for the same entry
* Close the modal and open it for a **different** entry
4. Observe that the warning still shows "No owner, sub-users or contacts on: AQUA-Test" regardless of the action taken.

**Expected Behavior:**

* The warning should update or clear when the brand name is changed.
* The warning should disappear if the brand is removed.
* The warning should reflect the correct state (or not appear at all) when reopening the modal, whether for the same or a different entry.

**Actual Behavior:**
The warning text is stuck referencing "AQUA-Test" and persists regardless of context — appears to be a stale/cached state issue rather than a live check tied to the current entry.
