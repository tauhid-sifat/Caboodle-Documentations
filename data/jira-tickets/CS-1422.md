## Description

## **Summary**

**Bug:** Distributor Report calculation error when KeHE Pack Size and Unit of Sale (UOS) do not match (e.g., Viori Beauty)

## **Description**

We have identified a calculation bug in the Distributor Report inside Caboodle.

### **Context**

* Caboodle pulls KeHE sales reports, which report in **eaches** (unit volume).
* To calculate sales in **case volume**, Caboodle divides the units sold by the case pack size defined in the **Product Spec Module**.
* **The Normal Case (95% of the time):** KeHE Pack Size and UOS match perfectly (e.g., Sunshine Nuts: Pack Size = 6, UOS = 6, Ratio = 1). The report calculates correctly.
* **The Edge Case (Small % of brands, mostly Health & Beauty):** Pack Size and UOS *do not* match because Viori sells to KeHE in Case Packs of 36, but KeHE sells to Retailers in Case Packs of 3. This mismatch is causing an inflated calculation (multiplying data by a factor of 12 instead of 1), leading to errors in the Distributor Report.

## **Example Case Study for Debugging**

* **Broker:** Noble Sales
* **Brand:** Viori Beauty
* **Product:** Bar Aged Sandalwood Conditioner Bar
* **UPC:** `197644130573`

### **Data Breakdown:**

* **KeHE Brand Item Location Report:** Pack Size = **36** (Column O) | UOS = **3** (Column Q)
* **KeHE POD Report:** Current Quantity (Units Sold to Retailer) = **3** (Column AM) | Price = **$15.84**
* **Current Caboodle Setup:** Product Spec Module case pack is currently set to **3**.

### **The Bug in Action:**

Because of the UOS/Pack Size mismatch, the Distributor Report dollar sales for Viori are not matching column AO in the POD report. There is an incorrect multiplier occurring.

> **Testing Note:** I tried manually changing this item’s case pack to **36** in the Caboodle Product Spec Module to test a fix, but the change **did not reflect or update** in the Distributor Report.

Additionally, on the Distributor Report for this Viori item (filtered by *KeHE > Sprouts > Aged*), dollar sales appear for all months, but cases shipped **only show data for January**.

## **Expected Behavior**

1. The Distributor Report should correctly calculate case volume and dollar sales even when a brand's KeHE Pack Size and UOS differ.
2. Changes made to the case pack configuration in the Product Spec Module should dynamically update or trigger a recalculation on the Distributor Report.
3. Cases shipped should consistently display across all months where sales dollars exist.

## **Steps to Reproduce / Verify**

1. Open the Distributor Report and filter by **KeHE > Sprouts > Aged Sandalwood Conditioner Bar** to view the Viori item.
2. Review the attached data files to compare the logic of a working brand (**Sunshine Nuts**) vs. a broken brand (**Viori Beauty**).
