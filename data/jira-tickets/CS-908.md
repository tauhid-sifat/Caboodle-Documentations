## Description

**Steps to Reproduce:**

1. Go to the distributor details page.
2. Open the “Add Banner” modal.
3. Observe already added banners appear in the list.
4. Select one of them.
5. Try to click save.
**Expected Behavior:**
Already added banners should not appear.
**Actual Behavior:**
Previously added banners appear selectable, but save button is disabled after selection.
