## Description

*Steps to Reproduce:*

# Go to the distributor details page.
# Open the “Add Banner” modal.
# Observe already added banners appear in the list.
# Select one of them.
# Try to click save.
*Expected Behavior:*
Already added banners should not appear.
*Actual Behavior:*
Previously added banners appear selectable, but save button is disabled after selection.
