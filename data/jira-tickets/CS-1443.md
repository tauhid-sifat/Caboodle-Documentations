## Description

Backend support for generalized CRM upload/export and server-side filtering. Provide reusable endpoints and contracts so the frontend can apply the same upload/export/filter behavior across applicable CRM data screens.

*Implementation scope*

Upload

* Generalized upload endpoint(s) for CRM data ingestion, reused across applicable entities rather than per-screen duplication.
* Server-side validation: file type, empty file, size limits, and row/column schema validation. Return structured, user-readable error responses.
* Consistent success/failure response contract (counts processed, rejected, error detail).

Export

* Export endpoint(s) that accept the same filter parameters as the list endpoints so exported data matches the filtered view.
* Consistent export format and column headers aligned with the entity's list contract.

Filter

* Server-side filtering on applicable CRM list endpoints, with a consistent query-parameter contract (field, operator/value) reused across entities.
* Ensure pagination and filtering compose correctly.

*Acceptance Criteria*

* Reusable upload/export/filter contracts usable across applicable CRM entities (no per-screen bespoke logic where a shared pattern fits).
* Validation errors returned in a structured, FE-consumable shape.
* Export honors the same filters as list retrieval.
* Filtering + pagination behave correctly together.
* Clean architecture / separation of concerns maintained; no regressions.
