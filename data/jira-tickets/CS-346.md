## Description

The Store itself doesn’t push because there is no place to push to.  But the sku and status should push to the banner that’s been selected. 

Here is an example 

Market Overview Example

* Region: Midwest 
* Retailer UNFI Independents 
* Banner UNFI Independent 
* Store: Back to the Best Country 
* Brand: Zucchini Beanie Demo Brand 
* Sku: Blue Berry Lavender Ice Cream 
* Sku Status: Pending 
* Distribution Center: UNFI Iowa City 
* Presentation Date: Feb 2 20024

Enter 

We want the sku Blueberry Lavender Ice cream to show up in the Banner UNFI Independents as Pending.  The store doesn’t push anywhere because there is not where for it to push.  But the sku should push to the banner.  See [Video Clip  |https://zoom.us/clips/share/Ewn-5PP7tbZ_iKSsrf0pcW2eYX-EwkLqFvGH_UKDiRjThFU1EEqde5G6jmS8PYsRtqmGIEEX58cCCgkOedH_DtDO.LXTvfKjIU-WXckKC]
