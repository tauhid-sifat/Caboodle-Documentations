# Broker Dashboard | Integrate Ask Caboodle

**New Requirement** | User Story | Priority: TBD | Status: New

## User Story

**As a** Broker user, **I want** Ask Caboodle (AI assistant) integrated into the Broker Dashboard, **So that** I can query data, get insights, and navigate using natural language.

---

## Description

Caboodle has an aspirational "Ask Caboodle" / "ASK Cab" AI feature referenced in the Intelligence module. This ticket covers integrating that capability into the Broker Dashboard so broker users can ask questions about their data (promotions, reviews, market overview, etc.) in natural language and get answers without navigating multiple screens.
