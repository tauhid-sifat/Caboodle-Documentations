## Description

**Description:**
In the Simple Promotion grid, the **EDLP (all year)** group currently has two columns: **Y/N** and **Everyday Allowance**. There is no place to enter the EDLP event name there. Today the user has to type the EDLP event name under **Jan → Event Name**, and the system has a validation for this.

Add a new column named **Event Name** under **EDLP (all year)**. This column holds the EDLP event name. Once this is in place, the old way (typing the EDLP name under Jan → Event Name) is no longer needed, so that validation must be removed.

**Current Behavior:**

* EDLP (all year) has only Y/N and Everyday Allowance.
* The EDLP event name must be entered under Jan → Event Name.
* A validation enforces this.

**Requested Behavior:**

* Add an **Event Name** column under EDLP (all year), next to Y/N and Everyday Allowance.
* The EDLP event name is entered in this new column.
* Remove the validation that requires the EDLP event name to be entered under Jan → Event Name.
* Jan → Event Name becomes a normal event name field again, with no EDLP-specific rule.

**Acceptance Criteria:**

* The EDLP (all year) group shows a new "Event Name" column.
* The EDLP event name saved from this column is used as the name of the EDLP event.
* The user is no longer asked to enter the EDLP name under Jan → Event Name, and the related validation no longer appears.
* Export and Import of the grid include the new Event Name column, and the exported file can be imported back without errors.
* Existing EDLP data (Y/N, Everyday Allowance) keeps working as before.
