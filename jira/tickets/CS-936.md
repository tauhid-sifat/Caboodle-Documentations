## Description

Clickable list items have no hover or pointer indicator

* **Steps to Reproduce:**1. Go to any list view (e.g., promo list, contact list, pipeline tasks).
  2. Try to click on an item assuming it’s clickable.
* **Expected Result:**
  Items should show hover state (e.g., underline, highlight, pointer cursor) to indicate they are clickable.
* **Actual Result:**
  No visual cue is present, causing usability confusion for users.
