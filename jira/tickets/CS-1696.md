## Description

Multiple label/terminology updates and filter consolidation changes are needed in the **Category Review** section to standardize naming (replacing "Submission Due Date" references with "Review Start Date" / "Review End Date") and to merge related From/To filter pairs into single Range filters for better usability.

---

1. **Add Log Modal — Field Title Updates**

**Current:**

* "Submission Due Date"
* "Review Date"

**Requested:**

* Rename **"Submission Due Date"** → **"Review Start Date"**
* Rename **"Review Date"** → **"Review End Date"**

---

2. **KPI Card — Title & Date Update**

**Current:**

* KPI Card title: "Submission Due Date" (as seen in the "Within 60 Days" popup listing dates with "Submission Due Date" label).

**Requested:**

* Update KPI Card title from **"Submission Due Date"** → **"Review Start Date"**.
* Update the KPI card's listed dates to correspond correctly to **Review Start Date** values (ensure data source reflects the renamed field correctly, not just a label change).

---

3. **Filter — "Submission Due Month" Title & Placeholder**

**Current:**

* Filter title: "Submission Due Month"

**Requested:**

* Rename to **"Review Start Month"**.
* Update placeholder text accordingly to reflect the new naming (e.g., "Select Review Start Month" — per the earlier agreed filter naming convention).

---

4. **Merge Filters — "Submission Due From" + "Submission Due To" → Range Filter**

**Current:**

* Two separate filters: "Submission Due From" and "Submission Due To".

**Requested:**

* Merge into a **single Range filter** titled **"Review Start Date"**, allowing users to select a start and end date within one combined field (consistent with standard range filter UX).
* Update placeholder text accordingly to reflect the new naming 

---

5. **Merge Filters — "Reset Date From" + "Reset Date To" → Range Filter**

**Current:**

* Two separate filters: "Reset Date From" and "Reset Date To".

**Requested:**

* Merge into a **single Range filter** titled **"Reset Date"**.
* Update placeholder text accordingly to reflect the new naming 

---

6. **Add New Filter — "Review End Date" (Range)**

**Requested:**

* Add a new **Range filter** titled **"Review End Date"**, allowing users to filter Category Review entries by a Review End Date range (currently no such filter exists).
* Update placeholder text accordingly to reflect the new naming
