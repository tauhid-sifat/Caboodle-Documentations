## Description

## Overview

As a user, I need the Data Mapping module to be more interactive and user-friendly so I can efficiently manage, filter, and resolve mapping issues without page disruptions.

**Modules Covered:** Data Mapping

## Acceptance Criteria

* Source rows are clickable and display full import sync details
* Users can change the status on any unmapped data item regardless of current state
* Dashboard date format shows MM/DD/YY (not DD/MM/YY) for Created On
* Auto resolve success message reflects the correct number of resolved items (not 0)
* Mapping status updates refresh the page in-place without a full reload
* Unmapped filter includes options for all available data properties
* Users can export unmapped records to a file
