## Description

When an Admin invites a Sub Broker, they must specify the parent Broker (i.e., which broker the sub-broker belongs to). This field includes a search functionality to help Admins quickly find and select the correct broker name. However, the **search is not working**, forcing Admins to scroll/find the broker manually without search assistance.

**Steps to Reproduce:**

1. Go to User Management → Sub Broker Invitation.
2. Start inviting a new Sub Broker.
3. In the **Broker** field, type a broker name to search.
4. Observe search behavior.

**Actual Behavior:**

* Typing in the broker search field does not filter/return matching results.

**Expected Behavior:**

* Typing a broker name (full or partial) should filter the list and show matching broker(s) for easy selection.
