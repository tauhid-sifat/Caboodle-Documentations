## Description

In the Admin Panel's User section, the **Phone Number** field currently accepts and displays alphanumeric values. Phone numbers should only ever contain numeric characters (with support for standard formatting like `+`, spaces, or hyphens if applicable — to confirm). Validation is needed both on input and at the API level, and existing bad data needs to be identified/cleaned up.
