## Description

In the Category Report section, entries can be created by either a brand user or a broker user. However, the "Created By" column always displays the broker's name, even when the entry was actually created by a brand user.

**Steps to Reproduce:**

1. Log in as a brand user.
2. Navigate to Category Report section.
3. Add a new entry.
4. Check the "Created By" column for that entry.

**Expected Behavior:**
"Created By" should reflect the actual user (brand or broker) who created the entry — showing the brand user's name when a brand user creates it, and the broker's name when a broker creates it.

**Actual Behavior:**
"Created By" always shows the broker's name, regardless of whether a brand or broker user actually created the entry.
