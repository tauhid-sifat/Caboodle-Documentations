## Description

User Feedback is that if they want to add a promotion they do not want to start at Step 1 in the stepper. 

It should be similar to add a Sku where the user is taken to a Pop-out box with an option to 

1. Select the items (offer category w/ item dependency) 
2. Enter Event Name
3. Enter Event lift 
4. Enter Dates
5. Enter the discount (Option to add Ad/TPR fee) 

The promotion would apply to all banners already in the promotion as well as the store count and velocity that’s already been entered for each item. The User shouldn’t have to renter that information
