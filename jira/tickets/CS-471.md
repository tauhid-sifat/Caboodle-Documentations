## Description

There are 2 skus with the same active date.  The trade spend stepper throws an error for one of the skus but not the other.  Screen shots below.  

Additionally, it created a promo for the month of Jan, but it wasn’t active until Feb.  When creating a promotion it should allow the user to create promotions for the months that the item is active.  So if the item is active in Feb 2024 and the user creates a promo for Jan and March, it should warn the user it won’t create it for Jan because the active date is Feb but let it move forward with the promo and create it for March.
