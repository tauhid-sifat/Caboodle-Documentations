## Description

Issue with trying to share a Caboodle page link in Pipeline activity - the URL brings user to either Caboodle homepage to log in, or if you are in a Brand's environment in Caboodle it will take you to the intended page within that Brand's environment. So sharing URL link to any page in Caboodle only works for the user that created it. Example: I was working in Melora's Brand environment. When I pasted a link that Erin shared for Kettle & Fire Pipeline Activity, it brought me to Melora's Pipeline, the module that was supposed to be shared for K&F. To test this, log into any Brand's environment in YYN's Broker/Brand Admin ***except**** Zucchini Beanie Demo Brand. * Stay on the Dashboard landing page for that Brand. Now paste this [link](https://app.caboodleservices.com/activities/47023c3a-99c1-46ee-99a8-3efd4379c8d2) in your browser and it will take you to the Pipeline of whatever Brand's page you were in.
