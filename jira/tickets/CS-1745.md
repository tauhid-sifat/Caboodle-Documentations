## Description

## Summary

On the Simple Promotion entry screen, the **Add Price** modal fails to save a price. It opens from the "Set price" link on the no-price warning. All required fields are filled and a product is selected, but the `create` API returns **400** with "Please select at least one product." The selected product does not appear to be sent in the request.

## Environment

Staging, brand **Apple Jacks**
URL: `/simple-entries/create?search-promo-year=2026`

## Steps to reproduce

1. Open Promotional Planning → Simple Promotion → create.
2. Enter a Promotion Title (e.g. "EDLP = Y two months") and fill a row for **ABSCO National · Natural Sparkling Mineral Water 750 ml Glass** (UPC 858072005290). This product has no price.
3. On the warning banner, click **Set price**.
4. In the Add Price modal, fill in:* Distributor: **KeHE DELIVERED**
* Product: **Natural Sparkling Mineral Water 750 ml Glass**
* Per Unit Price ($): **4**
* Valid From: **2026-09-02**
5. Click **Submit**.

## Actual result

* A toast shows "**ProductIDs** — Please select at least one product."
* In the Network tab, `create` fails on both attempts with:

```json
{
  "statusCode": 400,
  "type": "ValidatorException",
  "messages": { "ProductIDs": "Please select at least one product." }
}
```

logID: `b36010f9-e562-4cd2-95ed-48808b180018`

* The price is not saved and the row stays blocked.

## Expected result

* The selected product is sent as `ProductIDs` in the payload.
* The price is created successfully, the modal closes, and the warning clears for that row.

## Suspected cause

FE payload mapping. The Product dropdown value is not mapped to `ProductIDs`, or it is sent as an empty array or under the wrong key. Please verify the request in the Payload tab.

## Notes

* The Simple Promotion itself should not require a price at all (see **CS-1742**). This modal was the workaround, and it is also broken, so there is currently no working path for unpriced products.
* If this modal is shared with the main price-list feature, please check whether Add Price is broken elsewhere too.
