## Description

## User Story

As a Broker user,

I want each month column in the Promotional Management grid to be the same width,

So that the layout is consistent and easy to read.

## Description

The Promotional Management grid displays events grouped by month, but each month column renders at a different width depending on content. This makes the grid look uneven and harder to scan horizontally.

The grid should enforce uniform column widths so all 12 month columns are the same size, regardless of how many events each month contains.

## Acceptance Criteria

### Scenario 1: Equal Column Widths

* Given** I am viewing the Promotional Management grid

* Then** all 12 month columns have identical widths

* And** column width does not change when toggling months or event counts

### Scenario 2: Content Overflow

* Given** a month column has more events than fit in the standard width

* Then** the content scrolls vertically within the column (overflow: scroll or auto)

* Or** the row height expands to fit all events

### Scenario 3: Responsive Behavior

* Given** the screen width is reduced (tablet or smaller)

* Then** columns either remain uniform and scroll horizontally, or stack vertically

## Design Notes

* Likely a CSS-only fix: set `table-layout: fixed` on the grid/table and equal `width` or `flex` values on month columns

* If the grid uses a CSS grid layout: `grid-template-columns: repeat(12, 1fr)`

* Ensure sticky month headers remain aligned with columns

## Notes

* This is a frontend-only change — no backend work required

* Also check if the Category Review yearly grid (CS-1361) has the same issue for consistency
