## Description

In the Admin Panel's CRM Data Upload section, none of the filters are currently dynamic — meaning filter options appear to be static/hardcoded rather than reflecting the actual underlying data. All filters need to be made dynamic so they populate based on real, current data.

**Steps to Reproduce:**

1. Log in to Admin Panel.
2. Navigate to CRM Data Upload section.
3. Check the available filters.
4. Observe that filter options do not update/reflect based on actual uploaded/existing data (static list regardless of data changes).

**Expected Behavior:**
All filters in the CRM Data Upload section should be dynamic — i.e., filter options should be generated from the actual data present in the system (e.g., populated from distinct values in the dataset) and update automatically as data changes (new uploads, deletions, edits).

**Actual Behavior:**
Filters appear static and do not reflect real/current data options.
