## Description

On the Versions panel, the "Events" count shown against a version does not update automatically when events are added/removed/modified for that version. The count only reflects the correct, current value after the page is manually refreshed.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open a promo with multiple versions (e.g., "Test 123 V2").
3. Add, remove, or modify an event under "View & Edit Promo Events Details" for the currently active version.
4. Open the "Versions" panel on the right.
5. Check the "Events" count shown for that version.
6. Refresh the page and check the "Events" count again.

**Expected Result:**
The "Events" count in the Versions panel should reflect the current, accurate number of events immediately after any add/edit/remove action — without requiring a manual page refresh.

**Actual Result:**
The "Events" count shown in the Versions panel is stale/incorrect until the page is manually refreshed.
