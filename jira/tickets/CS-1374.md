## Description

### **Steps to Reproduce:**

1. Go to **TSS Promo (Step 4/5 or Event Details)**
2. Click **Add SKU**
3. Select:* Banner → AGSVT (example)
* Product → any product
* Event → e.g., **Q-123**
4. Click **Submit**
5. Observe top-right alert message

---

### **Actual Result:**

* Error toast appears:
  ❌ *“No events under this Promotion! Please add events and try again!”*
* Even though:* Event dropdown has value selected
  * Event exists in list (visible in background table)

---

### **Expected Result:**

* No error should be shown when a valid event is selected
* SKU should be successfully added to the selected event
