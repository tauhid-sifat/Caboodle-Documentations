## Description

## Background

Client feedback (Constance, Sep 29): users sometimes forget to add an item when creating a Simple Promo, or a brand/retailer adds an item to the promotion at a later date. Right now there is no way to add items to an existing Simple Promo entry.

## Goal

Allow users to add new items (SKUs/UPCs) to an existing Simple Promo without recreating the promotion.

## Requirements

1. On an existing Simple Promo entry, provide an **Add Item(s)** option (from the promotion detail/edit view).
2. The user can search and select one or more items to add. The item list should respect the promotion's **brand** and **retailer/banner**.
3. Newly added items **inherit the promotion's details** (event type, retailer/banner, dates, promo price/discount), with the option to edit item-level values where the promotion allows it.
4. Prevent **duplicates**: an item already in the promotion can't be added again. Show a clear message if the user tries.
5. Existing items in the promotion stay unchanged.
6. Added items appear everywhere the promotion's items are shown: the promotion detail, Promotional Calendar, promo event lists, exports, and reports.

## Acceptance Criteria

* A user can add one or more items to an existing Simple Promo.
* Added items take the promotion's dates and details.
* Duplicate items are blocked with a clear message.
* Added items show in the Promotional Calendar, promo events modal, exports, and reports.
* Existing promotion items are not affected.
