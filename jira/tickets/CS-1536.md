## Description

Users need the ability to download every Brand Report from the Category Review view in a single action, rather than opening and exporting each one individually.

**Acceptance Criteria:**

* An "Export All" (or "Download All") button/action is visible on the Category Review page where Brand Reports are listed.
* Clicking the action bundles all currently visible/filtered Brand Reports into a single download (e.g., a ZIP of individual files, or one combined file — *TBD with design/product*).
* Export respects any active filters (e.g., date range, category, region) rather than always pulling the entire dataset.
* User receives feedback while the export is generating (loading state / progress indicator) for large datasets.
* On completion, the file downloads automatically or a download link is presented.
* Errors (e.g., no reports match filters, export failure) are handled gracefully with a clear message.
