## Description

The search bar within the Files section returns search results from across the **entire app**, rather than being scoped to the Files section (or the current folder/section the user is in). From a user's perspective, a search bar inside Files should only search within Files.

**Steps to Reproduce:**

1. Go to Files section
2. Enter a search term in the Files search bar
3. Observe results — they include content from outside the Files section (app-wide results)

**Expected Behavior:** Search should be scoped to the Files section only (and ideally to the current folder context, tying into Ticket 18's folder navigation as well).

**Actual Behavior:** Search returns results from the whole application, not just Files.
