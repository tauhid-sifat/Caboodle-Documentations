## Description

The tables on the pages listed below currently load **10 rows per page by default**, but there is **no option for the user to change this** — no "Items per page" selector exists. Add pagination controls at the bottom of each table, including a selector to switch between **10 / 20 / 50 / 100** rows per page, consistent with the pattern shown in the attached reference image.

**Pages in Scope:**

* Brand Retail Item Status
* Market Overview
* Category Review
* Category Calendar Review
* Distributor APL

**Current Behavior:**

* Tables load a fixed **10 rows per page**.
* No **"Items per page"** dropdown or pagination navigation is present — user has no way to view more/fewer rows per page or navigate between pages explicitly.

**Requested Behavior:**

* Add a pagination bar at the bottom of the table on **each page listed above** with:* **Previous (←) / Next (→) navigation buttons** to move between pages.
  * **"Items per page" dropdown selector** with options: **10, 20, 50, 100**.
* Default should remain **10 per page** unless changed by the user.
* Pagination should work in conjunction with any applied filters/search — i.e., paginate over the currently filtered/searched result set, not the full unfiltered dataset.
* The pagination behavior and look should be consistent across all the pages listed above.

**Acceptance Criteria:**

* "Items per page" selector (10 / 20 / 50 / 100) is available at the bottom of the table on all 5 pages in scope.
* Previous / Next navigation works correctly on all 5 pages.
* Default stays at 10 per page.
* Changing the page size works correctly with applied filters/search.
* Behavior is consistent across all pages.
