## Description

When sending a Category Review notification email, the subject field is not pre-filled with the default subject. The subject line should always auto-populate with the default value when the send mail modal/screen opens, without requiring manual entry from the user.

**Steps to Reproduce:**

1. Go to Broker Dashboard > Category Review.
2. Select a brand/category and proceed to send mail.
3. Observe the Subject field.
4. Note that the default subject is not auto-filled

**Expected Behavior:**
The Subject field should always be pre-filled with the default subject line automatically when the send mail screen/modal opens.

**Actual Behavior:**
Subject field is not populated with the default subject.
