## Description

**Description:**
When a user deletes all events from a Promo, the page becomes blank across all "Add" flows (Add Promo Event, Add SKU, Add EDLP, etc.) with no way to add a new event back into that same promotion. This leaves the promo in a dead-end state where the user cannot recover or continue working within it.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open any promo with existing events.
3. Delete all events from the promo (via "View & Edit Promo Events Details").
4. Attempt to add a new event using any of the available "Add" options (Add Promo Event, Add SKU, Add EDLP, etc.).

**Expected Result:**
After all events are deleted from a promo, the user should still be able to create a new event under the same promotion — the "Add" options should remain functional and guide the user to add a fresh event, rather than showing a blank/dead-end page.

**Actual Result:**
Once all events are deleted, the page goes blank for all "Add" event types, and there is no option/path for the user to add a new event under the same promotion.
