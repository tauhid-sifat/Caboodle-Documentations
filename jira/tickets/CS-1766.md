## Description

## Overview

On the **Broker Dashboard → Management → Category Review** page, **Actions → Export** currently has two options: **All Data** and **Current Page**. Users have no way to export just the rows that match the filters they've applied.

This ticket adds a **Filtered Data** export option and a progress indicator while an export is running.

## Requirements

1. **New option.** Add **Filtered Data** to the Export submenu, so it lists:* All Data
* Filtered Data
* Current Page
2. **Filtered Data** exports every record that matches the currently applied table filters (global filters, column filters, and search), across **all pages**, not just the visible page.
3. **All Data** always exports the complete Category Review data and **ignores any applied filters**. Even if the user has filtered the table, choosing All Data exports everything.
4. **Current Page** keeps its current behavior and exports only the rows visible on the current page.
5. **When no filters are applied**, **Filtered Data** should be disabled (greyed out), with a tooltip such as "Apply a filter to export filtered data."
6. **Progress bar.** While an export runs:* Show a progress bar or progress indicator, with a percentage where possible.
* Disable the Export option until the current export finishes, so the user can't start duplicate exports.
* On completion, download the file and show a success message.
* On failure, show an error message and re-enable Export.
7. **Column structure.** The exported file has the same columns for all three options.

## Acceptance Criteria

* Export submenu shows All Data, Filtered Data, and Current Page.
* With filters applied, **Filtered Data** exports only matching records from all pages.
* With filters applied, **All Data** exports all records, ignoring the filters.
* **Current Page** exports only the visible page's rows.
* **Filtered Data** is disabled when no filter is applied.
* A progress indicator appears during every export and disappears when it finishes or fails.
* Users can't start a second export while one is in progress.
* Large exports complete without a timeout and the downloaded data is accurate.

## Notes

* **BE:** The export API needs to accept the same filter parameters as the Category Review listing API, so filtered exports match the table exactly.
* **BE:** If the progress bar should show real progress for large exports, the export may need to run as a background job with a status endpoint. Otherwise, the FE can show an indeterminate progress bar.
