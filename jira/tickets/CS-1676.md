## Description

Two enhancements requested for the **Admin – Stores** section:

1. Add three distinct export options to support different export needs.
2. Add a **Store ID** column to the table, along with a corresponding **Store ID filter**.

**Requirement 1: Add 3 Export Types**

**Current Behavior:**

* Export functionality does not offer options — *(please confirm current default: exports all data / current page only / etc.)*

**Requested Behavior:**
Add the following **3 export options** in Admin – Stores:

1. **Export All Data** — exports the complete dataset regardless of filters or pagination.
2. **Export Current Page** — exports only the records currently visible on the active page.
3. **Export Filtered Data** — exports only the records matching the currently applied filters/search (across all matching pages, not just current page).

**Requirement 2: Add Store ID Column + Filter**

**Current Behavior:**

* Store ID is not displayed as a column in the Stores table.
* No filter exists to search/filter by Store ID.

**Requested Behavior:**

* Add a **"Store ID"** column to the Stores table (position to be confirmed with design/stakeholder).
* Add a **Store ID filter** so users can filter the table by a specific Store ID.
