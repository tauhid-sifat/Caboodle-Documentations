## Description

## Overview

As a user, I need additional TSS capabilities to create, manage, and view promotions more flexibly and efficiently so I can handle complex trade spend scenarios without workarounds.

1. Lump Sum type:1. Choose Banner
2. Per product not per event. For Banner add all the products.
2. Coupon type:1. Choose Banner
2. Select product (if not then all)
3. Choose Dates (start and end)
4. Redemption rate
5. Coupon value
6. Lump Sum (optional)
3. Prime Member ship allowance type:1. Choose Banner
2. Choose Event / Events
3. Per Unit Scan Fee, Prime Member allowance, Redemption percentage
4. Another separate column for this type in the event details, event summery, product summery

Filter: New section for the coupons



**Modules Covered:** TSS (Trade Spend Sandbox)

## Acceptance Criteria

* Coupon option is available when creating a promotion in TSS
* Users can add a SKU to an existing event and select multiple events (discount mechanism removed per CS-1197 notes)
* Ad Fees and TPR Fees (Lump Sum) can be added independently without being tied to any promotion
* A single-promotion calculation module is available for isolated promo analysis
* New TSS Stepper auto-populates store count and unit velocity from Distributor Reporting data
* WFM Amazon Prime Membership Fees can be entered and tracked
* Users can reposition/move the field input box during editing to see data behind it
* Adding a new Promo Event does not force the user back to the retailer selection step
