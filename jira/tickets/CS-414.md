## Description

**This is for Broker Brands ONLY! **

For the broker brands the trade spend roll up should pull from the Trade Spend Sandbox. Trade Spend Sandbox was built for broker brands so the promotions they create don’t affect the Promos at a Glance report which is what the brokers use to submit promotions to the retailers. If brands are making promos in trade spend that are only for testing scenarios that means the admin staff would submit to retailers by mistake. That is why we created the sandbox.

Clarification. Trade spend sand box is an enhanced feature that broker brands can opt in and will pay an additional fee.  

For brands that are **not** a part of the brokers we don’t need the trade Spend Sandbox the trade spend roll up report should continue to pull from trade spend.
