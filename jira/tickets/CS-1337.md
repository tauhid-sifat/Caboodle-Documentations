## Description

## Overview

As a user, I need TSS to correctly create promotions, calculate fees, and handle UI interactions without errors so I can manage trade spend reliably and without data loss.

**Modules Covered:** TSS (Trade Spend Sandbox)

## Acceptance Criteria

* EDLP Promotion creates successfully without throwing an error
* Ad Fees are not incorrectly split across multiple events when multiple events are selected
* Pricing updates in Product Specs correctly flow through to Trade Spend calculations
* New and Discontinued items calculate correctly based on their Add/Disco dates
* Multiple clicks on a promo date edit field do not cause application errors
* Push to Approved status message no longer reads "push to trade spend"
* All issues captured in CS-1236 (TSS New Bugs) are resolved
* All issues in CS-1244 (Pricing, Allowance, Total Spend, Alert UI, TPR Fee) are resolved
