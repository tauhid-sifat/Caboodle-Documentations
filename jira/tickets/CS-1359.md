## Description

### **Description:**

System allows adding multiple Promotion Fees with the **same name**, which creates confusion and may lead to incorrect fee identification.

### **Steps to Reproduce:**

1. Go to TSS → Open any promo
2. Click **Add Promotion Fee**
3. Enter a name (e.g., "aaa")
4. Save
5. Add another Promotion Fee with the **same name "aaa"**

### **Expected Result:**

* Promotion Fee name should be **unique**
* System should show validation message:* *“Fee name already exists”*

### **Actual Result:**

* Duplicate names are allowed and displayed in the list
