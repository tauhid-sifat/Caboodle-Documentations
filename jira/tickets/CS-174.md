## Description

There is a concern from Broker Administration Staff that Sub Broker Users should not be able to make updates to Product Specs and Price Lists.  Parent Brokers and Brands should be able to make changes.  If that is possible for make read only for the sub brokers then the Upload Products and Add Product Buttons can be removed just for Sub Brokers.  They should remain for Parent Brokers and Brands.
