## Description

**Description:**
On the edit screen of a Simple Promotion (example: ABSCO DENVER, Brand Approved, plan year 2026), the column headers in the "You entered" section do not line up with the input boxes below them. The headers (EDA, OI %, MCB, Scan, TPR $, Ad/TPR, Comments) sit off to the side of their boxes, so each header ends up between two boxes. It is hard for the user to tell which box belongs to which column, especially when there are many rows.

The client said this is not a big issue and can wait until after the IAM service is complete.

**Steps to Reproduce:**

1. Open a Brand Approved Simple Promotion and go to the edit screen.
2. Look at the "You entered" section (EDA, OI %, MCB, Scan, TPR $, Ad/TPR, Comments).
3. Compare the position of each column header with the input boxes below it.

**Expected Result:**
Each column header is directly above its input boxes (same left edge and width, or centered over the box), so the user can see right away which box to edit.

**Actual Result:**
Headers are shifted away from their boxes and do not line up with them.

**Acceptance Criteria:**

* Every header in the "You entered" section lines up with the input boxes in its column.
* The alignment stays correct on all rows and when the screen is scrolled sideways.
* The "From your APL" and "Calculated" sections keep their current alignment.
