## Description

I had a disappointing meeting with the brokers yesterday.  Essentially, they concluded that the promotional stepper is just too complicated for the team to enter promotions.

After a long discussion we determined that there might be a way to create a new promotional entry system for them, once that’s closer to how they do it today but within Caboodle.  I created the attached sheet to outline how this might work (New Promo Entry) and **[this video](https://zoom.us/clips/share/fiV64x8Fyu7zDjdBXs1LG9MERXhSqO9UKOm_1SJ8124HmbKMSLy-0IBLlLbzQZkPrxKz8JIlRWhLvW9QgBunbk7J.ivk7V3wrMAAO0da4)** for you to review on Sunday. Let’s have this as our main discussion on Monday. 

 I forgot to mention in the video

* They don’t need any calculations, so they prefer to enter the discount mechanisms in the new event name. 
* They need to be able to easily copy the event name in multiple rows easily.  If a pull-down option like in excel (select the cell & pull the green box in left bottom corner) that would be ideal or select multiple rows and paste
* Added feature – can they enter comments in the event name with an at @ feature that tags a teammate? Similar to the pipeline?  

I hope this makes sense.  It’s sad that we spent so much time building this the way they directed then it not working for them.  However, the work is not waisted it’s still great for the trade spend sandbox!
