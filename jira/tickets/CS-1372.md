## Description

### **Steps to Reproduce:**

1. Navigate to **TSS Promo → View/Edit Promo**
2. Go to **Event Details / Promotion Fees section**
3. Locate a record where **Everyday Allowance** is already configured
4. Observe the displayed value

---

### **Actual Result:**

* Everyday Allowance field shows **0**
* But backend / previous input contains a **non-zero value**

---

### **Expected Result:**

* Everyday Allowance field should display the **actual stored value**
