## Description

User Story: As a Broker user, I want a Brand Report that acts as my Category Review workflow tracker - populated automatically when I notify brands (or add them manually, or when brands opt in themselves), with per-row statuses, notes, emails, and KPI filters, so that I can manage every brand's participation in a review from one place, know what to do next, and communicate with brands without leaving Caboodle.

## Architecture decisions

* Brand Report and Calendar are always in sync (remove from one = remove from other).
* Category Review List is separate - removing from calendar does NOT remove from the list.
* Calendar populates from the Brand Report, not from the list.
* Only brands that have been included/assigned appear; by default the row starts as In Progress.
* Brand environment has NO Brand Report - brands get calendar + KPI cards only.
* Statuses are dynamic, admin-configurable (color + display order + default per entry mechanism).
* Emails go to brand owners AND sub-users, grouped per brand; sender auto-BCC'd.
