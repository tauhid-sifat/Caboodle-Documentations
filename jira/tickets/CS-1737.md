## Description

**Description:**
When a version has already been pushed to Brand Approved, and the user subsequently edits or adds a promo event in the Sandbox, the system is supposed to indicate that the version is now out of sync — via the banner "This version has been edited since it was pushed, so Brand Approved no longer matches what you see here," the **"Push again"** button, and the **"Edited since push"** tag with **"Re-push"** option in the Versions panel.

Currently, this indication does not appear immediately after the edit/add action — it only shows up after the user manually refreshes the page.

Additionally, when the user performs a **delete** operation on a promo event (instead of edit/add), this same "edited since push" indication does not appear at all, even after a refresh.

**Steps to Reproduce:**

*Case 1 – Edit/Add (delayed indicator):*

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open a promo version that has already been pushed to Brand Approved.
3. Edit an existing promo event, or add a new promo event.
4. Observe the page — check for the "edited since push" banner and "Re-push"/"Push again" indicators.
5. Refresh the page and check again.

*Case 2 – Delete (missing indicator):*

1. On the same pushed version, delete a promo event instead.
2. Observe the page and refresh — check for the "edited since push" banner and "Re-push"/"Push again" indicators.

**Expected Result:**

* After editing or adding a promo event on an already-pushed version, the "edited since push" banner, "Push again" button, and "Edited since push"/"Re-push" tags should appear immediately, without requiring a page refresh.
* After deleting a promo event on an already-pushed version, the same indicators should also appear (currently they don't appear even after refresh).

**Actual Result:**

* Edit/Add: Indicators only appear after a manual page refresh, not immediately after the action.
* Delete: Indicators do not appear at all, even after a refresh.
