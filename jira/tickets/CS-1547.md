## Description

In the Admin Panel's Brand section, attempting to bulk upload brands via CSV fails with a 400 (Bad Request) error. This occurs even when using the exact sample CSV template provided/downloadable on the site, indicating the upload functionality itself is broken rather than a data formatting issue on the user's end.

**Steps to Reproduce:**

1. Log in to Admin Panel.
2. Navigate to Brand section.
3. Download/use the sample CSV file provided on the site.
4. Attempt to upload the sample CSV file without modification via the "Upload Brand" (or equivalent) feature.
5. Observe that the upload fails with a 400 error.

**Expected Behavior:**
The sample CSV file should upload successfully without errors, since it is provided by the system as the correct format for bulk brand upload.

**Actual Behavior:**
Upload fails with a 400 Bad Request error, even with the unmodified sample file.
