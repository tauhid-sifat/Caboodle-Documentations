## Description

Clicking the **"Export Filtered Promo Events"** button does not trigger any file download. No file is generated or downloaded when clicked.

**Steps to Reproduce:**

1. Go to Promotional Management
2. Apply any filter(s) to Promo Events
3. Click **"Export Filtered Promo Events"**
4. Observe: no file is downloaded, no error shown

**Expected Behavior:** Clicking the button should generate and download a file containing the filtered Promo Events data.

**Actual Behavior:** No file is downloaded — button appears non-functional, with no visible error or feedback to the user.
