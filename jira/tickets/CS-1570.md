## Description

Add input validation to the Phone Number field in the Admin Panel so that only numeric digits and phone-number-relevant special characters are accepted. Any other characters should be rejected.

## Background

Currently, the Phone Number field does not appear to restrict input, allowing admins to enter invalid or non-phone-related characters. This can lead to inconsistent or unusable data.

## Acceptance Criteria

* Client-confirmed list of acceptable characters is documented and implemented.
* Field rejects any character outside the approved digit/special-character set.
* Appropriate error/feedback is shown to the admin when invalid input is entered.
* Validation applies consistently wherever phone numbers are entered/edited in the Admin Panel.
* Existing valid phone number data is unaffected (no forced re-validation/breakage of existing records, unless explicitly required).
