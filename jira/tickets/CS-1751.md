## Description

## Summary

Client feedback: the **Filter** button on the Simple Promotion screens is too small and easy to miss. It sits on the right side of the grid toolbar.

## Screens affected

* Simple Promotion **create** grid (right of the undo/redo toolbar).
* Simple Promotion **details** screen (right of the legend row).

## Expected

One of the following, to be agreed with design:

* **Option A:** make the Filter button larger and more prominent, with a clear icon, label and active-filter count badge.
* **Option B:** move Filter to the **top control area** of the create screen, next to Promotion Title / Plan year / Copy events / Fill this in Excel, so it is visible without scrolling.

## Acceptance criteria

* Filter is easy to find on both the create and details screens.
* The active-filter count badge stays visible.
* Placement is consistent with filter placement on other Caboodle screens.
