## Description

On the Category Review Tracker (Brand Report) screen, accessed via Broker Dashboard → Category Review, the "Hide Statuses" global filter does not function. This filter is intended to hide specific statuses across the entire report grid, but selecting a status to hide has no effect — the report continues to display all rows regardless of the selected status(es).

**Steps to Reproduce:**

1. Log in as a Broker.
2. Navigate to Category Review → Category Review Tracker (Brand Report).
3. Locate the global "Hide Statuses" filter (above/outside the individual column filters).
4. Select one or more statuses to hide.
5. Observe the report grid.

**Expected Result:**
Rows matching the selected/hidden status(es) should be removed from the report view immediately after the filter is applied.

**Actual Result:**
No change occurs in the report grid. All rows remain visible regardless of the status(es) selected in the global filter.
