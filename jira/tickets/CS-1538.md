## Description

In the Brand Retailer section, brokers are linked to products and UPCs, and each broker is assigned to one or more regions. The section includes a Region filter, but it currently lists **all** region options — including regions for which no broker is actually present for that retailer. This lets users select a region with zero relevant brokers, resulting in an empty or misleading result set.

**Steps to Reproduce:**

1. Go to the Brand Retailer section for a given retailer.
2. Open the Region filter.
3. Observe the list of available regions.
4. Select a region that has no broker assigned to that retailer.

**Expected Behavior:**
The Region filter should only display regions that have at least one broker actually linked to that retailer. Regions with no associated broker should be excluded from the filter options.

**Actual Behavior:**
The Region filter shows all regions regardless of whether a broker exists for that retailer in that region, allowing selection of irrelevant/empty regions.
