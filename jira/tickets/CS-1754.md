## Description

## Summary

Once a Simple Promotion has been created, the user **cannot edit an event's Start Date / End Date**. In **Edit** mode on the Simple Promotion details screen, there is no option to change the dates.

## Environment

Staging, brand **Apple Jacks**, Approved Promotions → any Simple Promotion → Edit

## Steps to reproduce

1. Create and submit a Simple Promotion with at least one monthly event (e.g. Jan 01/05 – 01/20).
2. Open it from Approved Promotions.
3. Click **Edit**.
4. Try to change the event's Start Date or End Date.

## Actual result

There is no date edit field or option. Dates cannot be changed after creation.

## Expected result

* In Edit mode, each event's **Start Date** and **End Date** can be edited, using a date picker or the same format as the create grid.
* The same validations as create apply: start ≤ end, and dates within the plan year (and within the event's month, if that rule applies).
* EDLP events keep their full-year range. Confirm whether their dates should be editable.
* After saving, the new dates show on the details screen and on the **Brand and Broker promotional calendars**, and `numberOfWeeksOfEvent` is recalculated.

## Notes

* The BE edit endpoint already supports updating event dates (QA guide §9.1). This is expected to be FE-only.
* CS-1708 Sc. 3 and Sc. 8 require that events stay editable, including their dates.
