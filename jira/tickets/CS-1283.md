* Manual uploads of actuals will **override any existing data**.

### **4. Required Columns**

The following columns are mandatory:

* Distributor
* Retailer
* Banner
* Product
* Year
* Type
* At least one month’s value

These required fields will be marked with **[*]** in the template.

---

### **5. Proposed Import Functionality**

* The import process will support **month-specific uploads**.
* Example: For uploading **March 2026** data, the required columns would be:* Distributor, Retailer, Banner, Product, Year, Type, and **March**
* This approach allows flexibility for users to upload data for specific months without requiring a full-year dataset.
