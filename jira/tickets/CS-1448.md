## Description

During the Banner SKU upload process, the system displays the validation error:

> **"The provided banner name doesn't match any existing Caboodle System banners."**

However, the same banner names can be found successfully when searched manually in the Caboodle system. This indicates that the upload validation logic is not matching banner names consistently with the manual search functionality.

The banner validation during file upload should use the same matching logic as the manual banner search to prevent false validation errors.

**Acceptance Criteria**

* Banner names that exist in the Caboodle system should be accepted during Banner SKU file upload.
* Banner validation logic should be consistent with the manual banner search functionality.
* Existing banner names should not trigger the error message:"The provided banner name doesn't match any existing Caboodle System banners."
* Invalid banner names should continue to show the appropriate validation error.
* Regression testing confirms that banner uploads work correctly for both valid and invalid banner names.
