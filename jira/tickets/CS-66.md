## Description

File name cuts off if a “.” is in the file name. Can we enable file/folder naming that incorporates a “.” ? Example 2.1.2022?  Currently it cuts the name off at 2

### Minhaz (2023-11-05T11:00:51.154+0600)

@Constance Wolfe,  Please avoid using dot(.) in file names. If you have a file named **this.is.a.test.xlsx**, 

change it **this_is_a_test.xlsx** or** this-is-a-test.xlsx** to avoid ambiguity between the file name and 

extension. Remember that a file name contains two parts: the name and the extension. The file name in 

this case is -  **this_is_test**, and the file extension is - **.xlsx**. When you use a dot in the file name, it 

becomes difficult to distinguish between the file name and the extension.
