## Description

When a brand sub-user is invited and accepts the invitation, they are expected to appear in the Notify Mail section of the Broker Onboarding page as an available/notifiable recipient. However, if a broker already has that page open when a new sub-user is assigned and accepts, the new sub-user does not appear in the list. The broker must manually refresh the page to see them.

## Steps to Reproduce

1. Log in as a broker and open the Broker Onboarding page (Notify Mail section), and leave it open.
2. In a separate session, invite a sub-user for a brand.
3. Have that sub-user accept the invitation.
4. Without refreshing, return to the broker's already-open Notify Mail section.

## Expected Result

The newly accepted sub-user should appear in the Notify Mail recipient list automatically (or via some live-update mechanism), without the broker needing to manually refresh the page.

## Actual Result

The Notify Mail recipient list on the already-open page does not update. The new sub-user is missing until the broker manually refreshes the page.
