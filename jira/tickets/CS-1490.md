## Description

In the file upload modal, clicking the **Dismiss** button does not close the modal as expected.

**Steps to Reproduce:**

1. Open the file upload modal (any upload flow)
2. Click the **Dismiss** button

**Expected Behavior:** Clicking Dismiss should close the modal and return the user to the previous screen.

**Actual Behavior:** Modal remains open — Dismiss button has no effect.
