## Description

The feature previously named **"Retail APL"** has been renamed to **"Brand Retail Item Status,"** but the **URL path** still reflects the old name. This needs to be updated for consistency.

**Current Behavior:**

* URL: `https://app.caboodleservices.com/retail-apl`

**Expected Behavior:**

* URL should be updated to: `https://app.caboodleservices.com/brand-retail-item-status`

**Reason for Change:**

* Keeps the URL path consistent with the current feature name ("Brand Retail Item Status") shown in the UI, avoiding confusion for users who reference/bookmark the URL.
