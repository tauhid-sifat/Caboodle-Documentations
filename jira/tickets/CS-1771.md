## Description

**Description:**
The Category Review list shows 10 records per page. When a user selects some records on one page (e.g., 3 records) and then moves to the next page, the same row positions (e.g., rows 1, 2 and 3) appear as already selected on the new page, even though the user never selected them there. The selection seems to be tracked by row position instead of by the actual record, so it carries over to different records.

This is risky for bulk actions like Notify Brands, since the user may unknowingly act on records they never selected.

**Steps to Reproduce:**

1. Log in as a Broker and go to Category Review.
2. On page 1, select 3 Category Reviews (e.g., the first 3 rows).
3. Go to page 2.
4. Observe the checkboxes on page 2.

**Expected Result:**
Page 2 should show a fresh list of 10 Category Reviews with nothing selected. Selections made on page 1 should not appear on page 2.

**Actual Result:**
The same row positions (1, 2 and 3) are shown as selected on page 2, even though those are different records.

**Acceptance Criteria:**

* Selecting records on one page does not mark any record as selected on another page.
* Each page loads with its own 10 records and no pre-selected checkboxes (unless the user selected those specific records).
* Bulk actions (e.g., Notify Brands) apply only to the records the user actually selected.
