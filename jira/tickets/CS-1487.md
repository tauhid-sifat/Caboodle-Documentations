## Description

The fields required in the **"Add Distributor APL" manual entry modal** do not match the columns present in the **CSV upload sample file**. This creates inconsistency between the two methods of adding Distributor APL data — some required fields in the manual form are missing or misnamed in the CSV template, and vice versa. Both need to be **synced**, and **mandatory fields should be clearly marked** in the CSV template.

---

**Current Mismatch:**

| Add Distributor APL Modal (Manual) | CSV Upload Template Columns |
| Warehouse * | Distribution Center |
| Region * | *(not present in CSV)* |
| Distributor Item Code * | Distributor Item Code |
| Product * | *(shown as "Product Description" in table — needs check against CSV)* |
| Wholesale Case Cost * | Wholesale Case Cost |
| Wholesale Unit Cost * | Wholesale Unit Cost |
| *(not in modal)* | Unit UPC |

**Issues Identified:**

1. **"Warehouse"** (modal) vs **"Distribution Center"** (CSV) — naming mismatch (also ties into the earlier ticket renaming "Warehouse" → "Distribution Center Name" — CSV template needs the same update).
2. **"Region"** is a **mandatory field** in the manual modal but is **missing entirely** from the CSV template — meaning CSV upload cannot capture this required data.
3. **"Unit UPC"** exists in the CSV template but has **no corresponding field** in the manual entry modal — unclear if this is required, optional, or intentionally manual-only.
4. No visual indication in the CSV template of **which columns are mandatory** (manual modal uses a red asterisk `*`, but CSV has no equivalent marker).

---

**Expected Behavior:**

1. **Field Parity:** Manual entry modal fields and CSV upload columns should represent the **same complete set of fields** (same names, same fields available in both — no field present in one but missing in the other, unless intentionally scoped as manual-only or upload-only, which should be explicitly confirmed).
2. **Naming Sync:** Column/field names should match exactly between modal and CSV (per naming convention already being applied elsewhere — e.g., "Distribution Center Name," "Distributor Code," "Product").
3. **Mandatory Field Marking in CSV:** CSV template should clearly indicate which columns are **mandatory** (e.g., asterisk `*` in header, a legend/note in the sample file, or highlighted formatting) — mirroring the mandatory indicators already used in the manual modal.
4. **Validation Alignment:** CSV upload validation logic should enforce the same mandatory field rules as the manual entry form (if Region is mandatory manually, it should also be mandatory — and present as a column — in CSV upload)
