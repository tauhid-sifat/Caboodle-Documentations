## Description

The API endpoint for fetching Brand Report due dates returns a `405 Method Not Allowed` error when called via `GET`, indicating either the endpoint doesn't support the `GET` method as currently configured, or the route/method mapping is misconfigured on the backend.

**Request Details:**

* **URL:** `https://caboodle-service-stg.caboodleservices.com/api/v1/brandreport/due-dates?startDate=2026-07-26&endDate=2026-12-23&pageSize=200&currentPage=1`
* **Method:** `GET`
* **Status Code:** `405 Method Not Allowed`

**Steps to Reproduce:**

1. Send a `GET` request to the above endpoint with the specified query parameters.
2. Observe response status: `405 Method Not Allowed`.

**Expected Behavior:**
The endpoint should accept `GET` requests and return the due dates data (likely feeding the "Due Dates" / "Upcoming Reviews" KPI card) with a `200 OK` response and the expected payload.

**Actual Behavior:**
Server responds with `405 Method Not Allowed`, blocking retrieval of due dates data.
