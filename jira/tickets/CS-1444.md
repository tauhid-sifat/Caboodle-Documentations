## Description

Frontend work for the CRM Data Upload improvements. Deliver a consistent upload and export experience across applicable CRM screens, and add filtering to applicable CRM data tables.

**What the user should see**

Upload

* Consistent upload control across CRM screens that support upload.
* In-progress indicator while uploading; success confirmation on completion.
* Clear, readable error messages when a file is rejected (wrong format, empty, too large) or the upload fails.

Export

* Export action available on CRM screens where export applies.
* Exporting downloads the data currently shown, including any active filters.
* Downloaded file opens correctly and column headers match the table.

Filter

* Filter controls on all applicable CRM data tables.
* Results update in place without a full page reload; refresh spinner shows correctly during refetch.
* Clearing filters returns the table to its default state; active filters are clearly indicated.

**Acceptance Criteria**

* Upload/Export UI behaves consistently across applicable screens.
* Filtering works on all applicable tables and drives the export payload.
* Loading, success, and error states are visible and correct.
* No regressions to existing CRM screens.
