## Description

The **Reset **modal in the Category Review Calendar currently does not display the **Reset Date** — instead, it shows **Review Start Date** and **Review End Date**, which are not relevant in this context. The modal needs to be corrected to remove the Review Start/End Date fields and display the Reset Date instead.

**Steps to Reproduce:**

1. Go to Broker Dashboard > Category Review Calendar.
2. Trigger the Reset action/modal for a review.
3. Observe the modal displays "Review Start Date" and "Review End Date" fields.
4. Note that "Reset Date" is not shown anywhere in the modal.

**Expected Behavior:**
The Reset modal should:

* **Remove** the "Review Start Date" and "Review End Date" fields.
* **Add/Display** the correct **"Reset Date"** field instead.

**Actual Behavior:**
Modal incorrectly shows Review Start Date and Review End Date, and is missing the Reset Date entirely.

**Acceptance Criteria:**

* Reset modal no longer displays Review Start Date or Review End Date.
* Reset modal correctly displays Reset Date.
* Reset Date value shown is accurate and reflects the correct data source.
