## Description

**Depends on:** [CS-1462](https://caboodleservices.atlassian.net/browse/CS-1462)

Switch existing admin screens over — chiefly the view showing which brands a given user has. Also sets up what the new Admin role can see: **Admins get exactly the same product areas a Broker gets.** Since Admin is a new role, if this isn't set, Admins sign in to an empty product.

**Acceptance Criteria:**

* The admin "brands of user" screen returns correct results for every role, including Admin.
* An Admin sees the same product areas a Broker sees — verified with a real Admin account, not a Broker one.
* Brand-side users are unaffected.
