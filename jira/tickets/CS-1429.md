## Description

As an admin, I want a screen that lists all emails the system has sent so I can review them and resend when needed. I can resend a single email, or select multiple emails and resend them together in bulk.

**Acceptance Criteria:**

* A "Sent Emails" screen lists all sent emails in a paginated table.
* Each row shows: recipient, subject, email type/category, sent date & time, and status (Sent / Failed).
* Each row has a "Resend" action that resends that single email.
* Rows have checkboxes with a select-all on the current page.
* A "Resend Selected" action appears when one or more rows are selected and resends them in bulk.
* Success/failure feedback is shown after resend (single or bulk), including partial-failure results for bulk.
* Loading and disabled states are handled during resend so the admin can't double-submit.

**Open questions:**

* Search/filters on the list (recipient, date range, status, type)?
* Confirmation dialog before bulk resend?
* View-email detail (preview subject/body) needed, or list-only for now?
