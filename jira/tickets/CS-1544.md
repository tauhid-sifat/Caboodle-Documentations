## Description

When a Category Review is sent to selected brand owners, the notification email displays the brand and category name (e.g., "Ahold Delhaize USA · Italian") as a clickable, hyperlinked, underlined blue text. This text should be static/plain text, as it is not intended to be an actionable link.

**Steps to Reproduce:**

1. Go to Category Review section.
2. Select a brand/category (e.g., Ahold Delhaize USA · Italian) and send the review to the associated brand owner(s).
3. Open the resulting "Category Review Notification from Your Broker" email as the recipient.
4. Observe the brand/category name under "BRAND REPORT NOTIFICATION" — it appears styled as a hyperlink (blue, underlined).

**Expected Behavior:**
The brand and category name should display as plain, non-clickable text, consistent with other static fields in the email (e.g., "National · December · 08/18/2026 7:09 AM").

**Actual Behavior:**
The brand and category name is rendered as a hyperlink/anchor tag, giving the impression it is clickable even though no action is intended.
