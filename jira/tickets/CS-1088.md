## Description

* Sometimes Reports will change product descriptions which can cause confusion when a user is using the product filter. 
* For example, they may not realize that there is more than one description in the product filter and not select the proper data which will not result in accurate data.  Or if the user knows there is more than one, it’s a cumbersome process to ensure they select the multiple descriptions. 
* Please update so only 1 product name is shown for the corresponding UPC Code.  To Clarify, each product has only 1 UPC code but could have more than 1 product description. 
* Additionally if the description is long, the name is cut off in the filter list. Please add a hoover option so the name will pop out.
