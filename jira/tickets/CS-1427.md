## Description

As an admin, I want to view all emails the system has sent so that I can review delivery history and resend emails when needed.

From the sent email list, I can select a single email and resend it, or select multiple emails and resend them together in bulk.

**Acceptance Criteria:**

* The admin can open a "Sent Emails" screen that lists all emails sent from the system.
* Each row shows key details: recipient, subject, email type/category, sent date & time, and status (e.g. Sent / Failed).
* The list supports pagination.
* Each email has a "Resend" action to send that single email again to the original recipient.
* The admin can select multiple emails using checkboxes (including a select-all on the current page).
* A "Resend Selected" action is available when one or more emails are selected, and sends all selected emails in bulk.
* After a resend (single or bulk), the admin sees a confirmation of success or failure.
* The resend uses the original email's content and recipient.

**Open questions (for grooming, not blockers):**

* Search/filter needs on the list (by recipient, date range, status, email type)?
* Should resend go to the original recipient only, or allow editing the recipient?
* Any limit on bulk-resend batch size?
* Confirmation dialog required before bulk resend?
