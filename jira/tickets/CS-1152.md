## Description

**Description:**
In EDLP promo creation, the "Every Day Allowance" field is not enforced as mandatory, allowing users to proceed without entering a value.

**Steps to Reproduce:**

1. Go to Trade Spend Sandbox (TSS).
2. Start creating a new EDLP promo.
3. Leave the Every Day Allowance field blank.
4. Continue to the next step / submit.

**Expected Result:**
The system should enforce validation and prevent proceeding without entering a value in the Every Day Allowance field.
