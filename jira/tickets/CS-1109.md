## Description

**Promotions > BAP> Cancelling Events**

1. Cancelling events will be done in the TSS
2. There will be a status of cancelled and the calculations from that event will be removed from the promotion but still visible in the details
3. User will complete the updates in TSS then push to BAP from the main TSS list
4. When pushed to BAP there will only be 1 version, not multiple versions > a display a new date Change “Created Date” to  Updated or Modified Date > What if multiple mushes in a single day? Should we also have a time stamp?
5. Once it’s pushed to BAP, it will show up on the Promo Calendar as Canceled – possibly with a color yellow
6. If user deletes an event, it will be removed without record from BAP when the event is pushed
7. Other status options requested by Bijoy :

* Cancelled
* Pending
* Didn’t Run
* Declined
* Retailer Approved
* Completed

 

Other  Notes

1. If a user wants to delete an entire promotion with all events, they can do so from the TSS. That will remove it from BAP
