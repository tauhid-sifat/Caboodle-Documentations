## Description

In the **Files section**, copying the **Image URL** and opening it should show a preview of the image. However, for the following image formats, the URL instead triggers a **download prompt**, treating the image as a generic file rather than rendering an in-browser preview:

* `.bmp`
* `.ico`
* `.svg`
* `.tif`
* `.webp`

**Steps to Reproduce:**

1. Go to Files section.
2. Upload/select a file of type `.bmp`, `.ico`, `.svg`, `.tif`, or `.webp`.
3. Copy the **Image URL**.
4. Open the copied URL in a browser (or wherever it's meant to preview).

**Actual Behavior:**

* For all 5 listed formats, opening the URL triggers a **download** instead of displaying an image preview.

**Expected Behavior:**

* Opening the Image URL for these formats should **render/preview the image** directly (same as other supported image types like `.jpg`, `.png`, `.gif`, etc.), not force a download.
