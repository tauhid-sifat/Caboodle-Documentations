## Description

* **steps to reproduce**:1. go to any list view with pagination (e.g., distributor banners with products)
  2. scroll to the bottom to view pagination controls
* **expected result**:
  pagination should display:* total number of pages (e.g., “Page 2 of 5”)
  * total number of items (e.g., “Items 11–20 of 47”)
  * a clear dropdown to select number of items per page
* **actual result**:
  only current page and item count dropdown are shown (e.g., “10”), but:* no total page count is displayed
  * no total items count is shown
  * UX feels incomplete and causes user confusion
