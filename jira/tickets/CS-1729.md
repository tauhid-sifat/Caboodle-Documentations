## Description

## Background

Currently, when a version is renamed or a new version is pushed to Brand Approved, the display does not clearly separate the stable family/promotion name from the specific version name. This has caused confusion in cases like Trade Spend Sandbox, where the promo name shown in Brand Approved doesn't visibly reflect which version's content is actually live.

## Requirement

In both the **Sandbox** and **Brand Approved** sections, the header of a promotion/version should always show:

* The **main (family) promo name in bold**
* Followed by the **version name/label** shown beside it (not bold), e.g. "v2 · Test 123 V2"

## Reference

See attached screenshot from Bubbies staging (Trade Spend Sandbox) for the expected display pattern:

* Bold: `Test 123 V2`
* Beside it: `v2 · Test 123 V2`
* Subtext: `Trade Spend Sandbox`

This should be consistent everywhere a promo/version name is displayed, in both Sandbox and Brand Approved views, so users can always tell the family name apart from the specific version currently being viewed/pushed.

## Acceptance Criteria

Sandbox view: main version name shown in bold, version label shown beside it.Brand Approved view: same bold name + version label pattern applied.Pattern is consistent across all promos regardless of how many versions exist.No regression to existing name/version display elsewhere (list, filters, reports).
