## Description

**Description:**
In the Versions panel, each version normally shows a **"Copied from"** attribute, displaying the name of the original version it was copied from. Currently, if the original (source) version is deleted, the "Copied from" reference also disappears from the version that was copied.

This should instead persist as a static text reference — even if the original version is deleted, the "Copied from" field should continue to show the name of the version it was originally copied from, so the history/lineage of that version is not lost.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open a promo with multiple versions (e.g., v1, v2, where v2 was created via "Copy from v1").
3. Confirm v2 shows "Copied from: v1" (or the relevant version name).
4. Delete v1 (the original/source version).
5. Check the "Copied from" field on v2.

**Expected Result:**
The "Copied from" field on v2 should continue to display the name of the original version (v1), even after v1 has been deleted — since this is meant to be a historical reference, not a live link to an existing version.

**Actual Result:**
Once the original version is deleted, the "Copied from" reference also disappears from the version that was copied from it.

**Acceptance Criteria:**

* Deleting a version should not remove the "Copied from" text/reference on any version that was copied from it.
* The "Copied from" field should be stored/displayed as a static name reference, independent of whether the original version still exists.
