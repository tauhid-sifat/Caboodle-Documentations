## Description

**Description:**
On the Distributor APL screen, when uploading a file, the system shows a "Success" toast notification even though some rows in the uploaded data were not actually uploaded (corrupted/invalid data). The "Upload" modal simultaneously displays the message "Some data were not uploaded. Click Here to see the corrupted data," which directly contradicts the "Success" toast shown at the same time.

This is misleading — a user glancing at the "Success" message could assume the entire file uploaded correctly and miss that some rows failed.

**Steps to Reproduce:**

1. Navigate to Distributor APL.
2. Click "Upload" and select a file that contains some invalid/corrupted rows along with valid rows.
3. Observe the notifications shown after upload completes.

**Expected Result:**
If any rows in the uploaded file fail to upload (corrupted/invalid data), the system should NOT show a generic "Success" toast. Instead, it should show a partial-success/warning message (e.g., "Upload completed with some errors" or similar), clearly indicating that not all data was uploaded successfully, consistent with the "Some data were not uploaded" message already shown in the modal.

**Actual Result:**
A "Success" toast appears at the same time the "Upload" modal shows "Some data were not uploaded. Click Here to see the corrupted data" — these two messages contradict each other.
