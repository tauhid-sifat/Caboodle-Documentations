## Description

* **steps to reproduce**:1. click **add** to create a new promo
  2. enter promo name and go through steps (step 1, 2, 3, 4) — skip any step as it allows in draft mode
  3. leave the page (e.g., go to another module or refresh)
  4. try to return to the same draft promo
* **expected result**:
  there should be a **clear way to view and resume draft promos** from the promo list page or a dedicated “drafts” section
* **actual result**:
  the only way to access the draft is by clicking **add**, re-entering the same/other name, and then the system redirects back to the draft* this flow is unintuitive and hidden from the user
