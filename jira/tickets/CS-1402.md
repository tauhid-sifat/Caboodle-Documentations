## Description

This feature lets users import **Distributor Sales Reports** (KeHE or UNFI) into Caboodle by uploading a CSV file and tagging it with the reporting period it belongs to.

---

#### What the user can do

* Upload a distributor sales report CSV file (KeHE or UNFI).
* Select which **distributor** the file is from (KeHE or UNFI).
* Select the **month** and **year** the report covers.
* Start the import and watch progress in real time.
* See whether the import succeeded or failed, and download a list of failed rows if there were any.

---

#### How the flow works (user perspective)

1. User opens the **Distributor Sales Reports** import screen.
2. User picks a **CSV file** from their computer.
3. User selects:* **Distributor** — KeHE or UNFI
* **Month** — January through December
* **Year** — any year between 1900 and 2100
4. User clicks **Start Import**.
5. The file uploads with a visible progress bar.
6. Once uploaded, the system begins processing the report.
7. The screen shows live progress: how many rows have been processed, how many succeeded, how many failed.
8. When finished:* **Success** → user sees a summary of the import.
* **Failure** → user sees an error message and, if available, a link to download a file listing the rows that failed.

---

#### Acceptance criteria

* The import screen has fields for **file**, **distributor**, **month**, and **year**.
* Only `.csv` files can be selected. Other file types are rejected with a clear message.
* **Distributor** options are limited to **KeHE** and **UNFI**.
* **Month** options are **January through December**.
* **Year** accepts values between **1900 and 2100**, and defaults to the current year.
* The **Start Import** button stays disabled until all four fields are filled.
* A progress bar is shown while the file is uploading.
* Once upload finishes, processing begins automatically.
* During processing, the user can see:* Current status (uploading / processing / completed / failed)
  * Progress percentage
  * Number of rows processed
  * Number of successful rows
  * Number of failed rows
* When the import **completes successfully**, the user sees a clear success state and can start a new import.
* When the import **fails**, the user sees the error message and, if available, a **Download error file** link.
* If the user tries to leave the page while uploading, they are asked to confirm.
* The month and year picked by the user determine which reporting period the data belongs to — the system does **not** read the period from inside the CSV file.
