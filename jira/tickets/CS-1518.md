## Description

In SPINS → **Item Ranking Report**, there are two related problems with the Import functionality:

1. The **Import CSV sample/template** does not match the structure/format of the **Export** file — meaning a file exported from the system cannot be successfully re-imported, and the provided sample template is inconsistent with actual export output.
2. Attempting to import a file results in a failure — the API call to `/spins/import-items-ranking` returns a **400 Bad Request** error, blocking the import entirely.

**Problem**

* **Format mismatch:** If Export and Import formats don't align (e.g., different column names, order, required fields, or data types), users cannot use exported files as a round-trip import source, defeating a common expected workflow (export → edit → re-import).
* **Import failure:** Beyond the format mismatch, the import API itself is failing with a 400 error, indicating the backend is rejecting the request outright — likely due to invalid/unexpected payload structure, missing required fields, or a validation mismatch between what the frontend sends and what the API expects.

**Impact**

* Users are fully blocked from importing Item Ranking data via SPINS.
* Breaks a core expected workflow: export → modify → re-import.
* If the sample template is outdated or incorrect, users following it will always fail, creating repeated support burden.

**Steps to Reproduce**

1. Navigate to SPINS → **Item Ranking Report**.
2. Export a file from the report.
3. Compare the exported file's structure/columns against the **Import sample/template** file.
4. Note discrepancies between the two formats.
5. Attempt to import a file (either the sample or an exported file).
6. Observe API call to `/spins/import-items-ranking` returns a **400 error**, and import fails.

**Expected Behavior**

* The Import sample/template should exactly match the Export file format, enabling a seamless export → edit → re-import workflow.
* Importing a correctly formatted file (matching the sample/export structure) should succeed via `/spins/import-items-ranking` without errors.

**Actual Behavior**

* Import sample format does not match Export file format.
* Import fails with a 400 error regardless, blocking the feature entirely.
