## Description

## Summary

When a broker viewed the Category Review calendar from inside a specific brand's environment, the calendar incorrectly showed other, unrelated brands as well. It should have only shown the one brand relevant to that environment. This has now been fixed so the calendar only displays the correct brand.

## Acceptance Criteria

* When viewing the Category Review calendar from within a specific brand's environment, only that brand appears in the calendar's brand list.
* No other brands' names, assigned contacts, or review/reset date information are visible in that context.
* If the current brand has no data for that review's calendar, the calendar list is simply empty (not populated with other brands).
* All other existing calendar functionality continues to work as before.
