## Description

In **Admin – Store List – Tools – Merge Stores**, clicking **Undo** fails with a **500 Internal Server Error** due to a backend PostgreSQL error: `column "id" does not exist`. This completely blocks the ability to undo a merge action.

**Steps to Reproduce:**

1. Go to Admin → Store List → Tools → Merge Stores.
2. Perform a merge action (or use an existing completed merge).
3. Click **Undo**.
4. Observe the failure.

**Actual Behavior:**

* Undo action fails with a **500 error**.
* Backend error returned:

```json
{
  "error": {
    "logID": "4609e324-3c75-43ef-b743-32f837db7da7",
    "statusCode": 500,
    "type": "Npgsql.PostgresException",
    "messages": {
      "Generic": "42703: column \"id\" does not exist\n\nPOSITION: 61"
    }
  }
}
```

**Expected Behavior:**

* Undo action should successfully revert the merge and restore the store(s) to their pre-merge state, without any server error.
