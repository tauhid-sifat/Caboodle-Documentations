## Description

**Depends on:** [CS-1462](https://caboodleservices.atlassian.net/browse/CS-1462)-[CS-1472](https://caboodleservices.atlassian.net/browse/CS-1472)

Remove the old arrangement now that everything runs on Organizations. Nothing here changes what users see — it's cleanup, and the only part of the project that can't easily be undone, so it's done in stages with a pause and check between each rather than all at once.

The first stage simply stops maintaining the old records while leaving them in place, so if anything was missed, we find out while the old data is still there to fall back on.

**Acceptance Criteria:**

* Before starting, confirmed that no part of the product still relies on the old arrangement.
* Before starting, old and new records confirmed to match exactly, in both directions.
* Removal happens in separate stages, each released independently, with an agreed settling period between them.
* A verified backup is taken before each stage that removes data.
* A full round of testing across every role and area is completed after the first stage.
* No user-visible change at any point.
* Known issues identified during this project and left for later are confirmed resolved or closed.
