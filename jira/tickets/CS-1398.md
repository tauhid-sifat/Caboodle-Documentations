## Description

In User Management → Users → Action → Assign Role, admins can assign roles to users. However, if a user already has an assigned role, the system shows an error message indicating that the existing role must be removed first before assigning a new one.

Currently, there is no option within the same modal to remove the existing role, unlike the brand assignment flow where remove functionality is available.

**Steps to Reproduce:**

1. Go to User Management → Users
2. Click Action → Assign Role for a user with an existing role
3. Try assigning a new role

**Actual Result:**

* System shows an error stating the existing role must be removed first
* No remove role option is available in the modal

**Expected Result:**
Either:

* Add a remove role option within the same modal so admins can directly remove and reassign roles
  **OR**
* Disable the Assign Role option for already assigned users with a proper tooltip/message explaining the restriction

**Impact:**
The current flow is incomplete and confusing, requiring additional/manual steps without providing users a clear way to proceed.
