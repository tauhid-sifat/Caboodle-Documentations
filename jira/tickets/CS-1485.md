## Description

When a user edits an existing comment on any row in Market Overview, after saving the edit, the comment no longer appears in its original place/row. This creates confusion — the comment appears lost even though it may still exist elsewhere.

**Steps to Reproduce:**

1. Go to Market Overview
2. Select any row with an existing comment
3. Click Edit on the comment, make a change
4. Save
5. Look for the comment in the same row/position — it's not there

**Expected Behavior:** After saving an edited comment, it should remain visible in the same row/position where it was originally added.

**Actual Behavior:** Edited comment disappears from its expected location after save — bad user experience, and users may assume their edit/comment was lost entirely.

**Impact:** Users lose confidence that their comments are saved correctly; could lead to duplicate comments or lost context on rows.
