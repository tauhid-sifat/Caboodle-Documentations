## Description

When a filter is already applied, adding a new entry that falls under that filter's category does not automatically appear in the filter options — the filter list stays stale until the user resets filters or refreshes the page. The same issue occurs on delete: a deleted entry doesn't disappear from the list until refresh/reset.

**Steps to Reproduce (Add):**

1. Apply a filter — e.g., Region: SoPack Allied, with Brands filter showing options A, B
2. Add a new entry for Brand C under the same Region (SoPack Allied)
3. Check the Brand filter options — "C" does not appear
4. Close/reset all filters or refresh the page — "C" now appears

**Steps to Reproduce (Delete):**

1. Apply any filter showing a list of entries
2. Delete an entry from that filtered list
3. Observe: the deleted entry still shows in the list
4. Refresh or reset filters — entry is now correctly removed

**Expected Behavior:** Filter options and filtered results should update dynamically in real time after add/delete actions — no manual refresh or filter reset should be required.

**Actual Behavior:** Both filter options (e.g., available Brands) and filtered result lists are stale after add/delete — user must refresh or reset filters to see accurate data.
