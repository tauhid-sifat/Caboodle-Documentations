## Description

**Description:**
This covers two related naming-propagation behaviors for the Sandbox versioning feature:

**1. Promo (family) name edit — should propagate immediately across versions:**
If a user edits the promo name from any version in the Sandbox, this change should immediately reflect across all other versions of the same promo family (since the promo name is shared at the family level, not per-version).

Additionally, once the version carrying this updated promo name is re-pushed to Brand Approved, the new promo name should also update in:

* Brand Approved
* Trade Spend Roll Up Report
* Monthly Report

**2. Version name edit — should propagate after re-push:**
If a user updates the name of a specific version, once that version is re-pushed to Brand Approved, the new version name should update in:

* Brand Approved
* Trade Spend Roll Up Report
* Monthly Report

**Steps to Reproduce / Verify:**

*Case 1 – Promo name:*

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open a promo with multiple versions.
3. Edit the promo name from any version.
4. Check whether the name updates immediately across all other versions.
5. Re-push the version to Brand Approved.
6. Check Brand Approved, Trade Spend Roll Up Report, and Monthly Report for the updated promo name.

*Case 2 – Version name:*

1. On the same promo, rename a specific version.
2. Re-push that version to Brand Approved.
3. Check Brand Approved, Trade Spend Roll Up Report, and Monthly Report for the updated version name.

**Expected Result:**

* Editing the promo name should immediately reflect across all versions of that promo family.
* After re-push, both promo name and version name changes should be reflected consistently in Brand Approved, Trade Spend Roll Up Report, and Monthly Report.

**Acceptance Criteria:**

* Promo name edit from any version updates all versions of the same family immediately (no refresh/re-push needed for this part).
* After re-push, updated promo name reflects in Brand Approved, Trade Spend Roll Up Report, and Monthly Report.
* After re-push, updated version name reflects in Brand Approved, Trade Spend Roll Up Report, and Monthly Report.
