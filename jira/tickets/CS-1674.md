## Description

In **Broker – Promotional Management**, regardless of which filter is applied, the output **always includes "Denver DIV - Safeway" and "Raley's"** banner information alongside the actual filtered results. This happens even though the **API response itself is correct** (i.e., does not include this extra data) — indicating the issue is on the **frontend rendering/state handling**, not the backend.

**Steps to Reproduce:**

1. Go to Broker → Promotional Management.
2. Apply any filter (banner, date, brand, etc. — specify which filter(s) tested).
3. Observe the output/result list.
4. Check the actual API response via network tab/logs for the same filter action.

**Actual Behavior:**

* UI output always shows **"Denver DIV - Safeway"** and **"Raley's"** banner data included in the results — regardless of the filter applied.
* API response (network tab) is **correct** and does **not** include this data for the applied filter.

**Expected Behavior:**

* UI should display **only** the data returned by the API for the applied filter.
* "Denver DIV - Safeway" and "Raley's" banner data should appear **only if** they are actually part of the correct filtered API response — not persist unconditionally.
