## Description

There are 3 Boxes when adding an EDLP to an Existing Promo. 

1. 1st Box, User enters the Event Name and selects the Products. 
2. 2nd Box User sees the items selected in the previous box. User Selects Multiple Edit to Select Fields. 
3. 3rd Box User chooses the Events, Banners, etc. When the Products Field is selected there is only 1 product is displayed. 

Box 1 - User chooses the products 



Box 2 User sees the products they selected in previous box 



3rd Box Multiple Edit, Only 1 product is displayed 



If User does not select that item & only enters a value Metric, it will apply the EDLP to all. 

Question: If User is selecting the products in the first box, do they need to do that in the second box? 

In the first box the User enters Event Name & selects Products. Should they only enter the name here then use the 2nd box for to select products? We should probably re-think this
