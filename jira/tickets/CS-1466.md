## Description

**Depends on:** [CS-1462](https://caboodleservices.atlassian.net/browse/CS-1462)

Switch the Distributor APL screens over to Organization-based access. Also clears out an old workaround: APL results were being filtered to hide broken records left behind by an earlier bug — no longer needed now that the underlying cause is fixed.

**Acceptance Criteria:**

* The APL list, its export, and the brand/category/distribution centre/region/UPC filters all return identical results for an unaffected user.
* All APL screens agree with each other on which brands a user can see (three were previously maintained separately and could drift apart).
* No blank or broken records appear in APL output.
* APL import and delete still work.
