## Description

## Context

The Category Review module in the Broker Dashboard allows users to add reviews to a calendar view. When a user selects a review with a specific Review Month (e.g., October) and clicks "Add To Calendar," the system should add that review only to the selected month. Instead, it's adding the review to multiple months (both October and November in the example).

## Problem / Goal

When adding a category review to the calendar:

* **Expected behavior:** Review is added only to the Review Month shown in the Category Review list (October)
* **Actual behavior:** Review is added to both October and November (2 months instead of 1)
* **Impact:** Calendar view becomes cluttered with duplicate entries; unclear which month the review actually applies to

The "Add To Calendar" button should respect the Review Month column and add the entry only to that single month.

### Steps to Reproduce

1. Go to Noble Broker Dashboard
2. Navigate to Category Review module
3. In the Category Review list, select a review with Review Month = October (e.g., Sprouts > Baby Products)
4. Click "Add To Calendar" button
5. Navigate to Category Review Calendar tab
6. Observe: Review appears in both October AND November columns (should only appear in October)

See attached screenshots for reference:

* Screenshot 1: Category Review list showing October review selected
* Screenshot 2: Category Review Calendar showing review incorrectly appearing in both October and November

## Implementation Notes

* Review the "Add To Calendar" function logic — likely adding review to both current month and next month
* Verify the Review Month value is correctly passed when clicking "Add To Calendar"
* Check date calculation logic (may be adding 1-month offset unintentionally)
* Test with multiple reviews across different months to ensure single-month behavior is consistent
* Confirm Category Review Calendar view properly filters by intended month

## Acceptance Criteria

* When adding a review with Review Month = October, it appears only in October on the calendar
* No duplicate entries appear in adjacent months
* Tested with reviews from multiple months (April, July, October, etc.)
* Category Review List month and Category Review Calendar month match after "Add To Calendar"
* "Add To Calendar" button works consistently across all reviews and retailers
