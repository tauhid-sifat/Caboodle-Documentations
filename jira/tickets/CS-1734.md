## Description

**Description:**
In the Trade Spend Sandbox, a user can mark any version as the reporting version using the **"Set as reporting"** action in the Versions panel. This is meant to control which version of the promotion feeds into the Trade Spend Roll Up Report.

However, currently the Trade Spend Roll Up Report does not respect this setting — it instead always pulls data from whichever version is currently pushed to the **Approved Promotion**, regardless of which version has been explicitly marked as "Set as reporting" in the Sandbox.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open a promo with multiple versions (e.g., v1, v2, v3).
3. Mark a version other than the currently Approved one as **"Set as reporting."**
4. Navigate to the Trade Spend Roll Up Report for the same promo/brand.
5. Compare the data shown in the report against the version marked as reporting vs. the version currently in Approved Promotion.

**Expected Result:**
The Trade Spend Roll Up Report should reflect the data from whichever version is marked **"Set as reporting"** in the Sandbox, independent of which version is currently in the Approved Promotion.

**Actual Result:**
The Trade Spend Roll Up Report reflects the data from the version currently pushed to the **Approved Promotion**, ignoring the version explicitly marked as "Set as reporting."
