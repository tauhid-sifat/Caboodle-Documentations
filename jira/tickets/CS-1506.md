## Description

**Description:**
The search field under **Product Specification → Categories** displays an incomplete placeholder text. The expected text should include the letter **“E”** at the end.

**Steps to Reproduce:**

1. Navigate to **Product Specification → Categories**.
2. Observe the search input field.
3. Check the placeholder text displayed inside the field.

**Actual Result:**
The placeholder text is displayed as **“Search category or product by nam”**, with the letter **“E”** missing.

**Expected Result:**
The placeholder text should be displayed correctly as:

**“Search category or product by name”**
