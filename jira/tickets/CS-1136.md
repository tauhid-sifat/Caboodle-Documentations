## Description

**Description:**
When creating a new promo event, if a banner is selected in Step 1, then the user proceeds to Step 2 and Step 3, and later returns to Step 1 to change the banner, data mismatch occurs on the Trade Spend Sandbox (TSS) page.

Steps to Reproduce:

1. Go to Trade Spend Sandbox → Add New Promo Event.
2. In Step 1, select a banner.
3. Proceed to Step 2 and Step 3.
4. Return to Step 1, unselect the previous banner, and select a new banner.
5. Save and check TSS page.

Observed Behavior:

* Data displayed in the TSS page mismatches with the newly selected banner.
