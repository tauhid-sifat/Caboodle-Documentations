## Description

Currently, the **"Add New Note"** functionality in the Promotional Calendar (within the Brand Environment) is only available to the **Broker Owner** role. **Sub-Brokers** do not have access to this feature — the "Add New Note" button is **not available** to them at all. This is a new requirement to **extend note creation access to Sub-Brokers** as well.

**Current Behavior:**

* **Broker Owner** login → Brand Environment → Promotional Calendar: "Add New Note" button is **present and functional**.
* **Sub-Broker** login → Brand Environment → Promotional Calendar: "Add New Note" button is **not present** — Sub-Brokers cannot add notes at all.

**Requirement:**

* Add the **"Add New Note"** button/feature to the Promotional Calendar for **Sub-Broker** logins as well, so they have the same note-creation capability as the Broker Owner.

**Steps to Reproduce (Current Gap):**

1. Log in as a **Sub-Broker**.
2. Go to Brand Environment → Promotional Calendar.
3. Observe that the "Add New Note" button is missing at the top.
4. Log in as **Broker Owner** and repeat steps 2 — confirm the button **is** present.

**Business Justification:**

* Sub-Brokers are actively working within the Brand Environment and need the ability to add notes to Promotional Calendar entries as part of their regular workflow — currently blocked from doing so, limiting their ability to collaborate/document within the platform.

**Impact:**

* Enables Sub-Brokers to fully participate in Promotional Calendar documentation/workflow, improving collaboration and reducing dependency on Broker Owners solely for note-taking.
