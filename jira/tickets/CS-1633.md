## Description

Update the bucket structure of the "Upcoming Reviews" KPI card in Brand Report. Currently the card lists 7 separate monthly buckets; this needs to be consolidated into 4 buckets with updated naming, as detailed below.

**Requirements:**

| Current | New |
| Past Due | Past Due *(unchanged)* |
| 1 Month | **Next 30 Days** |
| 2 Months + 3 Months | Combined → **60-90 Days** |
| 4 Months + 5 Months + 6 Months | Combined → **4-6 Months** |

**Confirmed Date Range Logic (relative to today):**

| Bucket | Date Range |
| **Past Due** | Any Review Start Date **before today** (all overdue, no lower limit) |
| **Next 30 Days** | **Today** through **+30 days** |
| **60-90 Days** | **+31 days** through **+90 days** |
| **4-6 Months** | **+91 days** through **rest** (no upper limit) |

**Acceptance Criteria (updated):**

* **Past Due:** Review Start Date is any date before today (no lower bound).
* **Next 30 Days:** Review Start Date falls between today and today+30 days (inclusive).
* **60-90 Days:** Review Start Date falls between today+31 days and today+90 days (inclusive).
* **4-6 Months:** Review Start Date falls on or after today+91 days (no upper bound).
* Bucket ranges are mutually exclusive — no date falls into more than one bucket.
* Clicking each bucket filters the table correctly based on these exact ranges.
* Clear button resets the filter and restores full unfiltered view.
