## Description

The goal here is to implement a status feature for each promo. There should be 2 statuses.  1 Draft, the other Confirmed.  All promos so default to Draft.  User can change to Confirmed.  

If the promotion is in Draft status, it does not push to promotional calendar.  Only if user changes status from Draft to Confirmed does it push to promotional calendar.  

We envision a column on the All Promotions page that has the status listed. Each promotion defaulting to Draft.  If the user selects the check box next to a Promo Name then clicks the Confirmed button, it changes the status from Draft to Confirmed and pushes to the Promotional Calendar. 

Trade Spend Roll Up - The promos listed in this report also have a column for Status which the user can filter
