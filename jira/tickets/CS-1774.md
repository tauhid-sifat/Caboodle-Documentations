## Description

**Description:**
In the Simple Promotion flow, events are entered in the Excel-style promo event grid. An event whose dates run into a later month is split into one event per month covered (the screen shows "3 entries run into a later month and are sent as one event per month covered"). After the simple promotion is created, the events list shows each split event. The name of each split event correctly shows its own date range (e.g., "Within Jan-March 3/1-3/9"), but the date range shown under the name is the **full month** instead of the real split dates.

**Test data used (promotion "CS-1773 - Test", plan year 2026):**

| Entered in grid | Split event name | Date shown (wrong) | Date it should show |
| Within Jan-March, 01/21 to 03/09 | Within Jan-March 1/21-1/31 | 01 Jan – 31 Jan | 21 Jan – 31 Jan |
| Within Jan-March, 01/21 to 03/09 | Within Jan-March 2/1-2/28 | 01 Feb – 28 Feb | 01 Feb – 28 Feb (correct) |
| Within Jan-March, 01/21 to 03/09 | Within Jan-March 3/1-3/9 | 01 Mar – 31 Mar | 01 Mar – 09 Mar |
| Withinh Feb-March, 02/11 to 03/10 | Withinh Feb-March 2/11-2/28 | 01 Feb – 28 Feb | 11 Feb – 28 Feb |
| Withinh Feb-March, 02/11 to 03/10 | Withinh Feb-March 3/1-3/10 | 01 Mar – 31 Mar | 01 Mar – 10 Mar |

**Steps to Reproduce:**

1. Start a Simple Promotion and open the promo event grid.
2. Enter an event that starts in one month and ends in a later month (e.g., Start 01/21, End 03/09).
3. Create the simple promotion so the system splits it into one event per month.
4. Open the created events list and check the date range under each split event name.

**Expected Result:**
Each split event shows its own real start and end date, matching the date range in its name (e.g., "Within Jan-March 3/1-3/9" shows 01 Mar – 09 Mar).

**Actual Result:**
Each split event shows the full month (e.g., 01 Mar – 31 Mar). The first split (if it does not start on the 1st) and the last split (if it does not end on the last day of the month) are wrong.

**Acceptance Criteria:**

* First split starts on the original start date, and later splits start on the 1st of their month.
* Last split ends on the original end date, and earlier splits end on the last day of their month.
* The date range under the event name always matches the date range in the event name.
