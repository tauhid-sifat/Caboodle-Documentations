## Description

## Summary

Client feedback: the column headers on the Simple Promotion screens don't show whether a value is a **percentage (%)** or a **dollar amount ($)**. Some headers already have a unit (e.g. "OI%", "TPR $") and others don't. This causes confusion. For example, EDA is per-unit $ and gets multiplied by the case pack, and users may enter a per-case amount by mistake.

## Screens affected

* Simple Promotion **create** grid and the Excel **Export** file
* Simple Promotion **details** screen

## Expected headers

| Current | New |
| Everyday Allowance / EDA | Everyday Allowance ($ / unit) / EDA ($ / unit) |
| OI% / OI % | OI (%) |
| MCB | MCB (%) |
| Scan Amount / Scan | Scan ($ / unit) |
| TPR $ | TPR ($) |
| Ad/TPR Fees / Ad/TPR | Ad/TPR Fees ($) |
| Case cost, + Markup, Allowance, Net case, Net unit | Case cost ($), + Markup ($), Allowance ($), Net case ($), Net unit ($) |
| Profit | Profit (%) |

## Acceptance criteria

* Every numeric column header shows its unit (%, or $ and whether per unit).
* The unit format is the same on the create grid, the details screen and the Excel export/import template.
* Headers still fit without breaking the layout.
