## Description

# Reports | Brand Broker Market Overview | Sort Function - Date/Time Doesn't Work, List Needs a Date

RBMO1 | Bug | Priority: TBD | Status: New

## User Story

As a Brand/Broker user of the Broker Market Overview report,

I want the sort function (including the Date/Time column) to work, and the list to actually show a date,

So that I can sort and read entries by date.

## Description

In the Broker Market Overview report, there is a Date/Time column but the sort does not work, and it is unclear whether an actual date is shown on the list. Users expect to sort by date and see a date value per row.

## Acceptance Criteria

### Scenario 1: Date Visible on List

* Given** the Broker Market Overview list renders

* When** the user views rows

* Then** each row shows a clear date value (not just an unusable/missing Date/Time)

### Scenario 2: Sort by Date Works

* Given** a sortable Date/Time column

* When** the user clicks to sort by date (asc/desc)

* Then** the list reorders correctly by date

### Scenario 3: Other Sorts Unaffected

* Given** the fix

* When** other columns are sorted

* Then** sorting works as expected (no regression)
