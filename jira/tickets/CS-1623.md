## Description

# Reports | Brand Distributor Report | Rolling Latest 12 Months Unless Filtered

RDR2 | New Requirement | User Story | Priority: TBD | Status: New

## User Story

As a Brand user of the Distributor Report,

I want the report to show only a rolling latest 12 months by default,

So that I see current data without being overwhelmed by old history (unless I deliberately filter for a different range).

## Description

By default, the Brand Distributor Report should display only a rolling latest 12 months of data. Users can override this with an explicit date filter to view a different range. This matches the broader 'rolling 12 months for all Reports & Grids' rule.

This is a direct match to Jira CS-1274 ('Show only rolling 12 months for all Reports & Grids') - RDR2 is the working ticket for that rule as applied to the Distributor Report.

## Acceptance Criteria

### Scenario 1: Default Rolling 12 Months

* Given** the Distributor Report loads with no custom date filter

* When** it renders

* Then** only the trailing 12 months of data are shown

### Scenario 2: Override via Filter

* Given** the default view

* When** the user applies a different date filter (e.g., specific year or range)

* Then** the report shows that range instead of the rolling 12 months

### Scenario 3: Consistency

* Given** other Reports/Grids

* When** they apply the same rule

* Then** the Distributor Report behaves consistently with the rolling-12-month standard
