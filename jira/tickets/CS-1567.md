## Description

In the Admin Panel's brand owner invitation section, a brand is expected to appear faded/disabled once it has an assigned owner (i.e., an invitation has been accepted). Currently, this state only updates correctly after a manual page refresh. If an admin sends an invite and the brand owner accepts it while the admin is still on the page, the brand list does not reflect the change — the brand remains selectable, and the admin can send a duplicate invitation for a brand that already has an owner.

## Steps to Reproduce

1. Log into the Admin Panel and navigate to the User Invitation section.
2. Select a brand that currently has no assigned owner and send an invitation to a brand owner.
3. Have the invited user accept the invitation (in a separate session/browser).
4. Without refreshing the admin panel page, return to the brand invitation list.

## Expected Result

Once the brand owner accepts the invitation, the corresponding brand should automatically appear faded/disabled in the admin's invitation list, preventing the admin from selecting it again — without requiring a manual page refresh.

## Actual Result

The brand remains active/selectable in the admin's invitation list. The admin is able to select the same brand and send another invitation, even though an owner has already been assigned.
