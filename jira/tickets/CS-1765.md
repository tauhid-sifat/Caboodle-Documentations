## Description

On the **Admin → CRM Data Upload → Price Lists** page ("All Price List" table), the table shows a **Category Name** column (e.g. SS1, BS1, KS1, HS1). There is currently no way to filter the price list by category.

This task covers the **backend** work: add a **Category Name** filter to the Price Lists API so the frontend can offer it in the **Filter** panel.

**Requirements**

1. Add an optional **category** filter parameter to the Price Lists listing API used on the Admin "All Price List" page.
2. The filter should accept **multiple categories** (multi-select) and return price list rows matching **any** of the selected categories.
3. The category filter must work **together with the existing filters** (Product Name, Distributor Delivery Method, Brand Name, Start Date, etc.), combined with AND logic.
4. **Pagination and total count** must reflect the filtered results.
5. **Search and sorting** must continue to work with the category filter applied.
6. The **Export Price List** API should respect the same category filter, so the exported file matches what is shown on screen.
7. Provide (or extend) a **filter options endpoint** that returns the list of available Category Names for the dropdown. If filters on this page are dynamic, the category options should narrow based on the other applied filters.

**Acceptance Criteria**

* Calling the Price Lists API with one category (e.g. `SS1`) returns only rows with that Category Name.
* Calling it with multiple categories (e.g. `SS1`, `BS1`) returns rows for any of them.
* Calling it without the category parameter returns the same results as today (no regression).
* Combining the category filter with other filters returns the correct intersection.
* Total count and pagination are correct for filtered results.
* Exported data matches the filtered table data.
* An invalid or non-existent category returns an empty result set, not an error.
