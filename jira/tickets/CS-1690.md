## Description

### The following changes are required for the **Trade Spend Roll-Up Report**:

1. **Add Month Filter*** Add a month filter to the Trade Spend Roll-Up Report.
* The report data should be filtered based on the selected month.
2. **Add Total Spend Column*** Add a new **Total Spend** column to the following DTO/calculation models:* `BannerReportDTOs`
  * `PerBannerTotalCalculations`
  * `totalReportCalculations`
* The **Total Spend** value should follow the same calculation logic currently used on the **Promotion Details** page.

### Expected Outcome

The Trade Spend Roll-Up Report should allow users to filter the report by month and display the **Total Spend** value consistently with the existing calculation on the Promotion Details page.
