## Description

The upload result status does not correctly reflect the outcome of the row-level processing. When **all rows in the uploaded file fail** (including cases of wrong/invalid headers), the system incorrectly shows **"Partially Done"** instead of **"Failed"**. The status should only show "Partially Done" when there's a genuine mix of successful and failed rows.

**Steps to Reproduce:**

1. Go to Category Review → Upload File.
2. Upload a file where **all rows fail** (e.g., due to wrong header, invalid data in every row, etc.).
3. Observe the resulting status message.

**Actual Behavior:**

* Status shows: **"Partially Done"** — even though 0 rows succeeded and all rows failed.

**Expected Behavior:**
Status should be determined based on the success/fail ratio:

| Scenario | Expected Status |
| All rows fail (e.g., 0/8 success, 8/8 fail) | **Failed** |
| All rows succeed (e.g., 8/8 success) | **Done / Success** |
| Mixed results (e.g., 5 success / 3 fail, or 3 success / 5 fail) | **Partially Done** |

**Additional Requirement:**

* Update the error message shown for **wrong/invalid header** cases during upload to be more specific and clear (currently generic/unclear — needs improved wording so users understand exactly what's wrong with the header).
