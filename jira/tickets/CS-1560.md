## Description

Currently, when a user tries to accept an invitation that is no longer valid, no proper error message is shown. We need to detect the invalid state and show the user a clear, specific message for each case:

1. **Cancelled** — This invitation has been cancelled.
2. **Expired** — This invitation link has expired. Please request a new invitation.
3. **Already registered** — This invitation has already been accepted. Try logging in instead.
