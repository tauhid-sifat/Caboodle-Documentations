## Description

In **CRM → Distributors**, when adding a new distributor, both a **success message** and an **error message** are displayed together — even though the distributor is actually added successfully. Since the creation succeeds, showing the error message is misleading and serves no purpose.

**Impact**

* Users may think the distributor creation failed and attempt to re-add it, potentially causing duplicate entries or unnecessary support inquiries.
* Undermines trust in confirmation messages across the CRM module.
* Creates a confusing, unpolished UX moment with contradictory feedback.

**Steps to Reproduce**

1. Navigate to **CRM → Distributors**.
2. Add a new distributor with valid details.
3. Submit the form.
4. Observe both a **success message** and an **error message** appear together.
5. Verify in the distributor list that the distributor was, in fact, added successfully.

**Expected Behavior**

* Only the **success message** should be shown when a distributor is added successfully.
* No error message should appear unless the creation actually fails.

**Actual Behavior**

* Both success and error messages are shown simultaneously, despite the distributor being created successfully.
