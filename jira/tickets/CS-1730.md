## Description

**Description:**
Following the parent bucket rename from "Past Due" to "Current" on the "Upcoming Reviews" KPI card in Brand Report, the child heading currently still shows "Overdue" for the rows/items within that bucket. This creates a mismatch — the parent says "Current" while the child says "Overdue."

**Context / Discussion:**
Client asked whether the child headings should either match the parent ("Current") or be removed entirely, whichever is easier.

Decision: Remove the word "Overdue" from the child headings rather than replacing it with "Current," since the bucket includes all dates up to and including today — not just the current date — so "Current" would not accurately describe the full range either.

**Expected Result:**

* Remove the "Overdue" word/label from the child headings under the renamed "Current" bucket on the Upcoming Reviews KPI card.
* Do not replace it with "Current" (would be inaccurate since the bucket spans all dates up to and including today, not just today).
* Parent heading ("Current") and child heading should no longer be mismatched/contradictory.

**Acceptance Criteria:**

* Child heading no longer displays the word "Overdue."
* Child heading does not display "Current" either (per client discussion, would be inaccurate).
* No functional/date-range logic changes — this is a labeling/naming update only.
