## Description

Refactor the existing import-export functionality to be more generic and reusable across different data models. This includes:

* Implementing a flexible structure to handle various data types dynamically.
* Ensuring seamless mapping between DTOs and database entities.
* Supporting configurable column mappings for imports.
* Improving error handling and logging for better debugging.
* Maintaining backward compatibility with existing implementations.

The goal is to make the import-export process adaptable for future enhancements and additional data models with minimal code changes.
