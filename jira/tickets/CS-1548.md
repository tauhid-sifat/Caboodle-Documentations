## Description

Update the **Trade Spend Rollup Report** based on the issues identified by the client.

The client reported that the Rollup Report is currently calculating **Total Spend / Net Revenue**, whereas it should calculate **Total Spend / Gross Revenue**, consistent with the calculation used in the Trade Spend module.

The same promotion is currently showing the **same dollar amounts but different percentages** between the Sandbox Trade Spend view and the Trade Spend Rollup Report. The calculation logic should be reviewed and aligned.

## Requirements

### 1. Update Total Spend Percentage Calculation

* Change the percentage calculation in the Trade Spend Rollup Report from:
  **Total Spend / Net Revenue**
* To:
  **Total Spend / Gross Revenue**
* Ensure the calculation is consistent with the Trade Spend module.
* Verify that the percentage displayed for the same promotion is consistent between the Sandbox/Trade Spend view and the Rollup Report.
* The existing dollar amounts should remain unchanged unless they are affected by the calculation correction.

### 2. Remove Duplicate "Planned Net Dollar" in Retails

* The **Retails** section currently contains a duplicate **Planned Net Dollar** field/column.
* Remove the duplicate and ensure only one **Planned Net Dollar** is displayed.
* Verify that removing the duplicate does not affect the underlying data or calculations.

### 3. Verify Bubbies → ABSCO Denver

* Specifically verify the data/calculations for:
  **Bubbies → ABSCO Denver**
* Confirm that the Trade Spend Rollup Report is displaying the expected spend, revenue, and percentage values for this case.
* Use the client-provided screenshots as reference.

### 4. Add New Column

* Add the new column requested by the client.
* The exact column name/logic should be confirmed from the attached screenshot or client specification before implementation.
* Ensure the new column is populated with the appropriate data and follows the existing report formatting and calculation conventions.

## Acceptance Criteria

* Trade Spend Rollup Report calculates the percentage using **Total Spend / Gross Revenue**.
* Percentage values are consistent with the Trade Spend/Sandbox view for the same promotion.
* No duplicate **Planned Net Dollar** is displayed under Retails.
* **Bubbies → ABSCO Denver** data has been verified and displays the expected values.
* The requested new column is added and populated correctly.
* Existing dollar amount calculations are not unintentionally changed.
* Regression testing is completed for other promotions and retailers to ensure the calculation change does not introduce discrepancies.
* Client-provided screenshots are used as reference during development and QA.
