## Description

During QA of master data renames, four expected propagations failed. After saving a change and waiting for the background job, downstream screens still show the old values.

**Issue 1: Banner rename (CRM → Banners) does not reach sales and report tables** *(Test 1)*

Steps: CRM → Banners → edit banner → change name → Save → wait [X] minutes.

Test data: Retailer: [name]. Banner: [old name] → [new name].

Expected: The Banner column shows the new name in Mapped Data (KeHE / UNFI), Distributor Sales Records, Trade Spend → Monthly Report and Sandbox → Monthly Report.

Actual: All four screens still show the old banner name. Store List (DataHub) updates correctly.





**Issue 2: Store edit (DataHub → Store List) does not update Distributor Sales Records** *(Test 4)*

Steps: DataHub → Store List → edit a store → change [Retailer / Banner / Region / Store Name] → Save → wait [X] minutes.

Test data: Store: [name / Cust No]. Field changed: [old] → [new].

Expected: DSR rows for that store only show the new values, including Region.

Actual: DSR rows for the store still show the old values [specify: all fields, or Region only].



**Issue 3: Store Name change does not update the matching Entity Resolution entry** *(Test 4, "Store Name only")*

Steps: DataHub → Store List → edit a store → change Store Name only → Save → wait [X] minutes → open DataHub → Entity Resolution.

Test data: Store name: [old] → [new].

Expected: The matching Store entity in Entity Resolution shows the new Display Name.

Actual: The Entity Resolution entry still shows the old store name. [Mapped Data / DSR store name: updated / not updated]



**Issue 4: Retailer rename in Entity Resolution does not update Store List** *(Test 5)*

Steps: DataHub → Entity Resolution → edit a Retailer entity → change Display Name → Save → wait [X] minutes → open DataHub → Store List.

Test data: Retailer entity: [old] → [new].

Expected: The Retailer column in Store List shows the new name (along with Mapped Data, DSR and Monthly Reports).

Actual: Store List still shows the old retailer name. [Mapped Data / DSR / Monthly Reports: updated / not updated]
