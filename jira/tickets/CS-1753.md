## Description

## Summary

On the Simple Promotion create grid, **"Copy events to other months" does not work when a filter is applied**. Without a filter, Copy works.

## Environment

Staging, brand **Apple Jacks**, Promotional Planning → Simple Promotion → create

## Steps to reproduce

1. Open the Simple Promotion create screen and fill a Jan event on a few rows.
2. Open **Filter** and apply a filter (e.g. Retailer = ABSCO, or Category = Water).
3. Select the Jan event rows that are visible.
4. In "Copy events to other months", pick Feb (or several months), then click **Copy**.

## Actual result

Copy does not work while the filter is applied. The events are not copied to the target month(s).

## Expected result

* Copy works the same with or without a filter.
* Only the **selected, visible (filtered) rows** are copied. Hidden rows are not affected.
* If the **Months** filter hides a target month, either the copy still lands in that month (visible after Reset), or the user sees a clear message.
* After Reset, the copied events are in the right rows and months.

## Also check

* Copy with a Retailer, Category, Product, Item Status or Months filter, and with combined filters.
* Row mapping after filtering: the copy must land on the same product line, not the row at the same visual position.

## Related

* Copy end date is blank when the day doesn't exist in the target month (01/30 → Feb). This is a separate issue that has not been logged yet.
