## Description

Add note-taking to each Brand Report row with two visibility levels: internal notes (brokerage-only) and external notes (visible to the brand). External notes and system-logged activity should surface on the brand side via a KPI count and a calendar indicator.

**Acceptance Criteria (Given/Then):**

* **Given** a brand report row, **when** a user adds a note, **then** they can choose to mark it as *Internal* (brokerage-only) or *External* (visible to the brand).
* **Given** an external note is added, **then** it appears on the brand-facing side of the report.
* **Given** one or more external notes exist on a brand report, **then** the brand-side **Notes KPI** reflects the correct count.
* **Given** a brand report has any notes (or notes activity), **then** the corresponding **calendar cell** displays a notes indicator.
* **Given** the initial email for a brand report is sent, **then** the recipients are automatically logged as an **internal note** (send log) — no manual entry required.
