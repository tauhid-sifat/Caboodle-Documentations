## Description

In the Retail Report section, the filter dropdowns are showing extra options that don't actually correspond to any data present in the results table. Additionally, filters are not cascading — selecting one filter doesn't narrow down the available options in the other filters, so users can select combinations that return no matching data or feel disconnected from what's actually in the table.

**Problem**

1. **Stale/orphaned filter options** — Filter dropdowns list values that don't exist in the current table dataset, making it unclear to users which filters are actually applicable or "live."
2. **No filter interdependency (non-cascading filters)** — Applying one filter doesn't reduce/update the option sets of the remaining filters. Users can pick filter combinations that yield zero results, or see irrelevant options that don't reflect the already-filtered context.

**Impact**

* Users lose trust in the filter/report accuracy ("why is this option here if there's no data for it?").
* Increases user effort — manual trial-and-error to find valid filter combinations.
* May indicate filter options are being pulled from a static/master list rather than being derived dynamically from the active dataset.

**Steps to Reproduce**

1. Navigate to Retail Report section.
2. Open any filter dropdown — note options present that don't appear in the table.
3. Apply a filter (e.g., Filter A = X).
4. Open a second filter dropdown (Filter B) — note it still shows all original options instead of only those relevant to Filter A = X.

**Expected Behavior**

* Filter options should be dynamically generated based on the data currently available in the table (no orphaned/extra options).
* Filters should cascade: selecting a value in one filter should update the available options in the remaining filters to reflect only combinations that produce valid results.

**Actual Behavior**

* Filter dropdowns include options unrelated to the table's actual data.
* Filters operate independently of one another with no cascading/narrowing behavior.
