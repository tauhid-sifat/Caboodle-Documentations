## Description

When the **"Add SKU"** or **"Add Promo Event (Quick)"** modal is open, the **"Add"** button (and related action buttons) on the underlying page remain enabled/clickable. This allows the user to trigger another "Add" action while the current modal is still open, which can lead to overlapping/duplicate modals or unexpected behavior. Similarly, the "Add EDLP" modal showing "All products have been added to an EDLP event" also appears layered with other open modals simultaneously.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Open a promo and go to "View & Edit Promo Events Details."
3. Click "Add" → "Add SKU" (or "Add Promo Event (Quick)") to open its modal.
4. While that modal is still open, check whether the "Add" button on the underlying page is still enabled.
5. Click "Add" again without closing the current modal.

**Expected Result:**
While the "Add SKU" or "Add Promo Event (Quick)" modal (or any similar add/action modal) is open, the "Add" button on the underlying page should be disabled. It should only become enabled again once the user closes the currently open modal.

**Actual Result:**
The "Add" button remains enabled even while a modal is already open, allowing multiple modals to be triggered/opened simultaneously.
