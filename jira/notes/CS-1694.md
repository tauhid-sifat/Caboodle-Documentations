## Description

In **Broker Dashboard – Brand Retail Item Status**, the **Filtered Export** works correctly when using the standard **filter fields**, but **fails when the filtering is done via the normal Search bar** (list search) instead.

**Steps to Reproduce:**

1. Go to Broker Dashboard → Brand Retail Item Status.
2. Use the **Search bar** (not the filter fields) to search/filter the list (e.g., search by item name, SKU, etc.).
3. Trigger **Filtered Export** on the search-filtered results.
4. Check the exported file.

**Actual Behavior:**

* Filtered Export **does not work correctly** when the list is filtered via the **Search bar**.

**Expected Behavior:**

* Filtered Export should respect **any active filtering method** — whether applied via filter fields **or** the Search bar — and export only the data matching the currently displayed/searched results.
