## Description

Dropdown modal requires second click on same dropdown to close

* **Steps to Reproduce:**1. Click on any dropdown (e.g., add, sort by) to open the modal.
  2. Click anywhere outside the dropdown/modal.
* **Expected Result:**
  The modal should close automatically when clicking outside.
* **Actual Result:**
  The modal remains open. It only closes if the same dropdown is clicked again.
