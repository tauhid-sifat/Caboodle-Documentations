## Description

When editing all SKUs in Step 2 of TSS, the max store number validation is inconsistent between the "edit all" field and the individual product fields.

**Steps to Reproduce:**

1. Go to TSS and start creating/editing a promo event.
2. In Step 2, select Haggen brand (max store = 15).
3. Use **Edit All SKU** option and input store number = 16.
4. The system auto-corrects the value to 15 (as expected).
5. Scroll down to view the individual SKU fields.

**Expected Result:**
Each SKU’s store count field should also reflect the corrected value (15) consistently.

**Actual Result:**
The "edit all" field correctly changes to 15, but the individual product store count fields show 16.
