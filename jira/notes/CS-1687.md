## Description

When using **Find Nearby Stores → Near an Address**, if the user searches using an address that **exactly matches** an existing store's location, the resulting store should show **0 m distance** (since it's the same location). However, it currently shows a **non-zero distance** instead.

**Steps to Reproduce:**

1. Go to Admin → Store List → Tools → Find Nearby Stores.
2. Select **"Near an address"**.
3. Enter an address that exactly matches an existing store's address — e.g., `9740 SOUTHWEST BANK ROAD`, Zip: `98070`.
4. Set Radius (e.g., 2000 meters) and click Search.
5. Observe the distance shown for the store matching the exact searched address.

**Actual Behavior:**

* Store **"VASHON TW #400322 NWG"** (Northwest Grocers) — located at the exact searched address (`9740 SOUTHWEST BANK ROAD, WA, 98070-4982`) — shows a distance of **60 m** instead of **0 m**.

**Expected Behavior:**

* When the searched address exactly matches a store's location, that store should be listed with **0 m** distance, reflecting that it is the same point being searched.
