## Description

In the **Notify Brands** feature, inactive users are correctly **excluded from the visible Recipients list** in the UI. However, when sending mail using the **default recipient list**, inactive users are **still receiving emails** — indicating a mismatch between what's shown in the UI and what's actually used on the backend when sending mail.

**Steps to Reproduce:**

1. Go to Notify Brands.
2. Confirm an inactive user does **not** appear in the visible Recipients list (UI).
3. Send a notification/mail using the **default recipient list** (without manually modifying recipients).
4. Check if the inactive user received the email.

**Actual Behavior:**

* Inactive user is **not shown** in the Recipients list (UI) — correct.
* Inactive user **still receives the mail** when sent via the default recipient list — incorrect.

**Expected Behavior:**

* Inactive users should be excluded **both** from the UI recipient list **and** from the actual mail-sending logic.
* If a user is inactive, they should not receive any notification/mail through the default recipient list or any other sending method.
