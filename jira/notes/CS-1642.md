## Description

1. **Hide "Resend Notification Email" from Notes & Log**
Remove the "Resend Notification Email" action/option from the Notes & Log section.
2. **Add filter for "Method of Entry" column**
Introduce a filter option for the "Method of Entry" column so users can filter entries by how they were created.
3. **Internal Notes — restrict auto-generated entries to "Created via Notify Brand" only**
In Internal Notes, only the "Created via Notify Brand" system note should be auto-added. Other notification-triggered notes should not be logged in this section.
4. **Improve Contacts UI — show mail list in hierarchy**
Restructure the Contacts UI to display recipients in a clear hierarchy: Brand → Owner (email) → Sub Owner (email list) → Contacts (email list).
5. **Manual Brand Add — replace "Review Month" with "Retailer"**
During manual brand addition, replace/relabel it as "Retailer / Review."
6. **Email Brands modal — move info details to hover icon**
Remove the information details currently shown inside the Email Brands modal, and instead surface them via a hover icon placed beside the "Email Brands" header.
7. **Email Brands / Notify Brands — add default subject line **
Both the Email Brands and Notify Brands flows should pre-fill a default subject line rather than leaving it blank.
Ticket: [CS-1584](https://caboodleservices.atlassian.net/browse/CS-1584)
8. **Activity Log — fix action label spacing and filter option naming**
Fix the Activity Log action label from "ContactsNotified" (no space) to "Contacts Notified." Additionally, in the "All Actions" filter, replace the "Assignees Notified" option with "Contacts Notified."
9. **Activity/Email Sent Logs — fix broken arrow rendering**
The arrow character currently renders as "—→" (broken/double). It should render as a single, correctly formatted arrow (e.g., "→") on one line.
10. **Delete Notes — fix tooltip/button overlap in confirmation modal**
When deleting a note, clicking Delete opens a confirmation modal ("This cannot be undone") with its own Delete button. Currently, that confirmation Delete button overlaps with the leftover tooltip text ("Delete Note") from the initial click. Fix the overlap so the tooltip does not persist over the modal's button.
11. **Brand Category Review → Notes header rename**
On the Brand-side Category Review, update the Notes section header from "External Notes" to "Notes."
12. **Update the Time format if many 0 exists.**
Example: 2026-08-03T18:00:00.0000000Z
