## Description

In the Trade Spend Sandbox, the **Push** button for Promotions should only be **enabled** under specific conditions. Currently, the button's enable/disable logic does not correctly follow these rules.

**Actual Behavior:**

* Push button is **always enabled** for every promo.
* Users can click Push repeatedly/unnecessarily, even when:* The promo is already in "Brand Approved Promotions"

**Expected Behavior (Push button should be ENABLED only when):**

1. The promo has **not yet been added** to the "Brand Approved Promotions" list, **OR**
2. The promo **already exists** in "Brand Approved Promotions" **but has been updated/edited** in the sandbox and needs to sync those updates.

**Expected Behavior (Push button should be DISABLED when):**

* The promo already exists in "Brand Approved Promotions" **and** the sandbox version matches the approved version exactly (no pending changes).

**Steps to Reproduce:**

1. Go to Broker → Trade Spend Sandbox → Promotions.
2. Select a promo that already exists in "Brand Approved Promotions" with no edits made.
3. Observe that the Push button is still enabled/clickable.
