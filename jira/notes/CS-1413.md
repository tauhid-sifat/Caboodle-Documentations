## Description

If a Promotion is Filtered in the Select Promo Options the Promo Values of the other Promotions display 0 values and the item the is filtered (June B.) is not displayed at all. In this example, you can see in the Event Summary that June B. is the only Event listed because that is the one that is filtered, which is expected. The User would expect the same thing in the Promo Fee. In this case there are 2 other Promotion Fees (JAN B & March A). Expected Result is to display only the event that was selected in the Filter. If the value is 0 enter $0. Again if you look at the event summary above, you can see it says Prime Allowance $0. Essentially only display the events in Promo Fees that are selected in the filter.
