## Description

In the Distributor Sales Report section, within the **Sales by Product** table, the **Total Store Count** value (footer/summary total) does not match the sum of the individual **Store Count** values across all rows in the table.

**Problem**

* The displayed total is a computed/aggregated figure that should equal the sum of its constituent rows, but it currently doesn't — indicating a calculation, aggregation, or data-source mismatch.
* Since Store Count is likely used for business analysis (e.g., distribution reach, coverage tracking), an incorrect total directly misleads reporting and decision-making.

**Impact**

* Users cannot trust the Total Store Count figure for reporting or analysis purposes.
* May cause downstream errors if this total is referenced in exports, dashboards, or shared with stakeholders.
* Raises doubt about the accuracy of other totals/aggregates in the same table or report.

**Steps to Reproduce**

1. Navigate to Distributor Sales Report section.
2. Open the **Sales by Product** table.
3. Manually sum the **Store Count** column across all visible rows.
4. Compare against the **Total Store Count** value shown in the table footer/summary.
5. Observe the mismatch.

**Expected Behavior**

* Total Store Count should always equal the exact sum of the Store Count values across all rows in the table.

**Actual Behavior**

* Total Store Count value does not match the sum of individual row values.
