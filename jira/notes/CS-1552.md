## Description

In the Broker Dashboard, under Promotional Management, the Export functionality is not working. This is currently affecting the JADE broker in the production environment.

1. Log in as JADE broker (or a user under JADE broker) in production.
2. Navigate to Broker Dashboard > Promotional Management.
3. Click the Export button.
4. Observe that export fails/does not produce output.

**Expected Behavior:**
Clicking Export should successfully generate and download the expected file (CSV/Excel/PDF — please confirm format) containing the Promotional Management data.

**Actual Behavior:**
Export does not work — no file is generated/downloaded
