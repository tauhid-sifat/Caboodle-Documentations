## Description

### Steps to Reproduce

1. Login to the Admin Portal.
2. Navigate to **CRM Data Upload → Categories**.
3. Click **Upload Categories**.
4. Select a valid CSV file.
5. Complete the upload.

### Actual Result

* No success toast/message is displayed after upload.
* Upload modal remains open.

### Expected Result

* A success toast/message (e.g., **"Categories uploaded successfully."**) should be displayed.
* The upload modal should close automatically after a successful upload.
