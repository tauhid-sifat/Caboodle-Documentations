## Description

Add a refresh button to the Distributor Report page that re-fetches data for all reports/widgets on the page in a single action, without requiring a full page reload or manual filter re-application.

#### Current Behavior

Users currently have no way to refresh the Distributor Report data without reloading the entire page, which resets UI state (scroll position, expanded rows, etc.) and adds unnecessary friction when checking for updated data.

#### Expected Behavior

* A **Refresh** button is placed next to the existing filter controls on the Distributor Report page.
* Clicking the button re-fetches data for **all reports/widgets** rendered on the page (5+ reports) using the **currently applied filters**.
* All reports should refresh in parallel, not sequentially.
* Each report should show its existing loading state during the refresh.
* The refresh button itself should:* Show a loading/spinning state while any report is still fetching.
  * Be disabled during the refresh to prevent duplicate triggers.
  * Re-enable once all reports complete (success or error).
* Filter values, pagination, sorting, and other UI state must be preserved — refresh only re-runs the data fetches, it does not reset the page.

#### Acceptance Criteria

* Refresh button visible next to filters on the Distributor Report page.
* Clicking refresh triggers data re-fetch for every report on the page.
* All reports refresh in parallel.
* Currently applied filters are respected during refresh.
* Button shows loading state while refresh is in progress.
* Button is disabled during refresh and re-enables on completion.
* UI state (filters, pagination, sort, scroll) is preserved across refresh.
* Individual report loading indicators behave normally during refresh.
* Works consistently across supported browsers (Chrome, Edge, Firefox).
