## Description

When a user creates a new promotional event from the Trade Spend Sandbox, the generated promo URL does not include the `family id` query parameter. As a result, the "Versions" panel shows "Versions are unavailable here" and prompts the user to open the promotion from the Trade Spend Sandbox list instead. Once the user manually refreshes the page, the `family` id gets appended to the URL and version information loads correctly.

**Steps to Reproduce:**

1. Navigate to Promotional Planning → Trade Spend Sandbox.
2. Create a new promotional event.
3. Observe the URL generated after creation.
4. Click on "Versions" panel.
5. Refresh the page and check the URL again.

**Expected Result:**
Immediately after creating a new promo, the URL should include the `family` id, e.g.:
`https://caboodle-web-stg.caboodleservices.com/e8c90677-0320-41e5-a37f-52a8014c2752/trade-spend-sandbox/db460970-f6ea-4924-be73-f0b1618a3d86?family=ef93df01-aec2-4add-b0e3-c3d21f2d2089`

The "Versions" panel should load version information correctly without requiring a manual refresh.

**Actual Result:**
Immediately after creation, the URL is missing the `family` parameter:
`https://caboodle-web-stg.caboodleservices.com/e8c90677-0320-41e5-a37f-52a8014c2752/trade-spend-sandbox/db460970-f6ea-4924-be73-f0b1618a3d86`

The "Versions" panel shows "Versions are unavailable here" and instructs the user to open the promotion from the Trade Spend Sandbox list. The `family` id only gets appended after a manual page refresh.
