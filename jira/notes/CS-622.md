## Description

We’re hearing that sometimes the Retailers change their Distributors in which case the link between a retailer and distributor needs to be removed and relinked to a different pair.

* Currently there is no way to unlink a distributor from a retailer after a promotion has been created.
* Idea…Can we implement an end date for that link that keeps the current promotion intact with the retailer and distributor, then after the end date, the retailer can be linked to a different distributor…or something like that?
* Then we need to think about the copy function.  If a promotion is created for 2024 then the retailer changes the distributor in 2025, would the promotion capture the new distributor.  Can it change in the middle of the year if it’s based on some sort of dating system?  IE a 2025 plan is created then in July of 2025 the retailer is linked to a new distributor would it flow after that date?  IS this similar to a an item price date?
