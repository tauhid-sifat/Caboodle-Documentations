## Description

During the category review upload process, if any validation or processing errors occur, the user should be able to download an error file. The error file must include each failed row along with the corresponding error reason, allowing the user to identify and fix the issues easily before re-uploading.

**Tasks:**

* Display a **Download Error File** option when the upload contains errors.
* Download the error file provided by the backend.
* Ensure the downloaded file contains:* The original row data.
  * A dedicated **Error Reason** column with row-specific validation or processing errors.
* Hide the download option when the upload completes successfully without errors.
* Handle download failures gracefully by showing an appropriate error message.
