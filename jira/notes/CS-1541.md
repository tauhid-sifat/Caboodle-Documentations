## Description

In the Admin Panel, under Brokers → Sub Broker User, the "Invited By" filter does not return correct/expected results when applied.

**Steps to Reproduce:**

1. Go to Admin Panel → Brokers → Sub Broker User.
2. Apply the "Invited By" filter, selecting a specific inviter.
3. Observe the filtered results.

**Expected Behavior:**
Only sub-broker users invited by the selected person should be shown.

**Actual Behavior:**
Filter returns incorrect results — *(please confirm which of the below matches what you're seeing, so I can tighten the ticket)*:

* Shows sub-broker users invited by someone else, or
* Shows no results even when matching users exist, or
* Shows all users regardless of filter selection
