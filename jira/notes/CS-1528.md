## Description

In **Product Specs → Category** section, each category has a **UPC filter** intended to let users filter products belonging to that specific category. However, the UPC filter's option list incorrectly includes UPC values belonging to **other categories**, not just the selected one.

**Problem**

* The UPC filter options are not scoped/restricted to the current category's products — instead, they appear to pull from a broader/global UPC list.
* This allows users to select a UPC that doesn't even belong to the category they're currently viewing, which would either return no results or, worse, incorrectly filter/display data.

**Impact**

* Users may select an irrelevant UPC value and get confusing results (empty state or unexpected cross-category data).
* Undermines confidence in the category-scoped filtering — users expect filters within a category to only reflect that category's data.
* Could indicate the UPC filter options are sourced from a global/master product list rather than being scoped by category server-side or client-side.

**Steps to Reproduce**

1. Navigate to **Product Specs → Category**.
2. Select any specific category.
3. Open the **UPC filter** dropdown within that category.
4. Review the list of UPC values shown.
5. Cross-check against the actual products belonging to this category — observe UPC values present that belong to other categories instead.

**Expected Behavior**

* The UPC filter, when viewed within a specific category, should only display UPC values belonging to products within that category.

**Actual Behavior**

* The UPC filter includes UPC values from other categories as well, not scoped to the current category.
