## Description

In the "Category Name" dropdown (Add Product), the same category option appears multiple times in the list.

**Steps to Reproduce:**

1. Go to CRM – Product Specs > Add Product.
2. Select a Brand Name.
3. Open the "Category Name" dropdown.
4. Observe duplicate entries for the same category.

**Expected Behavior:**
Each category option should appear only once in the dropdown, with no duplicates.

**Suggested Fix:**
Add restriction during creating of "Category Name". Block the creation of duplicate "Category Name"

**Acceptance Criteria:**

* Category Name dropdown shows each category option exactly once.
* No duplicate entries regardless of which Brand is selected.
