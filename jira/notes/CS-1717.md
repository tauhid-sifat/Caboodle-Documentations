## Description

The CSV export of the Warehouse Report section under Distributor Sales Report does not match the layout/format shown in the UI. The exported file should mirror the columns, order, and structure as displayed on screen so users get a consistent view between what they see and what they download.

**Steps to Reproduce:**

1. Navigate to Distributor Sales Report → Warehouse Report.
2. Note the columns, order, and grouping shown in the UI.
3. Export the section as CSV.
4. Compare the exported file against the UI.

**Expected Result:**
The exported CSV should reflect the same columns, column order, and data structure as shown in the Warehouse Report UI.

**Actual Result:**
The exported CSV format differs from the UI
