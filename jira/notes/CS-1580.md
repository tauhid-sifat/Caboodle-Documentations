## Description

In the Brand Report Activity Log, an action point is displayed as "ContactsNotified" without a space between the words. Additionally, the corresponding filter list option currently shows as "Assignees Notified," which is incorrect and should instead read "Contacts Notified" to correctly match the actual action.

**Steps to Reproduce:**

1. Go to Broker Dashboard > Brand Report > Activity Log.
2. Observe an action entry labeled "ContactsNotified" (no space).
3. Check the Activity Log filter list.
4. Observe that the filter option shows "Assignees Notified" instead of "Contacts Notified."

**Expected Behavior:**

1. Action label should display as **"Contacts Notified"** (with proper spacing).
2. Filter list should show **"Contacts Notified"** as the option, replacing the incorrect "Assignees Notified" label.

**Actual Behavior:**

1. Action label displays as "ContactsNotified" (missing space).
2. Filter list incorrectly shows "Assignees Notified."
