## Description

* **Request:** `startDate` (optional — defaults to the current date), `endDate` (required).
* **Behavior:** Scan every date-type column across all rows and return the cells whose values fall within `[startDate, endDate]` sort by most recent.
* **Response:** a list of objects containing `columnName`, `date`, and `brandReportId`.
