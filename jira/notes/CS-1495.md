## Description

In the Notes section under Promotional Management, the **Brand Name** filter should only show brand options that actually exist within the current Notes list. Currently, the filter includes extra brand options that don't correspond to any entries in the Notes list. Additionally, filter options are not dynamically updating based on other filters applied — selections in one filter don't narrow down the available options in the Brand Name filter (or vice versa).

**Steps to Reproduce:**

1. Go to Promotional Management → Notes
2. Open the Brand Name filter
3. Compare filter options against the brands actually present in the Notes list
4. Note extra brand options appear that have no matching entries in Notes
5. Apply another filter (e.g., a different field) alongside Brand Name
6. Observe: Brand Name filter options do not update/narrow based on the other filter's selection

**Expected Behavior:**

* Brand Name filter should only display brands that have at least one corresponding entry in the current Notes list.
* Filter options should dynamically update based on other filters already applied — same cascading behavior described in **Ticket 17**.

**Actual Behavior:**

* Filter shows extra/irrelevant brand options not present in the actual Notes data.
* Filter options remain static regardless of other filters selected — no dependency/narrowing between filters.
