## Description

Both **Submit** and **Revoke** actions in Promotional Management are failing. The API call returns a **400 Bad Request** error for both actions.

**Steps to Reproduce:**

1. Go to Promotional Management
2. Attempt to **Submit** a promo event — fails with 400 Bad Request
3. Attempt to **Revoke** a promo event — fails with 400 Bad Request

**Expected Behavior:** Both Submit and Revoke actions should complete successfully, updating the promo event status accordingly.

**Actual Behavior:** Both actions fail at the API level with a 400 Bad Request response.

**Impact:** Users cannot submit or revoke promo events at all — complete blocker for core Promotional Management workflow.
