## Description

Inside a folder, if a user types text into the search bar and then clears it by pressing backspace repeatedly, removing the last character navigates the user out of the folder entirely — instead of simply showing an empty search with the folder's full contents.

**Steps to Reproduce:**

1. Go to Files section
2. Open/enter any folder
3. Type any text in the search bar (within that folder)
4. Press Backspace repeatedly to clear the text, one character at a time
5. Once the last character is removed, observe: user is taken out of the folder

**Expected Behavior:** Clearing the search bar (even down to an empty string) should keep the user inside the current folder and simply show the folder's unfiltered contents.

**Actual Behavior:** Removing the last character exits the folder, forcing the user to re-navigate back in.
