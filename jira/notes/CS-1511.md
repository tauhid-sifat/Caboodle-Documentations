## Description

Currently, when a user navigates from the Brands report section to any report page, there is no direct way to return to the Brands report section from within that module. Users need to use the browser back button or can go back by clicking the report section.

**Requirement:**
Add a **Back** button (or equivalent navigation element, e.g., breadcrumb/"Back to Dashboard" link) to every module accessible from the Brands report section, allowing users to return directly to the Brands report without routing through other section.
