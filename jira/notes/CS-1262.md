## Description

Currently, KeHE and UNFI distributor reports are implemented separately despite sharing a largely identical data structure and reporting logic. Maintaining two independent implementations creates duplication and increases maintenance overhead.

This task aims to consolidate both reports into a **single unified report** capable of serving data for both distributors.

### **Implementation Notes**

* Identify common fields and metrics across both reports.
* Consolidate report logic into a **single implementation**.
* Introduce a **Distributor identifier/filter** to distinguish between KeHE and UNFI data.
* Ensure existing calculations and report outputs remain consistent with the current reports.

### **Acceptance Criteria**

* A single report supports both **KeHE** and **UNFI** data.
* Users can **identify or filter by distributor**.
* Output remains consistent with the existing reports.
* Export functionality (if applicable) continues to work as expected.
