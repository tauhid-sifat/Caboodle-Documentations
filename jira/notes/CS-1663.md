## Description

The Filter API in the **Broker → Category Review**  and  **Brand → Category Review** sections are failing in the **Production environment**, preventing users from applying filters on this screen.

**Steps to Reproduce:**

1. Log in to Production environment.
2. Go to Broker → Category Review.
3. Apply any filter.
4. Observe the API call/response (via network tab or logs).
5. Go to Brand → Category Review.
6. Apply any filter.
7. Observe the API call/response (via network tab or logs).

**Actual Behavior:**

* Filter API call fails in Production.
* *Getting 400 with *"Unrecognized filter property."

**Expected Behavior:**

* Filter API should return a successful response with correctly filtered data, consistent with other environments (Staging).
