## Description

* No validation error when uploading a blank category file.
* **Steps to Reproduce:**1. Go to the "Create Category" section.
  2. Select and upload an empty Excel/CSV file (containing no data or only headers).
  3. Click "Submit".
* **Actual Result:*** No error message is shown.
  * It appears as if the file was uploaded successfully, though it contains no data.
* **Expected Result:*** The system should validate the file content.
  * If the file is blank or contains no valid rows, it should show an appropriate error message like "Uploaded file is empty" or "No valid data found".
