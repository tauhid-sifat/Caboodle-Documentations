## Description

In **Admin – Brands – Brand Owner**, the **Email filter** is not functioning. When a user searches/filters using an email value, the results **do not change** — the list remains the same regardless of what is entered.

**Steps to Reproduce:**

1. Go to Admin → Brands → Brand Owner.
2. Use the **Email filter** to search for a specific email.
3. Observe the results.

**Actual Behavior:**

* Entering a value in the Email filter does not update/filter the list — results remain unchanged, showing the same (unfiltered) data as before applying the filter.

**Expected Behavior:**

* Entering an email (full or partial) in the Email filter should filter the Brand Owner list to show only matching records.
