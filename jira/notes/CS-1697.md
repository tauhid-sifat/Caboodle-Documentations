## Description

Backend support is needed for a new **Range filter** on **"Review End Date"** in Category Review. The Filter API must accept a **from/to date range** for Review End Date and return correctly filtered results based on that range.

**Requirement:**

* Update the Category Review Filter API to accept two new parameters (e.g., `reviewEndDateFrom` and `reviewEndDateTo` — naming to be confirmed with engineering) representing the start and end of the desired **Review End Date** range.
* API should filter and return only records where the **Review End Date** column falls within the provided range (inclusive of both boundary dates — per the earlier raised date-range inclusivity ticket for Brand Report).
* If only one of the two parameters is provided (from or to), API should support **open-ended range filtering** (e.g., only "from" = all records on/after that date; only "to" = all records on/before that date).

**Data Reference:**

* Filter should operate on the existing **"Review End Date"** column already present in the Category Review table/data model
