## Description

Per the intended logic, promo events should only appear in **Broker – Promotional Management** and **Promotional Calendar** if they exist in **"Brand Approved Promotions."** However, currently:

* **Brand Approved Promotions** → No promo events present.
* **Promotional Calendar** → No promo events present.
* **Broker – Promotional Management** → **Multiple promo events are present**.

This breaks the expected dependency between these three sections.

**Expected Behavior (per actual intended logic):**

* Events should only be visible in **Broker – Promotional Management** and **Promotional Calendar** if they are present in **"Brand Approved Promotions."**
* If "Brand Approved Promotions" has **no events**, then both **Promotional Calendar** and **Broker – Promotional Management** should also show **no events**.

**Actual Behavior:**

* "Brand Approved Promotions" → Empty (no events).
* "Promotional Calendar" → Empty (no events) — **correct**, follows expected logic.
* "Broker – Promotional Management" → **Shows multiple events** — **incorrect**, violates expected logic since these events aren't backed by any entry in "Brand Approved Promotions."

**Steps to Reproduce:**

1. Confirm "Brand Approved Promotions" (Brand side) has zero promo events. (Check for** “All Clean Food“ **Brand)
2. Confirm "Promotional Calendar" also shows zero events (expected, consistent).
3. Go to Broker → Promotional Management.
4. Observe multiple promo events are listed there.
