## Description

In the Monthly Report section, the "Sort By Line" filter appears to be permanently locked/disabled, preventing users from interacting with it or changing the sort order as needed.

**Impact**

* Reduces report usability and flexibility for users who need to reorder data by line.
* May be perceived as a broken/non-functional feature, reducing trust in the report's completeness.

**Steps to Reproduce**

1. Navigate to Monthly Report section.
2. Locate the "Sort By Line" filter.
3. Attempt to interact with/change it.
4. Observe that it remains locked/disabled regardless of other filter states or data selections.

**Expected Behavior**

* "Sort By Line" filter should be interactive and allow users to change the sort order, unless there's a specific, documented condition under which it should remain locked (e.g., no line data available).

**Actual Behavior**

* Filter is always locked/disabled, with no clear condition triggering this state.
