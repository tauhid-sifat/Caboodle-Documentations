## Description

When filtering by brand and exporting, some items belonging to that brand are missing from the exported report, even though they appear correctly in the underlying Banner SKU list. Exporting with no filters applied includes the missing items correctly.

**Steps to Reproduce:**

1. Go to Admin, Banner SKU list
2. Filter by Brand: California Naturals
3. Export the filtered report
4. Compare against the Banner SKU list — note "Super Moisture Shampoo" is present in the list but missing from the filtered export
5. Export with no filter applied — the item appears correctly

**Expected Behavior:** Filtered export should include all items belonging to the selected brand, matching what's shown in the Banner SKU list.

**Actual Behavior:** Some items silently drop out of the filtered export only — data loss specific to the filter+export path.
