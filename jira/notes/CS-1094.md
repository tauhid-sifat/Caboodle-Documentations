## Description

in the filter section, selecting the Grocery category returns no results, even though there are SKUs like “onion” under that category. Selecting that SKU individually also shows no data.

**Steps to Reproduce:**

1. Go to the Trade Spend Sandbox page.
2. Open the filter panel.
3. Select the category *Grocery* and apply the filter.
4. Observe that no results appear.
5. Alternatively, select the SKU *Onion* (which belongs to Grocery) and apply the filter.
6. Observe that no data is returned.
