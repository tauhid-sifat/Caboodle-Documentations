## Description

We had a good conversation about this on last Tuesday’s Call (5-28-24) This is how we discussed it would work

* New Button in Promo details – Add Sku
* Select promotions (check box in front of each one)
* Click Add Sku.  A menu of available skus with check boxes will appear.  What’s already selected will be greyed out.  It will not add a sku prior to active date.
* A new row will be created for every item that was selected with the new sku or multiple skus (a new line for each sku) Click the skus to add
* If user wants to change the metric for the new skus (intro deal) they can go back and edit the with the new select all functionality
* I believe changes can only be made to 1 banner at a time since each banner may have different products that are active.
