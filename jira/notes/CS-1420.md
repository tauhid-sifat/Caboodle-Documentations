## Description

### **Problem Summary**

There are two distinct bugs occurring within the Promotion planning workflow:

1. **Sorting Issue:** Event names are not being displayed in chronological order as expected.
2. **Data Sync Issue:** Selecting an ad fee does not propagate the values to the "Store Ad Fee" or "Ad & TPR fees" columns under specific navigation paths, but *does* sync successfully if the user selects the event name directly in the Event Name section.

### **Steps to Reproduce**

#### **Scenario A: Bugged State**

1. Log in or impersonate **Broker:** `SarahNoble@noblesalesint.com`.
2. Navigate to **Brand:** `Viori` > **Promotion** > `SPROUTS 2026 DRAFT KG`.
3. Observe the Event Names list (they are not sorted chronologically).
4. Choose an ad fee in the designated field list.
5. Check the **Product Summary** section > **Store Ad Fee** column.* *Actual Result:* Value displays as `0`.
6. Check the **View & Edit Promo Events Details** section > **Ad & TPR fees** column.* *Actual Result:* The column is completely blank.

#### **Scenario B: Working State (Workaround / Comparison)**

1. Within the same promotion, navigate to the **Event Name Section** and explicitly select the same event name.
2. Return to look at the **Product Summary** and **View & Edit Promo Events Details** sections.* *Actual Result:* The chosen ad fee value now correctly populates in both sections.

### **Expected Behavior**

* **Event Names:** Should automatically sort in chronological order by default.
* **Ad Fees:** Selecting an ad fee from the dropdown/field list should immediately sync and reflect across all corresponding columns (**Store Ad Fee** and **Ad & TPR fees**) regardless of how the user navigates or selects the event.
